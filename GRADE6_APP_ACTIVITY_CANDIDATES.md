# Grade 6 App Activity Candidates from Monthly Planning

Reviewed:
- `plans/6th Grade Technology/6th Grade Monthly Planning`
- `plans/6th Grade Technology/Draft Planning/Monthly Planning`
- Current classroom activity types in the app

Grade-band rule: Grade 6 is Primary. Keep exactly 5 formal grades per trimester. The app can collect practice, evidence, reflections, and make-up work, but only the planned summative activities below should be treated by the teacher as formal grade evidence.

## App Activity Types Available

- Vocabulary lane: Word Hunt, Matching, Flashcards, Quiz, Word Search, Crossword, Hangman, Scramble, Wordle, Speed Match, Fill in Blank.
- Classroom Activities: Map / Diagram, Structured Response, Card Sort / Sequence Sort, Spreadsheet / Data Table, Image Label / Hotspot, External Artifact / Evidence, Flowchart / Algorithm.

Note: Word Hunt is already part of the app. The Word Hunt rows below are activities to assign/configure with existing vocabulary sets, not new app features to build.

## Vocabulary Sets to Use

The Grade 6 vocabulary files already exist under `vocabularies/grade6`. Since Word Hunt is already in the app, these only need to be assigned with the correct vocabulary set. Use the quicker vocabulary games for weekly review.

- T1 formal: `grade6_t1_summative_core_vocabulary.json`
- T2 formal: `grade6_t2_summative_robotics_vocabulary.json`
- T3 formal spreadsheet/data: `grade6_t3_summative_spreadsheet_vocabulary.json`
- Weekly practice sets: use the month/week vocabulary JSON files already named for March through December.

## Activities to Avoid Duplicating

- Do not make separate formal grades for every weekly vocabulary review; keep them formative unless they are one of the 15 planned summatives.
- Do not replace Scratch, Google Sites, Google Sheets, Tinkercad, mBot, MakeCode, or micro:bit work with an app-only activity. Use External Artifact / Evidence when the real product lives in another tool.
- Peer comments and gallery-style review are useful for May, August, November, and December, but the current workaround is Structured Response. A true Peer Feedback / Gallery workflow would still be a future enhancement.
