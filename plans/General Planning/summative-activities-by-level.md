# Summative Activities By Level

This reference summarizes the counted summative/daily-grade/appreciation/project evidence for Grades 6-9. It is organized by trimester, with separate tables for each level.

- `IT` = 1st Trimester
- `IIT` = 2nd Trimester
- `IIIT` = 3rd Trimester

Note: Grade 6 is listed with only the 5 counted activities per trimester. Appreciation or practice evidence for Grade 6 is intentionally not included in these tables.

## Common Collection Expectations

| Evidence Type | What To Collect |
|---|---|
| Vocabulary table | Definitions, illustrations, and example sentences for the 10 trimester words. |
| Quiz or quiz-style check | Completed answers plus short explanations where required. |
| Appreciation grade | Checklist, self-reflection, peer feedback, teamwork evidence, or teacher-observed behavior note. |
| Design plan | Goal/purpose, materials or tools, diagram/sketch, test plan, and success criteria. |
| Build or prototype | Working file, screenshot/photo, code evidence, labeled diagram, or teacher-observed demo. |
| Final presentation/demo | Product demonstration, explanation of design choices, testing evidence, improvement, and reflection. |
