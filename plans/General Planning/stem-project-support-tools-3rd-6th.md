# STEM Project Support Tools - Grades 3-6

Generated: 2026-05-31

Purpose: shared planning templates for the safe STEM alignment across Grades 3-6. These tools support existing summative slots and make-up work; they do not add extra formal grades.

## 1. Simple STEM Project Checklist

Use for Grade 3 Scratch Sound, Grade 4 inertia/movement, Grade 5 interactive routine, and Grade 6 mBot work.

| Item | Evidence |
| --- | --- |
| Goal or question | What will the project test, show, or solve? |
| Input or starting action | Button, command, push, sensor, data card, or starting condition. |
| Output or result | Sound, movement, table result, chart result, robot behavior, or displayed answer. |
| Test or trace | Screenshot, paper trace, table, observation, route map, or teacher checklist. |
| Improvement | One change made after testing or feedback. |
| Explanation | One short sentence or one-minute explanation of how it worked. |

## 3. Simple STEM Project Rubric

Use four levels if a rubric is needed, or convert each row to a checklist.

| Criterion | 4 - Secure | 3 - Developing | 2 - Beginning | 1 - Needs Support |
| --- | --- | --- | --- | --- |
| Project goal | Clear and realistic | Mostly clear | Partly clear | Missing or unclear |
| Required parts | All required parts included | One minor part missing | Several parts incomplete | Most parts missing |
| Test evidence | Test/result is clear | Test/result is present | Test/result is incomplete | No clear test/result |
| Improvement | Specific improvement explained | Improvement named | Improvement vague | No improvement |
| Explanation | Uses correct project words | Mostly correct words | Limited explanation | Cannot explain yet |

## Make-Up Defaults

- If hardware fails, collect planning, route, data, or flowchart evidence first.
- If accounts fail, use paper templates and upload later.
- If a student is absent for a project run, use teacher-provided data cards plus a short make-up explanation.
- If a class period is shortened, stop at partial test evidence and finish the demo in a scheduled station.
