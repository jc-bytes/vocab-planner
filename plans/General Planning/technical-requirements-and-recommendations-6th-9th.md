# Technical Requirements and Recommendations - Technology 6th to 9th Grade

Date prepared: May 23, 2026  
School year: 2026  
Program: Technology / Robotics / Physical Computing

This report summarizes the applications, accounts, hardware, and student-computer specifications needed for the 6th, 7th, 8th, and 9th grade technology plans. It is meant to support purchasing, lab setup, and classroom readiness.

## Executive Recommendation

The safest purchasing choice for this program is a **Windows 11 laptop** with:

- Intel i5 / AMD Ryzen 5 or better
- 16 GB RAM
- 256 GB SSD or larger
- 14-inch 1080p screen
- Wi-Fi and Bluetooth
- At least 2 USB ports, or USB-C plus adapters
- Chrome and Microsoft Edge installed
- Battery life of 6-8 classroom hours

This configuration supports Google tools, Scratch, mBlock, MakeCode, Inkscape, Arduino IDE, Python, Canva, Tinkercad, browser-based tools, and physical-device connections with fewer classroom interruptions.

## Chromebook Position

Chromebooks can work for many browser-based activities:

- Google Classroom
- Google Docs, Slides, Sheets
- Scratch online
- MakeCode simulator
- Canva
- Tinkercad
- Google Sites

However, Chromebooks are **not the best primary device** for this full 6th-9th pathway because the program also needs smoother support for:

- Arduino IDE
- Inkscape
- mBlock hardware connections
- USB serial drivers
- Scratch Link / micro:bit connection workflows
- Local file management for code, screenshots, and hardware evidence

Chromebooks may be acceptable for 6th grade and parts of 7th grade if hardware connections are carefully tested, but Windows or Mac laptops are strongly preferred for the full program.

## Classroom Setup Checklist

Before the school year:

- Confirm every student can log in to Google Classroom.
- Install Chrome and Edge.
- Confirm Google Drive, Docs, Slides, Sheets, and Sites access.
- Install Scratch Link where needed.
- Install mBlock 5 on robotics computers.
- Install Arduino IDE on 8th and 9th grade computers.
- Install Inkscape on 8th grade computers.
- Confirm Python environment or approved browser Python tool.
- Confirm Canva and Tinkercad account/access rules.
- Test MakeCode in Chrome or Edge.
- Test mBot connection on at least one student computer.
- Test micro:bit WebUSB connection in Chrome or Edge.
- Test Arduino/Freenove upload through USB.
- Prepare USB-C adapters if laptops do not have USB-A ports.
- Prepare printed fallback copies for summatives and study guides.

## Purchasing Priorities

1. Student laptops that meet the recommended specification.
2. USB-C/USB-A adapters and spare USB cables.
3. Charging/storage plan for student laptops.
4. mBot batteries/chargers and spare cables.
5. micro:bit batteries and spare USB cables.
6. Arduino/Freenove replacement components: LEDs, resistors, buttons, jumper wires, sensors.
7. Headphones for 9th grade audio activities.
8. A small stock of printed fallback packets.

## Source Notes

- Google Workspace officially recommends a supported, up-to-date browser and lists Chrome, Firefox, Safari, and Microsoft Edge as supported options. Chrome supports all Google Workspace features. Source: https://support.google.com/a/answer/33864
- Arduino IDE 2 official documentation lists Windows 10 or newer 64-bit, macOS 10.15 or newer 64-bit, and 64-bit Linux as requirements. Source: https://docs.arduino.cc/software/ide-v2/tutorials/getting-started/ide-v2-downloading-and-installing
- Makeblock documentation states mBlock 5 can run on Windows and macOS, with Windows 7 or later / Mac OS X or later listed in the install article; Makeblock also recommends Chrome for web use and notes CH340 drivers may be needed for device connection. Sources: https://support.makeblock.com/hc/en-us/articles/14779090584599-Install-mBlock-5-on-Windows-and-macOS and https://support.makeblock.com/hc/en-us/articles/4408569377431-FAQs-on-mBlock-5
- MakeCode for micro:bit supports current common browsers on Windows, macOS, Linux, Chrome OS, iOS, and Android; Internet Explorer is not supported. Source: https://makecode.microbit.org/browsers
- micro:bit support states MakeCode and Python editors are browser-based and work on Windows, Mac, Chrome OS, and Linux; Chrome and Edge fully support direct flashing using WebUSB. Sources: https://support.microbit.org/support/solutions/articles/19000106819-which-editors-can-i-use-with-the-micro-bit- and https://support.microbit.org/support/solutions/articles/19000013991-which-browsers-work-with-the-coding-editors
