# Grade 8 T3 exit and review bank

Use one exit prompt in the last three to five minutes. Students may type the response or use a half-sheet. The teacher key is in the second section and should not be projected with the prompts.

## Student prompts

1. Write one app problem and one feature that directly addresses it.
2. Complete the event: `Tap Submit → ________` and explain why the response is useful.
3. Write one test case with an action and expected result.
4. Explain the difference between a screen and an event.
5. Rewrite “The app works” as an observable success rule.
6. Why does `input()` often need `int()` or `float()` before arithmetic?
7. Trace `x = 4; y = x * 3; print(y)`.
8. Name the likely error when code uses `totl` after defining `total`.
9. A program runs but adds when it should multiply. Name the error type and correction.
10. What belongs in a repeatable test record?
11. Convert decimal 6 to four-bit binary and show the place values.
12. Convert binary 1011 to decimal and show the addition.
13. Why does a bit pattern need a file format or decoding rule?
14. Describe one micro:bit input and the Scratch action it should control.
15. Write one game-loop behavior that should repeat.
16. Write a peer-test comment that names a control issue without using “bad” or “weird.”
17. Explain why a retest should keep the same input or action.
18. Name one piece of evidence stronger than a completion claim.
19. Write the five expo explanation points from memory.
20. State one project improvement and the test result that supports it.

## Teacher check

1. Any specific problem-feature match. 2. A visible result such as validate, save, or open confirmation. 3. Must include repeatable action and expected result. 4. Screen is a view; event is a trigger and response. 5. Any countable or visible rule. 6. `input()` returns text. 7. 12. 8. NameError or undefined variable. 9. Logic error; replace `+` with `*`. 10. Input or condition, expected, actual, pass or fail. 11. 0110, 4 + 2. 12. 11, 8 + 2 + 1. 13. Bits need agreed meaning. 14–20 accept accurate answers tied to the student's project and recorded evidence.
