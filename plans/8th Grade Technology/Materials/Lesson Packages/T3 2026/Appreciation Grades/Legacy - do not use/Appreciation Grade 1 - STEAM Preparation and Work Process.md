# Appreciation Grade 1: App Development Work Habits and File Responsibility

Grade 8 Technology · Trimester 3 · 40 points  
Scheduled: 8A Wednesday, September 30 · 8B Monday, September 28

Use the Club Signup App scenario and the app file created during the taught app-design sequence.

1. Open the correct app file without creating a duplicate.
2. Rename it `G8_A1_Lastname_Firstname_AppWork`.
3. Follow the supplied task order and complete the assigned screen or event edit.
4. Record one independent correction or one clear help request.
5. Save the file in the teacher-approved location and complete the five-item evidence checklist.

The teacher uses the file, checklist, and in-class observation. This is regular Technology evidence, not STEAM evidence. File readiness is 4 of 40 points (10%). A student's own working computer and login satisfy readiness. A documented school device, network, or login failure is not penalized when the equal paper app map and checklist are completed. No phone, photo, or screenshot evidence is accepted or required.
