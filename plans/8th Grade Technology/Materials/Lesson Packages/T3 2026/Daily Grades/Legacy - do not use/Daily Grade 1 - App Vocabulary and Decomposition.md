## Supplied source

## Fixed task

Create one four-column table with exactly these ten terms: decomposition, user, screen, event, input, output, app, button, variable, feedback.

For each term, write a clear definition and one app example. A text example is enough; decoration is not scored. Then use this fixed goal:

> A student needs an app that records one homework task and shows a confirmation.

Break the goal into five ordered subtasks. Each subtask must start with an action verb and describe a different job.

## Structural example

For the unrelated term `navigation`: definition, “the paths used to move between screens”; example, “tap Home to return to the first screen.” Do not copy this as one of the ten answers.
