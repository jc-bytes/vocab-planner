# Grade 8 T3 teacher expected-response and check notes

Teacher-only. Use these notes for practice feedback. Formal work uses the existing rubric or answer key.

## App practice

- App A: accept different contexts when the user is specific and the five jobs use verbs such as identify, enter, search, display, save, or test. Reject decoration as a substitute for a job.
- App B: a valid map starts on one named screen, uses arrows in one direction, and gives the app response after each action. A stored value could be date, time, seat number, or reservation status.
- App C: the problem must exist before the solution. The feature must address it. A success rule needs an observable result such as tap count, time, correct screen, or visible confirmation.
- App D: the revision must respond to the issue in the actual-result column. A retest repeats the same starting condition and action.

## Python practice

- Python A is practice and should contain two `int()`-converted inputs, three arithmetic assignments using `+`, `-`, and `*`, and three labeled outputs. Use only the fixed practice test pairs.
- Python B records the evidence trail. Strong records name the type or failed result, quote the changed line, and report the same test after correction. Watch for multiple changes made before retesting.

## Binary practice key

| Decimal | Binary | Addition |
|---:|---|---|
| 3 | 0011 | 2 + 1 |
| 5 | 0101 | 4 + 1 |
| 7 | 0111 | 4 + 2 + 1 |
| 9 | 1001 | 8 + 1 |
| 12 | 1100 | 8 + 4 |
| 14 | 1110 | 8 + 4 + 2 |

For the explanation, expect the idea that bits require an agreed format or decoding rule. The same pattern has no single meaning by itself.

## Fast checks during project classes

- W10 45: file opens; title, sprite, background, and one input-action map exist.
- W10 90: Catch the Star uses the supplied start positions; A/left and B/right change x by 20; Star contact adds one and relocates; Obstacle contact shows feedback, resets score, and resets Player. Use all five fixed tests.
- W11 45: peer feedback includes a control issue, clarity issue, positive feature, fix, and same-condition retest.
- W11 90: final file, log, speaking notes, and reflection draft are present.
- W12 45: rehearsal lasts 90–120 seconds and explains control, game logic, challenge, test result, and improvement.
- W12 90: open the submitted file before scoring and observe the live demonstration.

## Reflection check

Each answer needs a named skill or problem and concrete evidence. Return statements such as “coding was good” or “I will improve” for one specific example.
