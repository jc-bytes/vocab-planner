# Scratch + micro:bit game milestones

Use this page at the start and end of every project class.

## Week 10 short class: shell and input

- [ ] Player, Star, and Obstacle use the supplied start positions.
- [ ] The Catch the Star goal is written.
- [ ] A/left and B/right are mapped to the two supplied actions.
- [ ] The project file is saved.
- [ ] Connection or simulator result is recorded in the log.

Teacher checkpoint: file opens and the planned input-action pair is visible.

## Week 10 long class: working game system

- [ ] Main game loop runs.
- [ ] Input controls movement or another meaningful action.
- [ ] Star contact changes `score` and relocates Star.
- [ ] Obstacle contact shows feedback and resets score and Player.
- [ ] One test and one improvement are recorded.

Teacher checkpoint: student demonstrates the input, loop, result rule, and recorded test.

## Week 11 short class: user testing

- [ ] Tester follows the written controls.
- [ ] Control issue, clarity issue, and positive feature are recorded.
- [ ] One issue is corrected.
- [ ] The same test passes or shows a new result after the correction.

## Week 11 long class: final evidence

- [ ] Final project file or link opens.
- [ ] Build and test log is complete.
- [ ] Speaking notes cover all five demonstration points.
- [ ] Reflection draft uses exact project evidence.

## Week 12 short class: rehearsal

- [ ] Project opens before timing begins.
- [ ] Demonstration lasts 90–120 seconds.
- [ ] Controls, game logic, challenge, test result, and improvement are explained.
- [ ] One correction from rehearsal is recorded.

## Week 12 long class: final submission

- [ ] Project file or link submitted.
- [ ] Build and test log submitted.
- [ ] Live demonstration completed.
- [ ] Reflection submitted.
- [ ] Files follow the teacher naming rule.
