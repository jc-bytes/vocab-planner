# App vocabulary reference

This is the supplied practice source before Daily Grade 1. Rewrite each meaning clearly in your own words and add an example that fits an app.

| Term | Supplied meaning |
|---|---|
| decomposition | Breaking one large task into smaller jobs |
| user | The person who uses the app |
| screen | One view or page in an app |
| event | An action or occurrence that starts app behavior |
| input | Data or an action given to the app |
| output | Information or a response produced by the app |
| app | A program designed to help a user complete a purpose |
| button | An interface element a user activates |
| variable | A named place that stores a value that may change |
| feedback | A visible, audible, or other clear response that tells the user what happened |
