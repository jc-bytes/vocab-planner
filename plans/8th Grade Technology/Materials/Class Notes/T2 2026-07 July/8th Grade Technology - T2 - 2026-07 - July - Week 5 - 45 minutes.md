## Class Objective

Build or inspect an ADC/potentiometer setup.

## Pre-Activities

- Review Week 5 practice vocabulary (part 1). digital: Using clear separate values, like on or off analog: Using values that can change smoothly potentiometer: A knob that changes an analog value ADC: A part that changes an analog signal into a number
- Sort examples into digital and analog: button, switch, potentiometer, light level, LED on/off, brightness. Review analog pin names.

## While Activities

- Build or inspect an ADC/potentiometer setup. Read values in the Serial Monitor and record minimum, middle, and maximum values.

## Post-Activities

- Write one sentence explaining why analog values are useful.
