## Class Objective

Build or simulate a flowing LED pattern with multiple LEDs.

## Pre-Activities

- Review Week 2 practice vocabulary (part 1). sequence: Steps or items in order output pin: A pin used to control an output delay: A pause in a program input: Information that goes into a system or program
- Complete a quick sequence puzzle using arrows and numbered steps. Review output pins and delay.

## While Activities

- Build or simulate a flowing LED pattern with multiple LEDs. Modify the order and timing so the pattern changes clearly.
- Answer the following questions in Google classroom:
- How did the pattern change when you modified the timing?
- How did the pattern change when you modified the order?

## Post-Activities

- Draw the sequence in your notebook. Explain how the code controls the LED order.
