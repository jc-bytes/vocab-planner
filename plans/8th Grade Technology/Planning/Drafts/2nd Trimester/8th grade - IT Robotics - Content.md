# 8th Grade - Second Trimester Robotics Content

## Unit Focus
Students use the Freenove Projects Kit to learn safe electronics handling, breadboard circuits, Arduino programming, digital and analog input/output, sensor values, and integrated prototype design.

## Required Tools and References
- Freenove Projects Kit compatible with Arduino IDE.
- Arduino IDE or approved classroom programming environment.
- Freenove Tutorial.pdf and selected sketches from `Freenove_Projects_Kit-refs`.
- Components as available: Freenove control board, breadboard, jumper wires, resistors, LEDs, push button, potentiometer, photoresistor, RGB LED, buzzer, servo, ultrasonic sensor.

## Selected Freenove Topics
- Board and breadboard basics.
- LED Blink.
- Flowing LED.
- Button input and LED control.
- Serial Monitor.
- ADC and potentiometer readings.
- Photoresistor input.
- RGB LED output.
- Buzzer output.
- Servo control.
- Ultrasonic ranging.
- Integrated input-process-output prototype.

## Content Standard Alignment

| Lesson | Main Topic | Student Outcome | Suggested Evidence |
|---|---|---|---|
| 1 | Safety, components, board, and breadboard | Identify parts of the Freenove/Arduino system and follow safe handling procedures. | Labeled board/breadboard diagram and safety rule. |
| 2 | LED Blink and digital output | Build a safe LED circuit and modify timing values in code. | Working circuit photo or demonstration note plus code note. |
| 3 | Flowing LED and sequences | Explain how code order controls output order and timing. | Sequence diagram and modified LED pattern. |
| 4 | Button input | Build a button-controlled LED circuit and explain input-process-output. | Labeled circuit diagram and demonstration. |
| 5 | Serial Monitor | Use serial messages to observe program behavior and support debugging. | Serial observations and modified message/timing. |
| 6 | Analog input and potentiometer | Read analog values and connect sensor values to output behavior. | Data chart with readings and conclusion. |
| 7 | Photoresistor and thresholds | Choose a threshold and use conditions to respond to light levels. | Light readings and threshold explanation. |
| 8 | RGB LED or buzzer | Control color or sound output through code values. | Output pattern with values recorded. |
| 9 | Servo or ultrasonic sensor | Use a sensor or input to control a physical output. | Demonstration, diagram, and explanation. |
| 10-12 | Integrated prototype project | Design, build, test, debug, present, and reflect on a practical Arduino system. | Prototype, circuit diagram, code evidence, test notes, presentation, reflection. |

## Competences
- Build and test basic circuits using safe procedures.
- Use Arduino code to control digital and analog outputs.
- Read sensor/input data and use it to affect system behavior.
- Apply variables, conditions, and testing to improve a prototype.
- Communicate how a physical computing system works.

## Recommended Exam Project
Create an Arduino/Freenove prototype that solves a small practical problem using at least one input, one output, code logic, testing evidence, and a short demonstration.

Possible project types:
- Distance alert.
- Smart parking guide.
- Light-sensitive signal or display.
- Servo gate or access indicator.
- Mini security alert.
- Simple environmental monitor.
