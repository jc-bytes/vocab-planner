# Annual Plan Addendum - Third Trimester Scratch + Micro:bit Integration

## Approved Annual Plan Update
Scratch + Micro:bit integration is added to the third trimester annual plan as the final applied project strand. This update extends the existing third trimester topics of mobile app development, Python programming, representation, binary digits, and project-based debugging by giving students a sensor-controlled programming product to design, test, present, and evaluate.

## Added Area
- Scratch + Micro:bit Interactive Game Development

## Added Learning Objectives
- Connect Micro:bit to Scratch using Scratch Link and Bluetooth on student devices.
- Use Micro:bit input such as buttons, tilt, or accelerometer values to control a Scratch sprite or game behavior.
- Apply event-driven programming, variables, conditions, testing, and debugging to create an interactive game.
- Explain how sensor input is represented, interpreted, and used by a digital program.
- Present and evaluate a Scratch + Micro:bit interactive game using project criteria.
