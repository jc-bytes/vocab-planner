# 8° Technology - August 2026

## Monthly Focus

Students complete the Arduino trimester by exploring distance sensing and integrated control systems, then designing a small Freenove/Arduino prototype for the exam project. The project asks students to solve a practical problem using input, processing, output, testing, and explanation.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- computer
- student's email and password
- student's email and password. sensors
- servo motor
- ultrasonic sensor
- project rubric
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Use sensors and outputs to design an integrated Arduino physical computing prototype.
- Plan, test, debug, and improve a prototype with clear input-process-output behavior and safety routines.
- Present a working or partially working physical computing project using diagrams, code evidence, and testing data.

## Learning Objectives

- Use an ultrasonic distance sensor or another approved sensor as a project input.
- Create a project design plan with purpose, measurable behavior, parts, diagram, code idea, and test criteria.
- Document testing, debugging, improvements, and final demonstration evidence for the physical computing project.

## Learning Outcomes

- Submit ultrasonic sensing practice and an Arduino project design plan.
- Build and improve the exam prototype during Weeks 10-11 using code, circuit, and testing records.
- Demonstrate the prototype and complete reflection, cleanup, and archive evidence during Weeks 12-13 as scheduled.

## Evaluation

- Daily Grade #5 in Week 9: project design plan.
- Exam Project begins in Week 10 and continues in Week 11.
- Exam Project Presentation happens in Week 12.
- Week 13 is reserved for exams, make-up work, reflection, and administration.
