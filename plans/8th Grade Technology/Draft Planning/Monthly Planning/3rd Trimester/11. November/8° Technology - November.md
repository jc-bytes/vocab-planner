# 8° Technology - November 2026

## Monthly Focus

Students finish core learning with data representation and binary concepts, then begin the Scratch + Micro:bit interactive game exam project. Week 9 completes the final daily and appreciation grades; Weeks 10 and 11 are project planning, building, testing, debugging, and documentation; Week 12 begins presentations.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Google Classroom
- LEDs and resistors
- buttons
- sensors
- Scratch access
- Micro:bit or simulator
- Scratch Link/Bluetooth when needed
- project rubric
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Explain representation, symbols, bits, binary numbers, bytes, code, and data size using simple examples.
- Convert small numbers between decimal and binary and connect representation ideas to digital systems.
- Build, test, present, and reflect on a Scratch + Micro:bit interactive game using sensor input and game logic.

## Learning Objectives

- Identify how text, images, sound, numbers, symbols, and physical signals can represent information.
- Convert simple decimal and binary values and explain what bits and bytes represent.
- Plan, build, test, debug, document, and present a sensor-controlled Scratch + Micro:bit game.

## Learning Outcomes

- Complete a binary and representation check with conversions and simple explanations.
- Submit project readiness, responsibility, testing, debugging, and presentation preparation evidence.
- Begin and continue the exam game project in Weeks 10-11 and present in Week 12 or December if needed.

## Evaluation

- Daily Grade #5 in Week 9: binary and representation check.
- Appreciation Grade #2 in Week 9: project readiness and responsibility reflection.
- Exam Project begins in Week 10 and continues in Week 11.
- Exam Project Presentation begins in Week 12 and continues in December if needed.

## Vocabulary Plan

### Practice Vocabulary

#### Week 9: Binary Representation

| Word | Simple Definition |
| --- | --- |
| representation | A way to show information. |
| symbol | A mark or picture that stands for something. |
| bit | A single binary digit, 0 or 1. |
| binary | A number system using only 0 and 1. |
| byte | A group of 8 bits. |
| code | Instructions or symbols used by a computer. |
| decimal | The number system using digits 0 through 9. |
