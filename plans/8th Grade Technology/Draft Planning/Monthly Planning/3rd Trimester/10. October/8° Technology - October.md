# 8° Technology - October 2026

## Monthly Focus

Students connect app-design logic to text-based programming and physical/sensor interaction. They practice Python input, output, variables, arithmetic, selection, and loops, then begin Scratch + Micro:bit integration as preparation for the trimester project.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Google Classroom
- LEDs and resistors
- buttons
- sensors
- Scratch access
- Micro:bit or simulator
- Scratch Link/Bluetooth when needed
- Python environment
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Write and test simple Python programs using algorithms, output, input, variables, arithmetic, selection, and loops.
- Debug syntax and logic errors using expected results, tracing, pair programming, and testing evidence.
- Connect event-driven thinking to Scratch and Micro:bit interaction using sensor-controlled game planning.

## Learning Objectives

- Distinguish algorithms, programs, syntax, strings, variables, input, output, and assignment in short Python tasks.
- Use if/else, random numbers, multi-branch choice, while loops, and counters in guided programs.
- Plan and prototype a sensor-controlled game using Scratch, Micro:bit input, testing, and debugging habits.

## Learning Outcomes

- Submit Python input/output, variable, arithmetic, and selection practice evidence.
- Complete a Python selection and loop debugging check with identified errors and corrections.
- Submit Scratch + Micro:bit setup, sensor-controlled game planning, prototype, and debugging habits evidence.

## Evaluation

- Daily Grade #3 in Week 5: Python input/output and variable task.
- Daily Grade #4 in Week 7: selection/loop debugging check.
- Appreciation Grade #1 in Week 8: pair programming and debugging habits checklist.
