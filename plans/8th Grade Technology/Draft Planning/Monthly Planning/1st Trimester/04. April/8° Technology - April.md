# 8° Technology - April 2026

## Monthly Focus

Students extend the campaign portfolio by learning computing systems, web development, search literacy, and responsible use of digital information. HTML and CSS work stays practical: students build pages that can later support their Google Sites environmental portfolio.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Inkscape
- vector graphics files
- Google Sites access
- Google Classroom
- text editor and browser
- environmental video file
- Scratch access
- project planning sheet
- projector

## Competences

- Explain how computing system components work together through input, processing, storage, output, and software.
- Build simple web content using HTML structure, images, links, CSS styling, and responsible source use.
- Use search strategies, source checks, AI/open-source ideas, and media organization to support a campaign portfolio.

## Learning Objectives

- Label hardware, software, input, output, processor, memory, storage, operating system, and logic roles.
- Create and style simple campaign web content using HTML tags, CSS rules, images, links, and credits.
- Choose keywords, evaluate sources, organize portfolio content, and explain responsible remixing choices.

## Learning Outcomes

- Submit a computing systems diagram that shows input, process, output, storage, and software relationships.
- Submit an HTML/CSS campaign page or practice evidence with image, link, style, and source credit.
- Complete effort, organization, feedback, digital responsibility, research, and video organization evidence.

## Evaluation

- Daily Grade #3 in Week 5: computing systems diagram.
- Daily Grade #4 in Week 7: HTML/CSS campaign page.
- Appreciation Grade #2 in Week 8: effort, organization, feedback, and digital responsibility self-reflection.

### Practice Vocabulary

#### Week 5: Computing Systems

| Word | Simple Definition |
| --- | --- |
| hardware | The physical parts of a computer or device. |
| software | Programs that tell hardware what to do. |
| input | Information that goes into a system or program. |
| output | What a system or program produces. |
| processor | The part that carries out instructions. |
| memory | Short-term storage used while a computer works. |
| storage | Long-term space for files and programs. |
| operating system | Software that manages a computer. |
| program | Instructions a computer can run. |

#### Week 6: AI and Responsible Remix

| Word | Simple Definition |
| --- | --- |
| AI | Software that can do tasks that seem intelligent. |
| machine learning | A type of AI that improves using data examples. |
| data | Facts or values that can be used or studied. |
| training | Using examples to teach a model. |
| testing | Trying something to see if it works. |
| prediction | A guess or result made by a model. |
| model | A simple version or representation of something. |
| limitation | Something that makes results less complete or certain. |
