Vector Graphics Portfolio

8th Grade Final Project

First Trimester

## Project Overview

You will create a personal portfolio using Google Sites to showcase your vector graphics designs. This project combines web development with vector graphics creation while demonstrating your understanding of computing systems concepts.

Learning Objectives

Identify the key components of Google Sites

Recall the elements of vector graphics (paths, nodes, shapes)

Explain how content organization affects website usability

Describe how vector and bitmap images differ and when to use each

Create vector graphics using appropriate tools and techniques

Build a multi-page Google Sites website with proper structure and navigation

Compare different approaches to organizing website content

Examine how search engines might index and rank your portfolio site

Test your website's functionality across different devices

Assess which vector graphic techniques are most effective for your designs

Design original vector graphics for your portfolio

Develop a complete, functioning Google Sites website that effectively showcases your work

Session Schedule

Week 1

Class 1: Project Introduction & Planning

Analyze the project requirements and success criteria

Create a functioning multi-page Google Sites website

Include at least 3 original vector graphics

Implement proper site structure and navigation

Apply consistent design elements across pages

Sketch website layout and plan content organization

Identify which vector graphics to create for your portfolio

Class 2:

First 45 minutes: Vector Graphics Creation

Create original vector graphics using path tools and shape manipulation

Apply layering, grouping, and boolean operations

Design a logo for your portfolio website

Second 45 minutes: Google Sites Setup

Create your Google Sites project

Set up multiple pages with consistent structure

Implement navigation menu

Add placeholder sections for your vector graphics

Week 2

Class 3: Design Refinement

Apply themes and customize the appearance of your site

Add headers, footers, and consistent design elements

Organize content for readability and visual appeal

Test your website's appearance on different devices

Class 4:

First 45 minutes: Integration & Refinement

Upload and integrate your vector graphics into the website

Add proper descriptions and alt text for accessibility and SEO

Test navigation and fix any issues

Add your computing systems knowledge in an "About" section

Second 45 minutes: Final Presentation & Reflection

Present your completed portfolio website to classmates

Demonstrate your vector graphics and explain your design choices

Evaluate your project against the rubric criteria

Reflect on what you learned and how you solved challenges by answering the following questions:

How did your understanding of vector graphics influence your website design choices? Explain specific examples of how you applied vector graphics principles to enhance your portfolio.

What was the most challenging aspect of integrating your vector graphics into the website, and how did you overcome it? Describe your problem-solving process and how your solution evolved from your initial approach.
