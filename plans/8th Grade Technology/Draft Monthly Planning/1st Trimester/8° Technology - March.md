# 8° Technology - March 2026

## Monthly Focus

Students begin the trimester by learning vector graphics in Inkscape and connecting visual design to a real campaign purpose. They practice shapes, paths, layers, grouping, and SVG vocabulary while creating early assets for an environmental campaign portfolio.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Inkscape
- vector graphics files
- Google Sites access
- Google Classroom
- project rubric
- checklist or worksheet
- projector

## Competences

- Create and refine vector graphics using shapes, paths, fill, stroke, grouping, layering, and object order.
- Organize digital design work for a clear audience, purpose, campaign message, and portfolio use.
- Compare vector and bitmap graphics and use feedback to improve an original design product.

## Learning Objectives

- Identify core vector vocabulary and apply it while creating and saving simple graphics in Inkscape.
- Build vector images using shapes, layers, alignment, grouping, paths, nodes, and SVG/markup basics.
- Plan, draft, review, and improve a campaign icon or logo for a Google Sites portfolio.

## Learning Outcomes

- Complete a vector vocabulary table with definitions, illustrations, and example sentences.
- Submit a campaign icon or logo draft using vector tools and clear audience/purpose choices.
- Complete design review, responsibility, collaboration, and improvement evidence for the campaign graphic.

## Evaluation

- Daily Grade #1 in Week 1: vector vocabulary table.
- Daily Grade #2 in Week 3: campaign icon/logo draft.
- Appreciation Grade #1 in Week 4: responsibility and collaboration checklist.

| --- | --- |

| duplicate | To make a copy. |
| resize | To change size. |
| rotate | To turn an object. |
