# 8° Technology - July 2026

## Monthly Focus

Students move from simple digital circuits to analog input, sensor data, sound, color, and servo control. The month emphasizes observing data, adjusting code, and connecting input-process-output thinking to practical Arduino projects.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- computer
- student's email and password

## Competences

- Read analog input values from potentiometers, photoresistors, and other approved sensors.
- Control outputs such as LEDs, RGB LEDs, buzzers, and servos using variables and conditional logic.
- Explain how sensor input is processed and used to control physical outputs in simple Arduino systems.

## Learning Objectives

- Compare digital and analog signals using circuit examples and sensor readings.
- Modify Arduino sketches to respond to changing sensor values and thresholds.
- Document testing results for input/output systems using charts, diagrams, or short explanations.

## Learning Outcomes

- Submit an analog sensor data chart with recorded values and one interpretation.
- Demonstrate a servo, buzzer, RGB LED, or LED output controlled by sensor input.
- Complete an integrated practice challenge and a perseverance/feedback reflection.

## Evaluation

- Daily Grade #3 in Week 5: analog sensor data chart.
- Daily Grade #4 in Week 7: servo or buzzer controlled by input.
- Appreciation Grade #2 in Week 8: perseverance and feedback self-reflection.
