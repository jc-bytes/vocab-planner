# 8° Technology - October 2026

## Monthly Focus

Students connect app-design logic to text-based programming, debugging habits, and digital representation. They practice Python input, output, variables, arithmetic, selection, loops, and binary concepts, then reserve November for Scratch + Micro:bit project setup and the exam project.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Google Classroom
- LEDs and resistors
- buttons
- sensors
- Scratch access
- Micro:bit or simulator
- Scratch Link/Bluetooth when needed
- Python environment
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Write and test simple Python programs using algorithms, output, input, variables, arithmetic, selection, and loops.
- Debug syntax and logic errors using expected results, tracing, pair programming, and testing evidence.
- Connect event-driven thinking, debugging habits, and representation concepts to later Scratch + Micro:bit project planning.

## Learning Objectives

- Distinguish algorithms, programs, syntax, strings, variables, input, output, and assignment in short Python tasks.
- Use if/else, random numbers, multi-branch choice, while loops, and counters in guided programs.
- Use debugging habits, representation vocabulary, and binary conversions to prepare for Scratch + Micro:bit project planning.

## Learning Outcomes

- Submit Python input/output, variable, arithmetic, and selection practice evidence.
- Complete programming habits, loop/debugging habits, and a Python selection/loop debugging check with identified errors and corrections.
- Complete a binary and representation check before November project setup and exam project work.

## Evaluation

- Daily Grade #3 in Week 5: Python input/output and variable task.
- Appreciation Grade #1 in Week 4: programming setup and work habits checklist.
- Appreciation Grade #2 in Week 6: loops and debugging habits checklist.
- Daily Grade #4 in Week 7: selection/loop debugging check.
- Daily Grade #5 in Week 8: binary and representation check.
