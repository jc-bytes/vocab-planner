# 8° Technology - November 2026

## Monthly Focus

Students use November for Scratch + Micro:bit project setup, make-up, and the interactive game exam project. Non-exam daily and appreciation grades are already finished by Week 8, so Week 9 can absorb interruptions and prepare students for the project build weeks.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Google Classroom
- LEDs and resistors
- buttons
- sensors
- Scratch access
- Micro:bit or simulator
- Scratch Link/Bluetooth when needed
- project rubric
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Connect Scratch, Micro:bit input, game controls, testing, and debugging to a sensor-controlled game project.
- Use Week 9 project setup and make-up time to strengthen required evidence without adding new daily or appreciation grades.
- Build, test, present, and reflect on a Scratch + Micro:bit interactive game using sensor input and game logic.

## Learning Objectives

- Set up Scratch + Micro:bit controls and identify how sensor input affects game behavior.
- Use make-up and review time to confirm previous daily and appreciation grade evidence when needed.
- Plan, build, test, debug, document, and present a sensor-controlled Scratch + Micro:bit game.

## Learning Outcomes

- Complete make-up, review, Scratch + Micro:bit setup, and project planning evidence without adding new daily or appreciation grades.
- Submit project setup, testing, debugging, and presentation preparation evidence.
- Begin and continue the exam game project in Weeks 10-11 and present in Week 12 or December if needed.

## Evaluation

- No new daily or appreciation grades after Week 8.
- Week 9 is reserved for make-up, Scratch + Micro:bit setup, and project readiness.
- Exam Project begins in Week 10 and continues in Week 11.
- Exam Project Presentation begins in Week 12 and continues in December if needed.
