# 8° Technology - September 2026

## Monthly Focus

Students begin the third trimester with mobile app design and event-driven programming. They practice decomposition, user needs, interface planning, and simple app screens before later connecting programming ideas to Python and Scratch + Micro:bit work.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Google Classroom
- LEDs and resistors
- buttons
- Scratch access
- Micro:bit or simulator
- Scratch Link/Bluetooth when needed
- Python environment
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Decompose an app idea into smaller tasks, screens, inputs, outputs, and event-driven behaviors.
- Design simple user interfaces for a clear audience, purpose, and user need.
- Use a project logbook to document app planning, feedback, design choices, and progress.

## Learning Objectives

- Break an app problem into smaller parts and identify purpose, audience, screens, input, and output.
- Plan app screens, navigation, buttons, variables, user input, and event flow.
- Build or modify a simple event-driven app feature and record feedback in a logbook.

## Learning Outcomes

- Complete an app vocabulary and decomposition check with smaller tasks and app purpose evidence.
- Submit an app screen plan and event map showing screens, buttons, user actions, and outputs.
- Submit logbook evidence showing user needs, feedback, design choices, and next steps.

## Evaluation

- Daily Grade #1 in Week 1: app vocabulary and decomposition check.
- Daily Grade #2 in Week 2: app screen plan and event map.
