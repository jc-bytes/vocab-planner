# 8° Technology - December 2026

## Monthly Focus

December is reserved for remaining project presentations, exam administration, make-up work, reflection, and digital file cleanup. No new major topics are introduced.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Google Classroom
- LEDs and resistors
- Scratch access
- Micro:bit or simulator
- Scratch Link/Bluetooth when needed
- Python environment
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Present and submit final Scratch + Micro:bit project evidence if a make-up or continuation is needed.
- Reflect on learning, debugging, collaboration, improvement, and personal work habits.
- Organize project files and complete missing exam/admin requirements without adding new assessed content.

## Learning Objectives

- Complete any remaining project presentation, file submission, reflection, or administrative task.
- Verify that project links, screenshots, notes, and reflections are named clearly and submitted correctly.
- Review strengths, challenges, next steps, and key trimester learning through a short reflection.

## Learning Outcomes

- Complete make-up presentation, submission, reflection, or file cleanup evidence only if assigned.
- Finish Week 13 exam/admin work without adding a new daily grade or appreciation grade.
- Leave final project evidence organized for archive, review, or return.

## Evaluation

- Week 13 is used for exams, make-up work, reflection, and administration.
- No new daily grades or appreciation grades are scheduled.
- Exam project presentations may finish here only if November Week 12 was interrupted.

## Vocabulary Plan

No new vocabulary set is added this month. Use this month only for review, project presentation, make-up, reflection, or administrative tasks if class meets.
