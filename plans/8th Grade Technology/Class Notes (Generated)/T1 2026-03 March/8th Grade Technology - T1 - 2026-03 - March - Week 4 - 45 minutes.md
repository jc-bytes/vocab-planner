## Class Objective

Edit a simple SVG property and explain how markup can describe an image.

## Pre-Activities

- Review Week 4 practice vocabulary (part 1). SVG: A file format for vector graphics markup: Text that describes structure or design tag: A markup label inside angle brackets Complete a short vocabulary check for SVG, markup, tag, attribute, and scalable. View a simple SVG code sample and circle repeated words or numbers.

## While Activities

- Edit one simple SVG property such as color, size, or position in a guided example. Compare the visual result before and after the change.

## Post-Activities

- Write one sentence explaining how markup can describe an image.
