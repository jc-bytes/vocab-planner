## Class Objective

Create basic vector shapes with fills and strokes and explain why vector graphics are useful for logos.

## Pre-Activities

- Sketch a simple environmental symbol using only basic shapes, such as a leaf, water drop, recycling arrow, sun, tree, or warning sign. Preview vector graphics by comparing a clean logo with a pixelated image and identify which one stays sharp when resized.

## While Activities

- Open Inkscape and create three simple shapes with different fills and strokes. Practice saving the file with your name.

## Post-Activities

- Save your practice file with your name. Write one sentence explaining why vector graphics are useful for logos.
