## Class Objective

Create a data chart with at least 6 potentiometer positions, analog readings, LED brightness observations, and one conclusion sentence about the relationship between input and output.

## Pre-Activities

- Review Week 5 practice vocabulary (part 2). variable: A value that can change in a program PWM: A fast on/off signal used to control brightness or speed brightness: How light or dark something is reading: A value measured by a sensor
- Complete a vocabulary match for analog input, ADC, potentiometer, variable, PWM, and brightness. Predict how turning the knob should change values.

## While Activities

- Complete Daily Grade #3: Create a data chart with at least 6 potentiometer positions, analog readings, LED brightness observations, and one conclusion sentence about the relationship between input and output.

## Post-Activities

- Submit the chart. Save one code value you changed successfully.
