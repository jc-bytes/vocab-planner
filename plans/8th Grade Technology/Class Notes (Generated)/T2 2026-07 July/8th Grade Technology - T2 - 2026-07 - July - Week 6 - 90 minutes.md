## Class Objective

Build or test an RGB LED circuit.

## Pre-Activities

- Review Week 6 practice vocabulary (part 2). bright: Giving a lot of light condition: A rule that can be true or false RGB: Red, green, and blue colors used to make other colors color mix: A color made by combining other colors
- Review red, green, blue, value, color mix, and output. Sketch a simple color signal system.

## While Activities

- Build or test an RGB LED circuit. Modify code values to create at least 4 colors. Write down the RGB combinations and what color you think it generated.
- Connect one color behavior to a potentiometer or sensor value.

## Post-Activities

- Record your favorite color setting and the values used.
