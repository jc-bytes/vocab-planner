## Class Objective

Write or modify conditional code that changes an output based on a sensor threshold.

## Pre-Activities

- Review Week 8 practice vocabulary (part 1). if/else: A code choice between two actions threshold: A limit where an action changes input: Information that goes into a system or program output: What a system or program produces Complete if/else sentence frames such as "If light is low, then..." and "If the button is pressed, then..."

## While Activities

- Write or modify conditional code that changes an output based on a sensor threshold. Test at least two threshold values.

## Post-Activities

- Record which threshold worked best and why.
