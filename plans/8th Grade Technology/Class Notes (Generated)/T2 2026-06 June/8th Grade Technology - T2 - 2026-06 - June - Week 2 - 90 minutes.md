## Class Objective

Build a button and LED circuit.

## Pre-Activities

- Review Week 2 practice vocabulary (part 2). output: What a system or program produces HIGH: An on or high signal LOW: An off or low signal button: A part the user can press
- Match input, output, pressed, not pressed, HIGH, and LOW with examples, such as button = input, LED = output, pressed = button is pushed, not pressed = button is released, HIGH = on, and LOW = off.
- Predict what should happen when the button is pressed.

## While Activities

- Build a button and LED circuit. Upload a guided button-control sketch. Test the button, fix connection mistakes, and record the input/output relationship.

## Post-Activities

- Submit the input/output relationship recorded. Write one sentence explaining the difference between input and output.
