## Class Objective

Create a campaign web page with HTML, CSS, image alt text, link, and source credit.

## Pre-Activities

- Review Week 7 practice vocabulary (part 2). list: A group of related items stored together link: A way to open a web page or file CSS: Code used to style a web page selector: CSS code that chooses what to style value: Information stored in a variable, cell, or program Complete a quick match for img, src, alt, CSS, selector, property, and value. Review how alt text helps accessibility.

## While Activities

- Complete Daily Grade #4: Create one campaign web page using HTML and CSS with a title, two sections, one image with alt text, one list, one link, three CSS style rules, and a short source credit.

## Post-Activities

- Save your files in the correct folder. Submit a screenshot and the HTML/CSS files or links requested in Classroom.
