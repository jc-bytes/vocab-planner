## Class Objective

Complete a programming setup and work habits checklist about preparation, focus, file organization, testing, respectful help, and safe computer use.

## Pre-Activities

- Review Week 4 practice vocabulary (part 2). string: Text stored in a program assignment: Giving a value to a variable input: Information that goes into a system or program Review variable, value, assignment, input, and output. Predict what a short program will display.

## While Activities

- Complete Appreciation Grade #1: Complete a programming setup and work habits checklist about preparation, focus, file organization, testing, respectful help, and safe computer use. Then write short programs that ask for a name or number, store it in a variable, and print a customized response.

## Post-Activities

- Save your best program. Write one sentence explaining what a variable stores.
