## Class Objective

Practice finding likely errors in a Python program with variables, if/else, and a loop before the graded debugging check.

## Pre-Activities

- Review Week 7 practice vocabulary (part 1). debug: To find and fix a problem colon: The two-dot punctuation mark used in Python blocks indentation: Spaces at the start of a code line comparison: Checking how two values are related Review common errors: missing colon, wrong indentation, wrong comparison, missing update, and variable name mismatch.

## While Activities

- Practice finding likely errors in a Python program with variables, if/else, and a loop before the graded debugging check.

## Post-Activities

- Compare one possible fix with a partner. Write the error type you will watch for next time.
