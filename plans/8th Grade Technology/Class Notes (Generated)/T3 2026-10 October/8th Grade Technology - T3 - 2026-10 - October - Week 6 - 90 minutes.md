## Class Objective

Complete a loops and debugging habits checklist about perseverance, careful testing, useful feedback, organized notes, and fixing mistakes.

## Pre-Activities

- Review Week 6 practice vocabulary (part 2). loop: Code that repeats counter: A variable used to count update: A change made during a loop or process while: A loop that repeats while a condition is true Complete a loop trace table for a short while loop. Identify the counter, condition, and update.

## While Activities

- Complete Appreciation Grade #2: Complete a loops and debugging habits checklist about perseverance, careful testing, useful feedback, organized notes, and fixing mistakes. Then build a small loop program that repeats until a condition is met.

## Post-Activities

- Record one bug that could cause a loop to run too long and one habit that helped you debug it.
