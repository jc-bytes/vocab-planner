## Class Objective

Write a Python program that asks for two numbers, calculates at least 3 results, displays labeled output, and includes one comment explaining the program purpose.

## Pre-Activities

- Review Week 5 practice vocabulary (part 2). calculate: To find an answer using math if/else: A code choice between two actions condition: A rule that can be true or false Sort conditions into true and false examples. Review greater than, less than, equal to, and not equal to.

## While Activities

- Complete Daily Grade #3: Write a Python program that asks for two numbers, calculates at least 3 results, displays labeled output, and includes one comment explaining the program purpose. Then create a Python decision program using if/else and test at least 4 inputs.

## Post-Activities

- Submit the code or screenshot. Write one test input that proved your program worked.
