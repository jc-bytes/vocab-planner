## Pre-Activities

- Review Week 4 practice vocabulary (part 1). algorithm: A clear set of steps to solve a problem program: Instructions a computer can run syntax: The exact rules for writing code print: A command that shows text output Match algorithm, program, syntax, output, print, and string with definitions. Put a simple recipe or school routine in correct step order, such as arrive to class, open file, enter input, run program, check output, and save work.

## While Activities
