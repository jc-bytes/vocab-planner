## Class Objective

Create a vocabulary table for these 10 words: decomposition, user, screen, event, input, output, app, button, variable, feedback.

## Pre-Activities

## While Activities

- Complete Daily Grade #1: Create a vocabulary table for these 10 words: decomposition, user, screen, event, input, output, app, button, variable, feedback. Then create a 3-screen app wireframe.

## Post-Activities

- Save or submit your wireframe. Write one change that would make the app easier to use.
