## Final Verification

- [ ] Student simulation completed.
- [ ] Teacher/substitute simulation completed.
- [ ] All files reopened after export.
- [ ] Presentation, directions, template, example, checklist, and scoring agree.
- [ ] Google Classroom instructions are paste-ready, contain no teacher placeholders, and name every required deliverable.
- [ ] Student-facing titles are short, literal, and easy to understand.
- [ ] Student directions pass the first-read test: first action, product, required parts, submission, and finish condition are obvious.
- [ ] Directions use familiar words, direct verbs, short sentences, and one main action per step.
- [ ] Necessary technical terms are explained before students must use them.
- [ ] The Classroom post, attachments, template, example, checklist, rubric DOCX, and Classroom rubric XLSX express one approved assignment specification.
- [ ] Every scored requirement appears in the Classroom directions; every required deliverable is scored or identified as a non-scored submission check.
- [ ] An absent student could complete and submit the task using only the Classroom post and attached student files.
- [ ] Rubric DOCX and Classroom XLSX have exact criterion, score-band, special-condition, and total-point parity.
- [ ] Classroom XLSX passes structural validation, contains zero formulas, and has been rendered and visually checked.
- [ ] Plan, package, and live module agree on ID, version, sections, track, timing, and evidence.
- [ ] Teacher-only materials are separated.
- [ ] All required artifacts are `Ready`.
