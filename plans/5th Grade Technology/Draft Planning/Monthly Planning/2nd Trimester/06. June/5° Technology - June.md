# 5th Grade Technology - June 2026

## Monthly Focus
June starts Trimester 2 with computer systems, input-process-output thinking, connected systems, and responsible web search. Lessons use sorting examples, system diagrams, search-result comparisons, and short quiz-style checks.

## Weekly Time
- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 hours
- Month plan weeks: 4

## Competences
- Explain simple computer systems using input, process, output, connection, user, and purpose.
- Use web search keywords responsibly and compare results with visible source clues.
- Record system diagrams, search choices, and quiz evidence in an organized way.

## Learning Objectives
- Sort examples into input, process, output, connection, and user categories.
- Draw system diagrams with at least input, process, output, user, and purpose labels.
- Choose useful web search results by checking keywords, source clues, result order, advertisements, and reliability.

## Learning Outcomes
- Complete Summative Activity #1: input-process-output sorting and system diagram.
- Complete Summative Activity #2: web search scenario quiz with short explanations.
- Complete formative sorting, drawing, search practice, source comparison, and peer discussion.

## Evaluation
- Summative Activity #1 in Week 2: input-process-output sorting and system diagram.
- Summative Activity #2 in Week 4: web search scenario quiz.
- All other June activities are formative sorting, drawing, search practice, and peer discussion.
