# 5th Grade Technology - September 2026

## Monthly Focus
September begins Trimester 3 with flat-file databases using data from the Interactive Routine STEM Project. Lessons use paper forms, cards, fields, records, sorting, and grouping before moving into computer-based data tasks.

## Weekly Time
- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 hours
- Month plan weeks: 3

## Competences
- Organize information with forms, fields, records, data cards, rows, columns, sorting, and grouping.
- Compare paper databases and computer-style tables using simple evidence.
- Answer questions from organized data using clear field, record, sort, group, filter, and value language.

## Learning Objectives
- Create data cards from a classroom-safe form and label fields and records.
- Sort and group data cards by different fields or values.
- Use a paper table or approved tool to search, filter, and answer simple data questions.

## Learning Outcomes
- Complete Summative Activity #1: STEM project fields, records, and sorting check.
- Complete formative paper database creation, card sorting, computer-style table practice, and search practice.
- Use database vocabulary in notebook evidence and short explanations.

## Evaluation
- Summative Activity #1 in Week 2: STEM project fields, records, and sorting check.
- All other September work is formative database practice, card sorting, discussion, and notebook evidence.
