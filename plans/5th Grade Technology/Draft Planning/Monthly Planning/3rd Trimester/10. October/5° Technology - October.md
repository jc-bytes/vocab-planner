# 5th Grade Technology - October 2026

## Monthly Focus
October finishes database selection and starts vector drawing. Lessons use organized data, simple charts, shapes, lines, color, layers, and grouping to make short visual products.

## Weekly Time
- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 hours
- Month plan weeks: 4

## Competences
- Use paper or approved database tools to answer questions and represent results with a simple chart.
- Use vector drawing or paper tool-card methods to create clear designs from shapes, lines, color, and layers.
- Revise data answers and vector designs using feedback, evidence, and simple design criteria.

## Learning Objectives
- Answer data questions by sorting or filtering at least two fields and creating one simple chart.
- Use or label vector tools such as shape, line, fill, color, select, resize, layer, group, and icon.
- Create a simple icon with required shapes, colors, grouping, and explanation sentences.

## Learning Outcomes
- Complete Summative Activity #2: database search and chart task.
- Complete Summative Activity #3: vector tool and simple icon check.
- Complete formative data practice, vector drawing practice, peer feedback, revision, and product preparation.

## Evaluation
- Summative Activity #2 in Week 4: database search and chart task.
- Summative Activity #3 in Week 6: vector tool and simple icon check.
- All other October work is formative data practice, drawing practice, peer feedback, and revision.
