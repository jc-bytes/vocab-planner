# 5th Grade Technology - March 2026

## Monthly Focus
March introduces the technology lab routine, safe robotics habits, robot parts, and simple robot instructions. The month keeps robotics concrete and visual so students can name parts, organize materials, and explain simple actions before building more complex mechanisms.

## Weekly Time
- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 hours
- Month plan weeks: 4

## Competences
- Follow safe technology lab routines while handling robot pictures, cards, and approved parts responsibly.
- Identify common robot parts and explain their jobs using simple input, process, output, power, and movement language.
- Create simple command sequences, path maps, drawings, and observation notes with clear evidence.

## Learning Objectives
- Name and label robot parts such as sensor, motor, controller, wheel, wire, frame, switch, and power source.
- Sort robot parts by input, movement, control, power, and output.
- Create a robot path map with commands, arrows, start/end points, one obstacle, and prediction sentences.

## Learning Outcomes
- Complete Summative Activity #1: robot parts labeling diagram with part names and function sentences.
- Complete Summative Activity #2: robot path map with commands, arrows, obstacle, and predictions.
- Complete formative lab routines, safe handling practice, component observations, and notebook corrections.

## Evaluation
- Summative Activity #1 in Week 2: robot parts labeling diagram.
- Summative Activity #2 in Week 3: robot path map with commands.
- All other March activities are formative practice, discussion, drawing, sorting, and notebook checks.
