# 9th Grade Technology - September 2026

## Monthly Focus
Students start the STEM trimester by connecting digital representation, sound, image data, and STEM project thinking. The month gives students vocabulary and short experiments they can later use in a STEM project logbook.

## Weekly Time
- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 135 minutes

## Competences

- • Explain how images, sounds, symbols, samples, and data can be represented digitally.
- • Use media representation vocabulary in practical image, sound, and STEM brainstorming tasks.
- • Document early STEM project ideas in a logbook connected to a real problem and possible data.

## Learning Objectives

- • Calculate or describe simple image and sound representation examples using pixel/sample vocabulary.
- • Use sound or image tools to test quality, data size, and file-size tradeoffs.
- • Brainstorm STEM project ideas connected to a real problem, image/sound/sensor data, and evidence.

## Learning Outcomes

- • Complete a digital media vocabulary table with representation terms and examples.
- • Complete an image/sound representation check with simple calculations or explanations.
- • Submit early STEM project brainstorm/logbook evidence connected to a real problem.

## Evaluation
- Daily Grade #1 in Week 1: audiovisual vocabulary table.
- Daily Grade #2 in Week 2: image/sound representation check.

## Vocabulary Plan
### Trimester 3 Summative Vocabulary

Used for Daily Grade #1 as the trimester vocabulary table. Week 1 does not need a separate practice vocabulary because these 10 words are the vocabulary focus.

STEM, pixel, resolution, color depth, sample, sensor, file size, quality, compression, RGB

### Practice Vocabulary

#### Week 2: Sound Quality

| Word | Simple Definition |
| --- | --- |
| sample rate | How often sound is measured each second. |
| sample size | How much detail each sound sample stores. |
| microphone | A device that captures sound. |
| speaker | A device that produces sound. |
| sound quality | How clear or accurate sound is. |
| audio | Sound stored or played by a device. |
| file setting | An option that changes how a file is saved. |
