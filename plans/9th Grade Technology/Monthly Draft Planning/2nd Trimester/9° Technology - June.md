# 9th Grade Technology - June 2026

## Monthly Focus
Students begin the data trimester by reviewing Python sequences and using lists, strings, conditions, and loops to process small sets of information. The goal is to make programming useful for later data collection and analysis.

## Weekly Time
- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 135 minutes

## Competences

- Write and test Python programs that use sequences, lists, loops, strings, and simple data operations.
- Debug loop and list behavior using indexes, conditions, counters, trace tables, and expected results.
- Connect programming structures to data science tasks such as storing, organizing, and describing data.

## Learning Objectives

- Create and modify Python lists by accessing, changing, and appending related items.
- Use while loops and for loops with lists to repeat actions and process data safely.
- Debug loop errors and use strings as data for simple mini-programs and data science examples.

## Learning Outcomes

- Complete a Python lists and core vocabulary task with school-related data examples.
- Complete a loop debugging quiz-style check using trace evidence and corrections.
- Create a mini Python program that uses sequences, lists or strings, and a simple explanation.

## Evaluation
- Daily Grade #1 in Week 1: Python and data vocabulary table.
- Daily Grade #2 in Week 3: loop debugging quiz-style check.
