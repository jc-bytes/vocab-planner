# Grade 9 Technology — Third Trimester Readiness Audit

Status: **Ready for classroom use, with pilot monitoring for web modules.**

## Completion

- Assessment count: 5 daily grades, 2 appreciation grades, and 1 exam project.
- Module coverage: digital representation and cybersecurity risk.
- STEAM: two common work weeks and expo assessment; no separate STEAM module.
- Evidence rule: saved files, share links, exported reports, typed test logs, teacher observation, and live demonstrations. No phone photography.
- Scoring: current 40-point daily/appreciation rubrics and 90-point exam packet; Google Classroom import workbooks are paired with the scoring rubrics.
- Delivery: monthly DOCX plans and class notes are synchronized with the current sequence.

## Pilot controls

The web modules are version `v0.1.0`. Each includes repeated practice, progress export, a teacher guide, and a printable fallback. The teacher should record timing and wording issues during the first run before promoting the modules beyond pilot status.
