# 9th Grade Technology - Simple Classroom Progress

This file explains the year in simple classroom sentences. It is meant for quick teacher review, parent-friendly explanation, or student-facing overview.

## 1st Trimester

### March

- Week 1, Class 1: First, students work on Physical computing systems. They sort devices into input, process, and output parts without adding a separate vocabulary table.
- Week 1, Class 2: Then, students work on lab safety, system maps, and the Trimester 1 summative vocabulary. They complete Daily Grade #1: Create a vocabulary table with definition, illustration, and example sentence for these 10 words: input, process, output, system, device, circuit, sketch, upload, debug, test. They also create a system map for a simple electronic device.
- Week 2, Class 1: Then, students work on Digital and analog signals. They create an input-process-output diagram for one physical computing system.
- Week 2, Class 2: Then, students work on LED blink and program structure. They upload or run a basic blink program.
- Week 3, Class 1: Then, students work on Vocabulary and debugging routine. They practice the lab safety and responsibility checklist before the graded reflection.
- Week 3, Class 2: Then, students work on Mini LED control practice. They complete Appreciation Grade #1: Complete the lab safety and responsibility checklist about preparation, careful material use, listening, cleanup, and persistence during testing. They also build a simple LED control circuit with the Arduino/Freenove kit.

### April

- Week 4, Class 1: Then, students work on Button input. They practice building or tracing a button-input system and draft the explanation before the graded practical check.
- Week 4, Class 2: Then, students work on Toggle control. They complete Daily Grade #2: Build a button-input system with the Arduino/Freenove kit that turns one LED on and off. They also modify the button program so each press changes the LED state.
- Week 5, Class 1: Then, students work on Serial monitor. They run a program that sends text or sensor values to the serial monitor.
- Week 5, Class 2: Then, students work on Analog input with potentiometer. They connect the analog input.
- Week 6, Class 1: Then, students work on Sensor threshold quiz-style check. They practice reading sensor values, choosing a threshold, and predicting expected outputs before the graded threshold check.
- Week 6, Class 2: Then, students work on RGB output and state colors. They complete Daily Grade #3: Complete a quiz-style sensor threshold check with 6 readings, one chosen threshold, the expected output for each reading, and a 2-sentence explanation of the rule. They also program RGB states for ready, active, warning, and error.
- Week 7, Class 1: Then, students work on Addressable LEDs and animation. They create a simple addressable LED light pattern with at least 3 colors and 2 speed settings.
- Week 7, Class 2: Then, students work on Team robotics practice. They complete Appreciation Grade #2: Complete the teamwork and feedback checklist about communication, shared responsibility, respectful testing, organization, and response to feedback while improving a light/sound system.
- Week 8, Class 1: Then, students work on State logic chart. They practice planning states, triggers, output responses, and explanations before the graded chart.
- Week 8, Class 2: Then, students work on Integrated input-output prototype. They complete Daily Grade #4: Create a state logic chart with 4 states, the input that triggers each state, the output response, and one explanation sentence for each row. They also combine at least one input and two outputs into a prototype.

### May

- Week 9, Class 1: Then, students work on Robotics project planning. They practice outlining a robotics design plan before the graded design plan.
- Week 9, Class 2: Then, students work on Prototype rehearsal. They complete Daily Grade #5: Create a robotics design plan with a project goal, 2 inputs or controls, 2 outputs, a state chart, a component list, and 3 testing steps. They also build a practice version of one project feature.
- Week 10, Class 1: Then, students work on Exam project setup. They begin Exam Project: Build the first working feature of their robotics project and record the input, output, and state logic in the project log.
- Week 10, Class 2: Then, students work on Exam project build. They continue Exam Project: Build the main robotic behavior, test each subsystem, debug wiring or code, and document at least 2 test results.
- Week 11, Class 1: Then, students work on Exam project testing. They continue Exam Project: Complete controlled testing with at least 5 test attempts and record pass/fail results plus fixes.
- Week 11, Class 2: Then, students work on Exam project improvement. They continue Exam Project: Improve reliability, clean the build, organize code comments, and prepare a 1-minute explanation of goal, inputs, outputs, and logic.
- Week 12, Class 1: Then, students work on Presentation rehearsal. They rehearse the robotics demonstration and draft the short reflection so the final presentation is ready for the 90-minute class.
- Week 12, Class 2: Then, students work on Robotics project presentations. They complete Exam Project Presentation: Demonstrate the working robotics project, explain the goal, inputs, outputs, state logic, testing evidence, and improvement made.
- Week 13, Class 1: Then, students work on Exam/admin buffer. They complete make-up tasks, organize files, or finish trimester exam/admin requirements as directed.
- Week 13, Class 2: Then, students work on Exam/admin buffer. They complete exam, make-up, reflection, or administrative tasks for the trimester.

## 2nd Trimester

### June

- Week 1, Class 1: Then, students work on Python sequence review. They create and modify a Python list without adding a separate vocabulary table.
- Week 1, Class 2: Then, students work on lists for real data and the Trimester 2 summative vocabulary. They complete Daily Grade #1: Create a vocabulary table with definition, illustration, and example sentence for these 10 words: Python, list, item, index, string, loop, condition, data, value, output. They also build a program that stores real data in a list.
- Week 2, Class 1: Then, students work on While loops. They trace a while loop and identify the condition, repeated action, and stopping point.
- Week 2, Class 2: Then, students work on For loops with lists. They create a for loop that checks each value in a list and counts, filters, or labels the items.
- Week 3, Class 1: Then, students work on Loop debugging quiz-style check. They practice correcting loop errors and explaining fixes before the graded debugging check.
- Week 3, Class 2: Then, students work on Strings as data. They complete Daily Grade #2: Complete a quiz-style debugging check by correcting a Python loop program with 4 marked issues. They also write programs that count characters, search for letters, and check whether a word contains a pattern.

### July

- Week 4, Class 1: Then, students work on Mini program with sequences. They create a small text or number analysis program that uses a list, a loop, and one condition.
- Week 4, Class 2: Then, students work on From programming to data science. They use a small dataset to make observations.
- Week 5, Class 1: Then, students work on Data collection plan. They practice drafting a data collection plan before the graded plan.
- Week 5, Class 2: Then, students work on Collect and organize data. They complete Daily Grade #3: Create a data collection plan with 1 question, 5 survey or measurement items, expected data type for each item, collection method, and one privacy rule. They also collect or enter a small dataset.
- Week 6, Class 1: Then, students work on Data cleaning habits. They practice cleaning the assigned dataset and recording changed values before the graded checklist.
- Week 6, Class 2: Then, students work on Tinkercad data model intro. They complete Appreciation Grade #1: Complete the collaboration checklist about responsibility, respectful communication, shared work, data care, and persistence while cleaning the assigned dataset. They also create a simple Tinkercad model that represents one category, object, or display idea from their data topic.
- Week 7, Class 1: Then, students work on Charts and patterns. They practice creating a chart and drafting interpretation sentences before the graded chart check.
- Week 7, Class 2: Then, students work on Correlation and outliers. They complete Daily Grade #4: Create one chart from a dataset and write 4 interpretation sentences: one pattern, one comparison, one outlier or limitation, and one conclusion. They also analyze a dataset for patterns, outliers, and possible correlation.

### August

- Week 8, Class 1: Then, students work on Data conclusions. They practice drafting a one-page data report before the graded report draft.
- Week 8, Class 2: Then, students work on Data product prototype. They complete Daily Grade #5: Create a one-page data report draft with title, question, chart, 3 evidence statements, 1 limitation, and 1 recommendation. They also build a prototype for their data product.
- Week 9, Class 1: Then, students work on Project readiness. They discuss examples of effort, organization, responsible data use, deadlines, and response to feedback before the graded self-reflection.
- Week 9, Class 2: Then, students work on Data project planning. They complete Appreciation Grade #2: Complete a self-reflection about effort, organization, responsible data use, meeting deadlines, and how students responded to feedback. They also create the data exam project plan with project question, dataset source, chart plan, product format, task list, and presentation outline.
- Week 10, Class 1: Then, students work on Exam project setup. They begin Exam Project: Finalize the dataset, clean remaining errors, and confirm the chart or visualization students will use.
- Week 10, Class 2: Then, students work on Exam project build. They continue Exam Project: Build the data product with at least one chart, evidence statements, and a clear design. Add a Tinkercad model/mock-up only if it supports the data story.
- Week 11, Class 1: Then, students work on Exam project testing. They continue Exam Project: Test clarity, fix labels, check calculations, and revise the conclusion so it matches the evidence.
- Week 11, Class 2: Then, students work on Exam project finalization. They continue Exam Project: Finish the product, prepare a 1-2 minute explanation, add a short reflection about data quality and limitations, and check all links/files.
- Week 12, Class 1: Then, students work on Presentation rehearsal. They rehearse the data project explanation and draft the final reflection so the formal demonstration is ready for the 90-minute class.
- Week 12, Class 2: Then, students work on Data project presentations. They complete Exam Project Presentation: Present the data question, method, chart, conclusion, limitation, recommendation, and final product.

## 3rd Trimester

### September

- Week 1, Class 1: Then, students work on STEM and digital media launch. They brainstorm STEM project ideas without adding a separate vocabulary table.
- Week 1, Class 2: Then, students work on A splash of colour and the Trimester 3 summative vocabulary. They complete Daily Grade #1: Create a vocabulary table with definition, illustration, and example sentence for these 10 words: STEM, pixel, resolution, color depth, sample, sensor, file size, quality, compression, RGB. They also create or inspect a small pixel image.
- Week 2, Class 1: Then, students work on Sound representation. They practice image and sound representation questions before the graded check.
- Week 2, Class 2: Then, students work on Sonic playground. They complete Daily Grade #2: Answer a 10-item image and sound representation check covering pixel, resolution, color depth, sample rate, sample size, microphone, speaker, file size, quality, and compression. They also use Audacity or an approved web audio tool to compare two sample rates or file settings.

### October

- Week 3, Class 1: Then, students work on You and your data. They analyze 4 online-service scenarios and identify what data is collected, why it matters, and one safer choice.
- Week 3, Class 2: Then, students work on Social engineering. They analyze social engineering messages.
- Week 4, Class 1: Then, students work on Digital responsibility habits. They practice the collaboration and digital responsibility checklist before the graded checklist.
- Week 4, Class 2: Then, students work on Script kiddies and malware. They complete Appreciation Grade #1: Complete the collaboration and digital responsibility checklist about respectful communication, source care, privacy, participation, and safe account behavior. They also research or inspect short case summaries of cyber attacks.
- Week 5, Class 1: Then, students work on Cyber security scenario quiz. They practice identifying threats, choosing protections, and justifying answers before the graded scenario quiz.
- Week 5, Class 2: Then, students work on Risk and impact. They complete Daily Grade #3: Complete a 12-question scenario quiz where students identify the threat, choose the best protection, and justify 3 answers with one sentence each. They also compare security threats by probability and impact.
- Week 6, Class 1: Then, students work on STEM project problem selection. They choose one STEM project problem and identify users, constraints, possible data, and possible prototype tools such as Tinkercad, Arduino/Freenove when electronics are needed, or Google Classroom resources.
- Week 6, Class 2: Then, students work on STEM prototype planning. They complete Appreciation Grade #2: Complete a self-reflection about effort, organization, safe material use, perseverance, and how students responded to feedback during STEM planning. They also create a first STEM project plan with goal, roles, materials, digital tools, sketch or Tinkercad concept, and 3 planned tests.
- Week 7, Class 1: Then, students work on Risk map final. They practice creating a risk map before the graded map.
- Week 7, Class 2: Then, students work on STEM design refinement. They complete Daily Grade #4: Create a risk map with 6 risks, probability rating, impact rating, protection strategy, and one priority recommendation paragraph. They also revise the STEM project plan.

### November

- Week 8, Class 1: Then, students work on STEM proposal. They practice drafting a STEM project proposal before the graded proposal.
- Week 8, Class 2: Then, students work on Prototype practice. They complete Daily Grade #5: Create a STEM project proposal with problem, users, goal, tools/platforms, sketch or Tinkercad concept, materials, 3 test criteria, and expected evidence. They also build a practice prototype feature using the approved platform for their project.
- Week 9, Class 1: Then, students work on Project habits review. They review the Week 6 reflection, Week 8 proposal, logbook evidence, materials, safe work habits, and make-up needs before the final exam project begins.
- Week 9, Class 2: Then, students work on Exam project planning. They create the final exam project task list, team roles, build schedule, testing plan, and presentation outline. This class is for make-up evidence and project preparation, not a new formal summative.
- Week 10, Class 1: Then, students work on Exam project setup. They begin Exam Project: Build the first feature or model section and record the goal, tool used, and first test result.
- Week 10, Class 2: Then, students work on Exam project build. They continue Exam Project: Build the main prototype or digital product, test each feature, debug issues, and record at least 2 results with photos/screenshots.
- Week 11, Class 1: Then, students work on Exam project testing. They continue Exam Project: Complete controlled testing, identify one weakness, and record the evidence that proves the weakness.
- Week 11, Class 2: Then, students work on Exam project improvement. They continue Exam Project: Improve the prototype, clean the model or code, update the logbook, and prepare a 1-2 minute explanation of problem, design, tests, and improvement.

### December

- Week 12, Class 1: Then, students work on Presentation rehearsal. They rehearse the STEM project demonstration and draft the final reflection so the formal presentation is ready for Class 2.
- Week 12, Class 2: Then, students work on STEM project presentations. They complete Exam Project Presentation: Present the STEM project, demonstrate the product, explain the problem, tools, design choices, testing evidence, improvement, and reflection.
- Week 13, Class 1: Then, students work on Exam/admin buffer. They complete make-up evidence, final exam tasks, reflection corrections, or administrative requirements as directed.
- Week 13, Class 2: Then, students work on Exam/admin buffer. They complete final exam, make-up, portfolio organization, or course closure tasks as directed.
