## Class Objective

Create a for loop that checks each value in a list and counts, filters, or labels the items, such as counting scores above 70, filtering names that start with A.

## Pre-Activities

- Review Week 2 practice vocabulary (part 2). display: To show information while loop: A loop that repeats while a condition is true stopping point: The condition that makes a loop end
- Predict what a for loop prints when it reads a list of 5 items.

## While Activities

- Create a for loop that checks each value in a list and counts, filters, or labels the items, such as counting scores above 70, filtering names that start with A, or labeling values high/low. Test the program with two data sets.

## Post-Activities

- Compare for loops and while loops in two sentences.
