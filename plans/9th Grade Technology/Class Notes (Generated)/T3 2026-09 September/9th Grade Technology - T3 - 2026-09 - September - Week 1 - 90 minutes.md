## Class Objective

Create a vocabulary table for these 10 words: STEM, pixel, resolution, color depth, sample, sensor, file size, quality, compression, RGB.

## Pre-Activities

- Preview the 10 Trimester 3 vocabulary words. Match RGB color examples with red, green, and blue intensity values, such as red = 255,0,0 and yellow = 255,255,0.

## While Activities

- Complete Daily Grade #1: Create a vocabulary table for these 10 words: STEM, pixel, resolution, color depth, sample, sensor, file size, quality, compression, RGB. Then inspect a small pixel image and compare quality/file-size tradeoffs.

## Post-Activities

- Add one image-representation note to the STEM logbook.
