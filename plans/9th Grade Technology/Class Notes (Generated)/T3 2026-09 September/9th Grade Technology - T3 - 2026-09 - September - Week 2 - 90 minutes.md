## Class Objective

Complete an image and sound representation check using pixel, resolution, color depth, sample rate, and compression vocabulary.

## Pre-Activities

- Review Week 2 practice vocabulary (part 2). sound quality: How clear or accurate sound is audio: Sound stored or played by a device file setting: An option that changes how a file is saved

## While Activities

- Complete Daily Grade #2: Answer a 10-item image and sound representation check covering pixel, resolution, color depth, sample rate, sample size, microphone, speaker, file size, quality, and compression. Then use Audacity or an approved web audio tool to compare two sample rates or file settings.
