## Class Objective

Read potentiometer values and use analog input ranges to control LED brightness.

## Pre-Activities

- Review Week 5 practice vocabulary (part 2). analog input: A changing sensor value read by a board potentiometer: A knob that changes an analog value brightness: How light or dark something is

## While Activities

- Inspect a potentiometer setup and predict low, medium, and high values.
- Fill in the worksheet with the identified values.
- Use the potentiometer as analog input. Read values on the Serial Monitor and use the readings to control PWM LED brightness.
- Describe the LED brightness for low, medium, and high readings, justify the ranges you chose, and explain which range gives the most reliable control.

## Post-Activities

- Submit your value table and explain which value made the brightest output.
