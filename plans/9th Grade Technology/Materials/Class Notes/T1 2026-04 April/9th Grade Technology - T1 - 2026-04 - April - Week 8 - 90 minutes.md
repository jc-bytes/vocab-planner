## Class Objective

Build an input-output prototype, test two cases, and record evidence-based improvements.

## Pre-Activities

- Review Week 8 practice vocabulary (part 2). prototype: An early version used for testing project log: A record of project work and tests improvement: A change that makes something better
- Review the project criteria for a small robotic behavior.

## While Activities

- Complete Daily Grade #4: Create a state logic chart with 4 states, the input that triggers each state, the output response, and one explanation sentence for each row. Then combine at least one input and two outputs into a prototype, test two cases, and record two evidence-based improvements in your group project log.

## Post-Activities

- Demonstrate the prototype behavior and submit the project log.
