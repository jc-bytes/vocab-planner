## Class Objective

Use Serial Monitor messages and sensor values to support debugging and explain program output.

## Pre-Activities

- Review Week 5 practice vocabulary (part 1). serial monitor: A tool that shows messages from a program baud rate: The speed used for serial messages data: Facts or values that can be used or studied message: Information sent or shown
- Open the sample data message found in Google Classroom and predict what value will change.

## While Activities

- Run a program that sends text and sensor values to the Serial Monitor. Change one message, such as Sensor ready or Value changed, upload the code again, and explain how the changed output helps confirm the program is running correctly.
- Identify the baud rate, data, message, and output in the Arduino interface, then record one example of serial data that could support debugging.
- Fill in the worksheet with the identified values.

## Post-Activities

- Write one reason serial data helps during testing.
