## Class Objective

Plan a state logic chart with states, input triggers, output responses, and explanations.

## Pre-Activities

- Review Week 8 practice vocabulary (part 1). state logic: Rules for how a system changes between states input trigger: An input that starts a response output response: What the system does after an input
- Review ready, active, warning, and error as possible robot states.

## While Activities

- Practice planning a state logic chart with states, triggers, output responses, and explanation sentences before the graded chart.
- Use one example row such as ready, button pressed, green LED on, system starts.

## Post-Activities

- Circle the state that would be hardest to program and explain why.
