## Class Objective

Create a vocabulary table for these 10 words: Python, list, item, index, string, loop, condition, data, value, output.

## Pre-Activities

- Predict the output of 3 short list examples, including one access example, one change example, and one append example.

## While Activities

- Complete Daily Summative #1: Create a vocabulary table for these 10 words: Python, list, item, index, string, loop, condition, data, value, output.
- Then build a program that stores real data in a list.

## Post-Activities

- Submit one before/after list example and explain which method changed it.
