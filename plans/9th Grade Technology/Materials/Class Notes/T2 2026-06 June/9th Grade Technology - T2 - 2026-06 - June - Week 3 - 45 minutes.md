## Class Objective

Practice correcting loop errors and explaining fixes before the graded debugging check.

## Pre-Activities

- Review Week 3 practice vocabulary (part 1). for loop: A loop that repeats for each item in a group count: To find how many there are filter: To show or use only items that match a rule label: A name or short description
- Read a short broken loop and predict the error.

## While Activities

- Practice correcting loop errors and explaining fixes before the graded debugging check. Use examples such as missing colon, wrong indentation, condition that never stops, or wrong list index.

## Post-Activities

- Choose the most common loop error and write how to avoid it.
