## Class Objective

Complete a quiz-style debugging check by correcting a Python loop program with 4 marked issues.

## Pre-Activities

- Review Week 3 practice vocabulary (part 2). debugging: Finding and fixing problems character: One letter, number, space, or symbol in text length: How many items or characters something has substring: A smaller part of a string
- Match these words with examples: string, character, index, length, substring.

## While Activities

- Complete Daily Summative #2: Complete a quiz-style debugging check by correcting a Python loop program with 4 marked issues. Submit the corrected code, output, and one sentence explaining each fix. Then write programs that count characters, search for letters, and check whether a word contains a pattern.

## Post-Activities

- Submit your strongest string example and explain what it checks.
