## Class Objective

Upload and modify a blink program, test delay values, and explain how delay changes LED behavior.

## Pre-Activities

- Review Week 2 practice vocabulary (part 2). blink: To turn on and off setup: The part of a program that runs first loop: Code that repeats delay: A pause in a program Predict what happens when a delay value gets larger or smaller.

## While Activities

- Use your vocabulary table as a technical reference while testing the LED program.
- Upload and run the basic blink program found in Google Classroom. Identify setup, loop, comments, output pin, and delay, then predict the effect of one code change before testing it.
- Modify delay values three times, such as 200 ms, 500 ms, and 1000 ms. Record expected behavior, actual behavior, and one conclusion in the test table from Google Classroom.

## Post-Activities

- Explain how delay changes the LED behavior.
