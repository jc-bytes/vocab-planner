## Class Objective

Complete core vocabulary and create a physical computing system map with input, process, output, and response.

## Pre-Activities

- Review these lab rules: keep liquids away, handle parts gently, connect power last, test only in the assigned area, and clean up parts. Preview the 10 vocabulary words.

## While Activities

- Complete Daily Grade #1: Create a vocabulary table for these 10 words: input, process, output, system, device, circuit, sketch, upload, debug, test.
- Create a system map for a simple electronic device, such as an automatic door or motion light, with input, process, output, state, and response arrows. Add one sentence explaining the system decision.

## Post-Activities

- Submit the system map and write one lab habit you need to practice.
