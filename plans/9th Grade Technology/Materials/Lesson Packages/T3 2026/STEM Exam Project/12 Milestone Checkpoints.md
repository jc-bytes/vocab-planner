## Stop-and-fix rules

- If the goal or criteria cannot be measured, revise them before building more.
- If the teacher cannot open the file or link, the milestone is not complete.
- If test conditions change between trials, explain the change or run a controlled set again.
- If the improvement is not connected to evidence, identify the weakness before revising.
- If hardware or software fails, move to the approved offline path and keep recording comparable evidence.
