# Daily Grade 5: STEM System Proposal

Grade 9 Technology · Trimester 3 · 40 points  
Scheduled: 9A and 9B Monday, November 16

## Use these files

1. `../Assessment Sources and Templates/05 STEM Proposal Option Cards.md`
2. `../Assessment Sources and Templates/06 STEM Proposal Template.md`

The teacher assigns Option A, B, C, or D. The option card supplies the problem, users, product choices, three test inputs, and knowledge source. Complete the named template. Do not select a different topic or search the internet unless the teacher writes an approved change on the proposal.

## Task

Complete every field in the proposal template. It has these nine sections.

1. Specific problem and intended users
2. Testable project goal
3. Product and teacher-approved tool
4. Main feature or model concept
5. Materials and school-approved accounts
6. Labeled concept sketch, flow, or layout
7. Three measurable success criteria
8. Evidence plan naming the v1 file, final file, dated logbook, three typed test rows, before/after comparison, and live demonstration
9. One realistic limitation or constraint

## Finish checklist

- [ ] The assigned option letter, fixed problem, and users are named.
- [ ] The problem, users, and goal agree.
- [ ] The design is realistic for the available time and tools.
- [ ] The concept sketch or flow is labeled.
- [ ] Criteria `C1–C3` use the three required test inputs and name visible or numeric pass rules.
- [ ] The evidence plan uses saved computer work, typed records, or live teacher observation.
- [ ] The proposal is named `9_-LastName-DG5-Proposal` and submitted as `.docx`, `.pdf`, or the teacher-provided Google Docs file; or the printed fallback is complete.

Scoring tool: `../../../../Assessments/Rubrics/IIIT/Daily/9th grade - IIIT - 2026-11-16 - Daily Grade 5 - STEM System Proposal.docx`
