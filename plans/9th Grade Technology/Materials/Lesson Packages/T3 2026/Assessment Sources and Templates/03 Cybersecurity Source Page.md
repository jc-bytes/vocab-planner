# Cybersecurity source page

Use this page for Daily Grades 3 and 4. You do not need to search the internet or test a real attack.

Module: `MOD-CYBERSECURITY-RISK-01 v0.1.0`

## Words taught in class

| Word | Meaning |
|---|---|
| asset | Something valuable that should be protected, such as an account, file, device, service, or personal information. |
| threat | Something that could cause harm. |
| vulnerability | A weakness that makes harm more likely. |
| protection | An action or control that reduces a risk. |
| phishing | A fake message or page designed to make a person reveal information or open something unsafe. |
| brute-force attack | Repeated password guesses until one works. |
| malware | Harmful software. Ransomware, trojans, and worms are malware families. |
| ransomware | Malware that blocks or encrypts files and demands payment. |
| trojan | Malware hidden inside something that appears safe or useful. |
| worm | Malware that copies itself and spreads between devices. |
| DDoS | Many devices or requests overwhelm a service so real users cannot access it. |
| firewall | A control that filters network traffic using rules. |
| verified update | An update from an approved source that repairs known weaknesses. |
| MFA | A second form of verification in addition to a password. |
| backup | A separate saved copy used to recover lost or damaged work. |
| data minimization | Keeping only the personal data that is truly needed. |

## Safe response rules

- Do not open suspicious links, files, or downloads.
- Do not enter real passwords or personal information into a practice task.
- Verify a message using the official school site or a trusted adult.
- Report the problem to the responsible adult or system administrator.
- Match the protection to the clue in the scenario. Do not blame the person who received the message.

Review sections `THREAT-LEARN-01`, `THREAT-PRACTICE-01`, `RISK-LEARN-01`, `RISK-PRACTICE-01`, `PROTECTION-LEARN-01`, and `PROTECTION-PRACTICE-01`.
