## Formulas taught and allowed

- Number of pixels = width × height
- Uncompressed image data in bits = width × height × color depth
- Uncompressed mono sound data in bits = sample rate × sample size × duration in seconds

## Meaning of each value

- Width and height are measured in pixels.
- Color depth is measured in bits per pixel.
- Sample rate is measured in samples per second or hertz (Hz).
- Sample size is measured in bits per sample.
- Duration is measured in seconds.

## How to show work

Write the formula with the given numbers, calculate the result, and include the unit. Example structure: `width × height = ___ pixels`. The check uses the same formulas and concepts as the module practice. It does not require a different formula.
