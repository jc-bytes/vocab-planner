# Representation vocabulary source

Use this page for representation vocabulary practice before Daily Grade 1. You do not need to search the internet.

The words and examples come from `MOD-DIGITAL-REPRESENTATION-01 v0.1.0`, sections `IMAGE-LEARN-01` and `SOUND-LEARN-01`.

| Term | Meaning taught in class | Example you may study |
|---|---|---|
| pixel | One small color square in a digital image. | A 10 × 8 image has 80 pixels. |
| resolution | The number of pixels across and down an image. | 1920 × 1080 is a resolution. |
| color depth | The number of bits used to store the color of one pixel. | An image may use 8 bits per pixel. |
| RGB | A color model that mixes red, green, and blue values. | Red 255, green 0, blue 0 makes bright red. |
| sample | One recorded measurement of a sound wave. | A microphone takes many samples each second. |
| sample rate | The number of sound samples recorded each second. | 8,000 samples per second is an 8,000 Hz sample rate. |
| sample size | The number of bits used to store one sound sample. | A recording may use 8 bits per sample. |
| microphone | An input device that changes sound into data the computer can record. | A microphone records a voice. |
| speaker | An output device that changes stored sound data into sound we can hear. | A speaker plays the recording. |
| compression | A method that reduces the amount of data needed to store or send a file. | Compressing audio can make the file smaller but may remove detail. |

## Two relationships you practiced

- More pixels or more bits per pixel usually increase image detail and file size.
- More samples per second or more bits per sample usually increase sound detail and file size.

Write definitions in your own clear words. Do not copy this table sentence by sentence.
