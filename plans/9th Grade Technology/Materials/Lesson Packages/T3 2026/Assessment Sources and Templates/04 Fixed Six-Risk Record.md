# Fixed six-risk record

Use these six records for Daily Grade 5. Do not invent new risks and do not search the internet.

| ID | Fixed record |
|---|---|
| R1 | A shared attendance account uses the password `school123`. Unknown logins have appeared. The account contains student records. |
| R2 | Fake school-login messages arrive every week. The real school account already has MFA enabled. |
| R3 | An offline practice laptop contains no personal data and is reset at the end of each day. |
| R4 | A library computer has missed verified updates for six months. Students use it to download email attachments. |
| R5 | The public school website had one short outage last year. It stores no student records. |
| R6 | A project folder has no backup. A student accidentally deletes a file about once each month. |

For each record, identify the asset, threat or harmful event, vulnerability or existing protection, probability, impact, and one practical protection. Base every rating on a fact in the record. Use only `low` or `high` for probability and impact.

These are the same `R1–R6` records used in `MOD-CYBERSECURITY-RISK-01 v0.1.0`, section `RISK-RECORD-01`.
