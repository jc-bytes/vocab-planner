# Grade 9 Technology, Trimester 3 exit and review bank

Use one exit prompt at the end of an instructional or work class. Use the review sets before the matching formal task. Students answer on paper or in the teacher-approved class form.

## Exit prompts

1. Write one RGB value and name the color it represents.
2. Explain why doubling both image dimensions creates four times as many pixels.
3. State the difference between sample rate and sample size.
4. Name one media setting that can change quality and file size.
5. Write one exact clue that indicates phishing.
6. Explain the difference between a threat and a vulnerability.
7. Name one probability fact and one impact fact from today's scenario.
8. Rewrite “be safe online” as a specific protection.
9. State one measurable test criterion for your project.
10. Write the expected result and actual result from today's test.
11. Name one weakness proved by testing evidence.
12. Explain what changed after feedback or testing.
13. State your presentation role and first sentence.
14. Name one saved file or typed record the teacher can check.

## Review set A: digital representation

1. Define pixel, resolution, color depth, sample, sample rate, sample size, compression, RGB, file size, and quality.
2. Calculate the pixel count for 15 × 12.
3. Calculate uncompressed image data for 180 pixels at 8 bits per pixel.
4. Calculate a 2-second mono sound at 12 samples per second and 4 bits per sample.
5. Explain one quality-size trade-off for an image and one for sound.
6. Explain what a microphone does and what a speaker does.

## Review set B: cybersecurity scenarios

For each term, write a clue and a practical protection: phishing, brute force, trojan, ransomware, worm, DDoS, weak password, unpatched software.

Then answer:

1. Why is a firewall not the same as a backup?
2. How can MFA reduce damage from a stolen password?
3. Why should a student report a suspicious message instead of testing it?
4. Which scenario fact supports your threat choice?

Existing game alternative: use the Weeks 3-5 or Weeks 6-7 IIIT review CSV that matches the assigned content.

## Review set C: risk maps

1. Define probability and impact without using the word “risk.”
2. Place four teacher-read scenarios in the correct quadrant.
3. Cite one fact for each placement.
4. Match one protection to each risk.
5. Defend which risk should be handled first.

## Review set D: STEM exam project

1. State the problem, users, and testable goal.
2. Name the main feature and show where it appears in the product.
3. List three success criteria.
4. Summarize three test trials.
5. Name one weakness, one evidence-based change, and the result after the change.
6. State one remaining limitation.
7. Rehearse the 1–2 minute explanation without reading full paragraphs.

Existing game alternative: use the Weeks 8-12 IIIT review CSV.

## Teacher quick checks

- Correct digital-representation work shows operations and units.
- Correct cybersecurity work names a clue, not only a label.
- A risk rating is defensible only when it cites a scenario fact.
- A project milestone is complete only when the saved product and typed log agree.
- A demonstration explains the test evidence and improvement, not only what the product looks like.
