# 9th Grade Technology - November 2026

## Monthly Focus
Students complete the fifth daily grade, reflect on project habits, and move into the STEM exam project. The focus shifts from learning separate concepts to building, testing, documenting, and improving a STEM solution.

## Weekly Time
- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 135 minutes

## Competences

- • Use project planning evidence to build a STEM prototype with clear users, goal, tools, and success criteria.
- • Work responsibly with shared materials, feedback, documentation, and time management.
- • Test and improve a prototype using clear criteria, trial evidence, and reflection.

## Learning Objectives

- • Create a complete STEM project proposal with problem, users, goal, platform/tools, sketch, materials, and test criteria.
- • Build and document the exam prototype across project sessions using notes, screenshots, photos, or files.
- • Use evidence from testing to improve the design and prepare a clear project explanation.

## Learning Outcomes

- • Submit a STEM project proposal and project habits/organization reflection.
- • Build and improve the exam STEM prototype during Weeks 10-11 using testing evidence.
- • Prepare final documentation and presentation evidence for December.

## Evaluation
- Daily Grade #5 in Week 8: STEM project proposal.
- Appreciation Grade #2 in Week 9: project effort and organization self-reflection.
- Exam Project begins Week 10 and continues Week 11.
