Curriculum Breakdown
1: Foundations of Arduino/Freenove
Topics Covered:
Meet Arduino/Freenove (Introduction)
Hardware Basics: Arduino/Freenove Arduino-compatible board and breadboard, Features, and Usage
Code & Programming (Arduino IDE): Quick Start, Download, and Programming Basics
Chapter 1: LED outputs (blink, patterns, and simple light signals)
Chapter 2: Button input and LED control
Conceptual Content:
Understanding the Arduino/Freenove hardware and GPIO features.
Exploring the LED matrix and its applications.
Programming basics using Arduino IDE.
Procedural Content:
Navigate and use the Arduino IDE interface for programming.
Create LED-based projects to display patterns, text, and numbers.
Implement basic control using built-in buttons A and B.
Attitudinal Content:
Foster enthusiasm for programming and electronics.
Encourage creativity in designing LED matrix displays.
Promote collaboration during project implementation.
Competencies:
Set up and program the Arduino/Freenove kit for basic LED and button functionality.
Develop custom displays and text using the LED matrix.
Collaborate effectively on introductory Arduino/Freenove projects.
Indicators of Achievement:
Successfully program a heartbeat or text display on the LED matrix.
Demonstrate button control functionality for LED projects.
Show confidence in navigating Arduino IDE and uploading sketches.
2: Intermediate Programming and GPIO Applications
Topics Covered:
Chapter 3: LED (Project 3.1: Blink)
Chapter 4: Button and LED (Projects 4.1: Control LED by Button, 4.2: Table Lamp)
Chapter 5: LED Bar Graph (Project 5.1: Flowing Light)
Chapter 6: PWM (Project 6.1: Breathing Light)
Conceptual Content:
Exploring the use of external LEDs with Arduino/Freenove.
Understanding PWM (Pulse Width Modulation) for light control.
Creating dynamic light effects using GPIO.
Procedural Content:
Build and test circuits for LED blinking and control.
Program and implement button-controlled LED projects.
Create light-based effects like flowing and breathing lights using PWM.
Attitudinal Content:
Encourage precision and accuracy in circuit assembly.
Foster curiosity about light effects and programming possibilities.
Promote teamwork and problem-solving during project development.
Competencies:
Build and program GPIO-based LED circuits with buttons.
Design and execute PWM projects for dynamic light effects.
Troubleshoot and refine LED bar graph circuits and programs.
Indicators of Achievement:
Successfully create a table lamp project controlled by a button.
Program a flowing light effect using the LED bar graph.
Demonstrate a breathing light effect using PWM.
3: Advanced Projects with Arduino/Freenove
Topics Covered:
Chapter 7: RGBLED (Projects 7.1: Monochromatic Light, 7.2: Multicolored Light)
Chapter 8: Neopixel (Project 8.1: Rainbow Water Light)
Chapter 9: Buzzer (Projects 9.1-9.3: Active Buzzer, Happy Birthday Melody, Custom Melody)
Chapter 10: Serial Communication (Project 10.1: Display the Data)
Conceptual Content:
Using RGB LEDs and Neopixels for advanced lighting effects.
Programming and controlling sound outputs with buzzers.
Exploring serial communication for data transmission and display.
Procedural Content:
Build and program RGBLED and Neopixel circuits for light effects.
Design custom melodies and sound effects using the buzzer.
Implement serial communication to display data on external devices.
Attitudinal Content:
Foster innovation in light and sound-based projects.
Encourage resilience when troubleshooting advanced systems.
Promote collaboration in integrating hardware and software components.
Competencies:
Create and control RGBLED and Neopixel-based lighting systems.
Design and program custom melodies using buzzers.
Implement serial communication to display real-time data.
Indicators of Achievement:
Successfully program a rainbow water light effect using Neopixels.
Create and play a melody like "Happy Birthday" using a buzzer.
Demonstrate real-time data display via serial communication.
Methodology and Techniques
Project-based learning.
Group and individual practical activities.
Use of tutorials and digital guides.
Collaborative problem-solving.
Evaluation Activities
Complete and functional assembly and programming of Arduino/Freenove projects.
Development of creative light and sound effects using Arduino/Freenove.
Group presentations showcasing project designs and outcomes.
Maintain a digital portfolio documenting project progress and results.
Correlated Subjects
Computer Science.
Physics (basic concepts of light, sound, and data transmission).
Mathematics (logical sequences and patterns).
Additional Resources

Freenove Tutorials and Kit Guide
Python Programming for Arduino/Freenove (https://python.microbit.org/)
Notes
This plan is flexible and can be adjusted based on student progress and interests. Encourage creativity and experimentation to enhance the learning experience.
