# 9th Grade Technology - August 2026

## Monthly Focus
Students complete the required data grades, prepare their data project, and use weeks 10-12 for the trimester exam project. The project emphasizes a clear question, clean data, visual evidence, a digital product, and a short presentation.

## Weekly Time
- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 135 minutes

## Competences

- • Analyze data and communicate conclusions with evidence, limitations, and responsible data practices.
- • Design a clear and useful data product using charts, reports, dashboards, or a simple model when helpful.
- • Present a data project and reflect on effort, organization, deadlines, feedback, and data responsibility.

## Learning Objectives

- • Prepare a data report or dashboard from clean data with chart, conclusion, and limitation.
- • Use Tinkercad only when a simple 3D model supports the data-story product.
- • Plan, build, test, revise, and present the exam data project using project evidence.

## Learning Outcomes

- • Submit project readiness evidence, self-reflection, and a data project plan.
- • Build and improve the exam data project during Weeks 10-11 using feedback and testing evidence.
- • Present the data project in Week 12 with evidence, conclusion, limitation, and reflection.

## Evaluation
- Daily Grade #5 in Week 8: data report draft.
- Appreciation Grade #2 in Week 9: effort and organization self-reflection.
- Exam Project begins Week 10, continues Week 11, and presents Week 12.
