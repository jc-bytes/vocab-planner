## Risk-Control Checklist For Most At-Risk Lessons
| Lesson/Window | Main Risk | Control Checklist |
|---|---|---|
| April Week 5 Class 2: Analog Input With Potentiometer | Arduino port/serial monitor setup takes too long | Test boards before class; prepare starter sketch; label USB cables; prepare sample reading table as backup; limit required readings to low/medium/high |
| April Week 7 Class 1: Addressable LEDs | Library/wiring/component issues delay the lesson | Install/check library before class; pre-wire one demo; prepare wiring diagram; keep pattern requirement small: 3 colors and 2 speeds |
| May Weeks 10-11: Robotics Project | Hardware debugging expands beyond available time | Limit scope to one main input and two outputs; require project log; approve design before building; keep spare components ready |
| July Week 6 Class 2: Tinkercad Intro | Account/login/browser setup eats class time | Check student accounts; prepare join link/class code; provide screenshot guide; accept screenshot evidence if sharing links fails |
| August Week 10: Data Project Setup | Dataset is messy, missing, or too large | Approve dataset by week 9; provide backup dataset; require clean table before product design |
| September Week 2 Class 2: Sound Experiment | Audio software/files are not ready | Prepare web audio tool backup; provide sample audio files; allow 3-row evidence table instead of complex editing |
| November Weeks 10-11: STEM Project | Project scope becomes too broad | Require one problem, one user group, one prototype feature, and three test criteria; approve materials before week 10 |

## Make-Up Plan For Interruption-Prone Grades
| Grade/Window | Why It May Be Interrupted | Make-Up Option |
|---|---|---|
| Trimester 1 Daily Grade #2: Button-Input Practical Check | Hardware, absences, or port issues | Submit labeled photo/screenshot, starter-code annotation, and 3-sentence explanation in Google Classroom |
| Trimester 1 Daily Grade #3: Sensor Threshold Quiz-Style Check | Sensor availability or serial monitor problems | Use provided sample sensor readings to complete the threshold check and explanation |
| Trimester 1 Daily Grade #5: Robotics Design Plan | Absence near project launch | Complete the design plan template in Google Classroom before joining build work |
| Trimester 1 Exam Project | Hardware debugging or presentation absence | Submit recorded demo or photo sequence, project log, code/screenshots, and written explanation |
| Trimester 2 Daily Grade #3: Data Collection Plan | Absence or unclear survey/data question | Complete the plan form using a teacher-approved backup topic |
| Trimester 2 Daily Grade #4: Chart and Interpretation | Missing or unusable data | Use a teacher-provided backup dataset to create the chart and 4 interpretation sentences |
| Trimester 2 Daily Grade #5: Data Report Draft | Lost file or incomplete dataset | Submit report draft using the backup dataset and explain the limitation |
| Trimester 2 Exam Project | Dataset/product problems or presentation absence | Submit final product link/file, clean dataset, screenshots, reflection, and recorded or written presentation |
| Trimester 3 Daily Grade #2: Representation Check | Absence during quiz/form | Complete the Google Form or printed make-up version |
| Trimester 3 Daily Grade #3: Cyber Security Scenario Quiz | Absence during scenario quiz | Complete the Google Form or printed make-up version |
| Trimester 3 Daily Grade #4: Risk Map | Missed planning class | Complete the risk map template with 6 risks and priority recommendation |
| Trimester 3 Daily Grade #5: STEM Proposal | Absence near project launch | Submit STEM proposal form before project build approval |
| Trimester 3 Exam Project | Prototype or presentation interruption | Submit recorded demo or photo sequence, logbook, testing evidence, final reflection, and written explanation |
