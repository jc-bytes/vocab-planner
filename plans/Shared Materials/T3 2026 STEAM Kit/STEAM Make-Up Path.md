# STEAM Make-Up Path

This path replaces missing individual evidence for either Technology STEAM grade. Grade 6 records these as Summatives 3 and 4. Grades 7–9 record Expo Explanation and Closure as Daily Grade 3 and Individual Work Process as Daily Grade 4, never Appreciation grades. The make-up does not require a student to build a second project.

## If a student misses a work session

The student reviews the group's current file, prototype, calculations, or written record and submits:

1. the project problem and goal in their own words;
2. the role they can complete now;
3. one specific contribution to the current group version;
4. one test or quality check and its result;
5. an updated individual work-log entry.

The teacher may observe the contribution live or accept the saved file, typed record, or completed physical part.

## If a student misses the expo

The student gives a short live explanation to the teacher or submits a written explanation containing:

- the problem and goal;
- how the project works;
- the student's contribution;
- one test and result;
- one improvement;
- a completed individual reflection and cleanup or materials-return responsibility.

## If the project file or device is unavailable

Use the individual work log, test record, labeled diagram, pseudocode, calculation, storyboard, or explanation plan. The teacher checks the record or explanation directly.
