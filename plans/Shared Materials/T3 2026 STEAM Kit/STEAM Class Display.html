STEAM · ORGANIZE

One project. One clear role for every student.

Record

  • project and problem
  • assigned subject teacher
  • your role
  • today's first task

Before work starts

  • open the correct file or collect materials
  • agree on file and version names
  • identify the safe workspace

Checkpoint: each student can state, “My role today is …”

STEAM · WORK

Complete something that moves the assigned project forward.

  1. Work on your assigned task.
  2. Ask for help using a specific question.
  3. Save or store the current version.
  4. Write what you completed in your individual log.

Technology evidence: saved file, completed part, calculation, typed record, teacher observation, or live demonstration.

STEAM · TEST

A test needs an expected result and an actual result.

Before

What should happen? What will you observe or measure?

After

What happened? What will you keep, change, or test again?

Record one real result. “It worked” is not enough.

STEAM · EXPO

Explain the problem, goal, action, evidence, and improvement.

  1. Problem or need
  2. What the project should do
  3. Your contribution
  4. How it works
  5. One test and result
  6. One improvement

Every student completes the assigned speaking or demonstration role.

STEAM · CLOSE

Leave evidence and a ready workspace.

  • Save and name files clearly.
  • Return and label materials.
  • Complete your individual reflection.
  • Finish your assigned cleanup task.
  • Write the next step for the project.

Use saved work, typed records, teacher observation, or a live demonstration.
