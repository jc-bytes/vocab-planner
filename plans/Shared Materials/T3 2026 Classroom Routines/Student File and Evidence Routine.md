# Student File and Evidence Routine

## Start

1. Bring and open your computer.
2. Open only the tool, module, or file named by the teacher.
3. Create or open the correct grade, trimester, and topic folder.
4. Use the required filename: `Grade_Class_Lastname_Task_Version`.

## Work

1. Follow the current lesson or checkpoint.
2. Save after every meaningful change.
3. Keep the evidence requested for that class: module export, editable file, share link, typed response, test record, or live demonstration.
4. Ask for help by naming the step, expected result, and actual result.

## Finish

1. Confirm the file opens.
2. Check the task directions or submission checklist.
3. Submit or share through the location named by the teacher.
4. Record the filename or link before leaving.
5. Close accounts and leave the workspace ready.

Personal mobile devices and separate recording-device submissions are not used.
