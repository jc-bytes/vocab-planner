# Teacher Before-Class and Collection Check

## Before students enter

- [ ] Open the exact module section, class visual anchor, example, or task directions.
- [ ] Confirm the student task and expected output.
- [ ] Open or print the fallback.
- [ ] Confirm required accounts, links, files, and physical materials.
- [ ] Identify the midpoint checkpoint and the last-save warning.
- [ ] Open the rubric or quick-check notes when evidence is graded.

## During class

- [ ] State what students will make, practice, or explain.
- [ ] Show one correct example or model the first step.
- [ ] Check progress at the midpoint using visible evidence.
- [ ] Record students who need reteaching, extension, or make-up work.
- [ ] For group work, record each student's role, action, or explanation separately from the shared product.
- [ ] Give a five-minute save and submission warning.

## Before dismissal

- [ ] Confirm the required file, export, share link, typed record, or live demonstration.
- [ ] Use the exit check or closing question.
- [ ] Verify materials and accounts are closed safely.
- [ ] Note the next class's starting point.
