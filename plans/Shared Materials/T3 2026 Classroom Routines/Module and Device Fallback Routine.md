# Module and Device Fallback Routine

The Grade 6–9 modules are classroom pilots. Use the live module when it opens correctly and students can save or export the intended practice evidence. Keep the printable fallback ready.

## If the module does not open

1. Project or distribute the module's `printable-fallback.html`.
2. Teach from the same Learn or Inspect example.
3. Students complete the matching practice and application record on paper or in a local document.
4. The teacher checks the same success criteria as the live module.

## If one student's computer fails

1. The student may observe the projected example or work beside a partner for instruction.
2. The student completes an individual paper or local-document response.
3. Record the device issue; do not replace individual evidence with the partner's submission.

## If saving or exporting fails

1. Keep the editable source file when one exists.
2. Copy the module's visible result into a typed or paper record.
3. The teacher may verify the work live and initial the record.
4. Retry export only if class time allows.

Use individual paper work, a local document, or direct teacher verification as the fallback evidence.
