# 4th Grade Technology - June 2026

## Monthly Focus

June opens the robotics trimester with lab routines, safe handling, robot parts, inputs/outputs, and simple command sequences. Students use pictures, diagrams, cards, and approved kit pieces only when they are ready and safe.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 hours
- Month plan weeks: 4

## Competences

- Follow robotics lab routines and safe handling expectations.
- Identify common robot parts and explain their basic functions.
- Describe input, process, output, power, and movement using simple examples.
- Create a clear robot path map using commands, arrows, and predictions.

## Learning Objectives

- Name and label robot parts such as sensor, motor, controller, wheel, frame, wire, switch, and power source.
- Sort robot parts by function: input, movement, control, power, and output.
- Build a simple command sequence with start, move, turn, stop, and repeat.
- Create a path map with a start point, end point, commands, and one obstacle or goal.

## Learning Outcomes

- Complete Summative Activity #1: robot parts diagram and vocabulary.
- Complete Summative Activity #2: robot sequence/path map.
- Complete formative robotics safety, input-output diagrams, command-card practice, and notebook corrections.

## Evaluation

- Summative Activity #1 in Week 2: robot parts diagram and function sentences.
- Summative Activity #2 in Week 4: robot path map and predictions.
- All other June activities are formative practice, guided exploration, discussion, notebook work, and feedback.
