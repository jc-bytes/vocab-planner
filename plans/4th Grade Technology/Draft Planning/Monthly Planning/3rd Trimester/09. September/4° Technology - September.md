# 4th Grade Technology - September 2026

## Monthly Focus

September begins the third trimester with data questions, class-safe data collection, and a STEM data-table bridge from the inertia/movement work in Trimester 2. Students learn that data can help answer questions when it is recorded clearly and responsibly.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 hours
- Month plan weeks: 3

## Competences

- Ask simple, safe questions that can be answered with data.
- Collect and record a small data set accurately.
- Use tables to organize observations over time.
- Protect private information when collecting class data.

## Learning Objectives

- Write or choose a data question.
- Collect 8-10 safe responses or use a teacher-provided data set.
- Organize data in a table with clear categories.
- Begin a simple log over time.

## Learning Outcomes

- Complete Summative Activity #1: STEM data question and collection table.
- Complete formative data-question practice and data logging notes.

## Evaluation

- Summative Activity #1 in Week 2: STEM data question and collection table.
- All other September T3 activities are formative practice, guided data collection, logging practice, and feedback.
