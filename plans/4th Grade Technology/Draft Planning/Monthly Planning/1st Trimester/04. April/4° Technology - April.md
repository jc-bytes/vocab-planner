# 4th Grade Technology - April 2026

## Monthly Focus

April builds practical digital-work skills through Google Docs, Google Sheets, and Canva. Students practice creating, organizing, interpreting, designing, and submitting simple digital evidence. The month removes the off-spine computer hardware unit from required first-trimester work and keeps every task short, visible, and Grade 4 appropriate.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 hours
- Month plan weeks: 5

## Competences

- Create and format a simple digital document using titles, images, and clear text.
- Organize information in a Google Sheets table using rows, columns, categories, and simple count/sort actions.
- Interpret a small data set to answer basic questions.
- Design a Canva product with a clear purpose, readable text, and organized visual choices.

## Learning Objectives

- Create a structured Google Docs practice document with a title, subtitle, image, and basic formatting.
- Enter, sort, and read simple data in a table.
- Answer 2-3 questions using information from a small data set.
- Create a Canva product with a title, image, readable text, and a short explanation of purpose.

## Learning Outcomes

- Complete Summative Activity #3: Google Sheets simple data table/check.
- Complete Summative Activity #4: Canva visual communication product.
- Complete formative Google Docs practice, Google Sheets practice, Canva planning, feedback, and revision.

## Evaluation

- Summative Activity #3 in Week 7: Google Sheets simple data table/check.
- Summative Activity #4 in Week 9: Canva visual communication product.
- All other April activities are formative practice, guided tool use, feedback, revision, and notebook checks.
