# 7° Technology - September 2026

## Monthly Focus

Students begin the third trimester with spreadsheets and data modeling. They learn spreadsheet vocabulary, enter and format data, use basic formulas, and create simple charts. The month keeps the work practical so students can use data tools later for project tracking and reflection.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Google Classroom
- Google Sheets or Excel
- prepared data files
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Organize classroom data in spreadsheets using rows, columns, cells, sheets, and cell references.
- Use formulas and basic functions accurately to calculate and compare data.
- Create simple charts and explain what spreadsheet data shows using clear vocabulary.

## Learning Objectives

- Identify spreadsheet parts and enter formatted text and numbers in a clean data table.
- Use SUM, AVERAGE, MIN, and MAX with simple data and correct cell references.
- Create a chart from classroom data and write a short interpretation of the result.

## Learning Outcomes

- Complete a spreadsheet vocabulary table with definitions, illustrations, and example sentences.
- Submit a formatted class data table and formula practice evidence.
- Submit a formulas and chart task with a short data interpretation and teamwork checklist.

## Evaluation

- Daily Grade #1: spreadsheet vocabulary table.
- Daily Grade #2: formulas and chart task.
- Appreciation Grade #1: data teamwork checklist.

## Vocabulary Plan

### Trimester 3 Summative Vocabulary

Used for Daily Grade #1 as the trimester vocabulary table. Week 1 does not need a separate practice vocabulary because these 10 words are the vocabulary focus.

spreadsheet, sheet, row, column, cell, cell reference, formula, function, average, chart

### Practice Vocabulary

#### Week 2: Formulas and Charts

| Word | Simple Definition |
| --- | --- |
| formula | A rule that calculates a value. |
| function | A built-in formula tool, such as AVERAGE. |
| average | A number found by adding values and dividing by how many values there are. |
| minimum | The smallest value. |
| maximum | The largest value. |
| chart | A visual way to show data. |
| interpretation | An explanation of what data means. |
