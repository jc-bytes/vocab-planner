# 7° Technology - May 2026

## Monthly Focus

Students complete the first trimester by applying mBot movement, sensors, testing, and debugging to the mBot Maze Navigator exam project. Week 9 closes regular grading; weeks 10-11 are project build and improvement weeks; week 12 is presentation and demonstration.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- mBot kits
- mBlock software
- USB cables or Bluetooth connection
- charged batteries
- ultrasonic sensor
- project rubric
- checklist or worksheet
- project planning sheet
- maze materials
- floor tape or markers
- projector

## Competences

- Plan a maze route and robot algorithm using checkpoints, obstacles, sensors, and movement commands.
- Build, test, debug, and improve an mBot Maze Navigator solution with team responsibilities.
- Present a robotics project clearly using testing evidence, code explanation, and reflection.

## Learning Objectives

- Create a maze plan with start, finish, turns, obstacles, checkpoints, and sensor checks.
- Program the mBot to navigate maze sections and use test evidence to improve the route.
- Explain how sensors, motors, code, and teamwork contributed to the final solution.

## Learning Outcomes

- Submit maze planning evidence, make-up evidence if needed, and a project readiness goal.
- Build and test the mBot Maze Navigator in a group of 2-3 using trial records and debugging notes.
- Demonstrate the final maze solution and submit a reflection about planning, testing, debugging, and teamwork.

## Evaluation

- Week 9: regular practice and make-up for Daily Grades #1-#5 and Appreciation Grades #1-#2.
- Weeks 10-11: Begin and continue exam project in groups of 2-3.
- Week 12: Complete exam project presentation using the mBot Maze Navigator rubric.
- Required grading resource: mBot Maze Navigator rubric and testing checklist.
