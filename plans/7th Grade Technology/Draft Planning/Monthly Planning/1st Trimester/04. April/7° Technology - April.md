# 7° Technology - April 2026

## Monthly Focus

Students improve mBot movement control by using speed, time, direction, turns, LEDs, sounds, sensor values, and simple if/else logic. The month prepares students for the final maze project by emphasizing testing, precision, and clear robot feedback.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- mBot kits
- mBlock software
- USB cables or Bluetooth connection
- charged batteries
- ultrasonic sensor
- speaker or computer sound output
- project planning sheet
- maze materials
- floor tape or markers
- projector

## Competences

- Program controlled mBot movement using speed, time, direction, and measured testing.
- Design efficient robot routes with movement sequences, checkpoints, outputs, and feedback signals.
- Use ultrasonic sensor readings and if/else logic to create simple reactive robot behavior.

## Learning Objectives

- Adjust speed, time, and turns to improve movement accuracy on measured paths.
- Plan and test routes using grid maps, movement arrows, LEDs, and sound signals.
- Read ultrasonic values, choose a threshold, and explain an obstacle-detection program.

## Learning Outcomes

- Submit a movement calibration chart and route-planning evidence with tested values.
- Demonstrate movement with LED or sound feedback and explain what each signal means.
- Complete a sensor-values quiz-style check and demonstrate a reactive obstacle program.

## Evaluation

- Daily Grade #4: movement calibration chart.
- Daily Grade #5: reactive obstacle program demonstration.
- Appreciation Grade #2: perseverance and feedback self-reflection.
- Quiz-style check: sensor values, thresholds, and if/else logic after practice.
