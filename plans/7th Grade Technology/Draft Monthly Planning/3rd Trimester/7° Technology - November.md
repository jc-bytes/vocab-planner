# 7° Technology - November 2026

## Monthly Focus

Students use November for make-up, project setup, and the Mandrake Detection System exam project. Non-exam summative grades are already finished by Week 7, so Weeks 8-11 can absorb Panamanian celebration interruptions while students practice input-output thinking, micro:bit sensor logic, distance thresholds, Bluetooth signaling, documentation, testing, and presentation skills.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Canva access
- Scratch access
- starter files when needed
- Google Sheets or Excel
- prepared data files
- micro:bit or simulator
- USB cables
- ultrasonic sensor
- speaker or computer sound output
- project rubric
- checklist or worksheet
- project planning sheet
- projector

## Competences

- Design and explain a sensor-based physical computing system using input, process, output, and threshold logic.
- Use testing evidence to improve a micro:bit Mandrake Detection System or a clearly labeled simulation.
- Present project purpose, parts, code logic, testing challenges, results, and personal responsibility clearly.

## Learning Objectives

- Plan a sensor-triggered output system with purpose, parts, diagram, threshold rule, and testing questions.
- Build or simulate distance-based logic and document how threshold values affect output behavior.
- Prepare and deliver a final project explanation using code evidence, test results, and reflection.

## Learning Outcomes

- Use November buffer classes to review the Week 7 micro:bit sensor-system design plan, complete make-up work if needed, and prepare project materials.
- Complete a quiz-style vocabulary review covering spreadsheets, Scratch, source credibility, and micro:bit ideas without adding a new daily or appreciation grade.
- Demonstrate the Mandrake Detection System or simulation and submit final project reflection evidence.

## Evaluation

- No new daily or appreciation grades after Week 7.
- Weeks 8-9: make-up, threshold testing practice, vocabulary review, and project setup.
- Weeks 10-11: begin and continue exam project in groups of 2-3.
- Week 12: Complete exam project presentation using the Mandrake Detection System rubric.
- Required grading resource: Mandrake Detection System rubric and threshold testing checklist.
