# 7° Technology - October 2026

## Monthly Focus

Students extend spreadsheet skills into data analysis, then connect computational thinking with Scratch programming and responsible online media use. The month closes the non-exam summative sequence by Week 7 with a micro:bit sensor-system design plan that prepares students for the Mandrake Detection System exam project.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- Google Classroom
- Scratch access
- starter files when needed
- Google Sheets or Excel
- prepared data files
- micro:bit or simulator
- USB cables
- ultrasonic sensor
- speaker or computer sound output
- Google Sites access
- project planning sheet
- projector

## Competences

- Analyze spreadsheet data with sorting, filtering, COUNTIF, and conditional formatting.
- Apply decomposition, subroutines, loops, and lists to organize Scratch programs.
- Evaluate digital sources, credit media correctly, and describe input/output behavior in physical computing systems.

## Learning Objectives

- Sort and filter spreadsheet data, count matching items, and write one conclusion from a pattern.
- Plan and build Scratch features using reusable subroutines, loops, and organized lists.
- Check source credibility, create a short media post plan, and label a micro:bit sensor system diagram.

## Learning Outcomes

- Submit spreadsheet analysis evidence using sort, filter, COUNTIF, conditional formatting, and responsible data teamwork.
- Demonstrate a Scratch subroutine and loop feature and explain how the program is organized.
- Complete source credibility, blog/media responsibility, and micro:bit sensor-system planning evidence before November project buffers.

## Evaluation

- Appreciation Grade #1: data teamwork checklist.
- Daily Grade #3: Scratch subroutine and loop demonstration.
- Daily Grade #4: source credibility and image credit check.
- Appreciation Grade #2: blog/media responsibility, source credit, and revision habits.
- Daily Grade #5: micro:bit sensor-system design plan.

## Vocabulary Plan

### Practice Vocabulary

#### Week 3: Data Analysis

| Word | Simple Definition |
| --- | --- |
| sort | To arrange data in order. |
| filter | To show only data that matches a rule. |
| COUNTIF | A spreadsheet function that counts items matching a condition. |
| formatting | Changing how text or data looks. |
| pattern | Something that repeats or has a clear order. |
| condition | A rule that can be true or false. |

#### Week 4: Scratch Decomposition

| Word | Simple Definition |
| --- | --- |
| decomposition | Breaking a big task into smaller parts. |
| subroutine | A smaller named part of a program that can be reused. |
| call | To run a subroutine from another part of a program. |
| main program | The main set of instructions that controls a project. |
| reuse | To use something again instead of rebuilding it. |
| loop | Code that repeats. |

#### Week 5: Sources and Lists

| Word | Simple Definition |
| --- | --- |
| list | A group of related items stored together. |
| item | One thing in a list. |
| index | A position number in a list. |
| source | Where information or media comes from. |
| credible | Trustworthy and believable. |
| citation | Information that shows where a source came from. |
| plagiarism | Using someone else's work as if it were your own. |

#### Week 6: Blog Media

| Word | Simple Definition |
| --- | --- |
| blog | A web page or post that shares ideas or information. |
| heading | A title for a section of text. |
| caption | Short text that explains an image. |
| paragraph | A group of sentences about one idea. |
| layout | How text and images are arranged. |
| call to action | Words that ask the reader to do something. |
| credit | A note that says who made or provided something. |

#### Week 7: Sensor Systems

| Word | Simple Definition |
| --- | --- |
| input | Information that goes into a system or program. |
| output | What a system or program produces. |
| sensor | A part that detects information from the environment. |

| threshold | A limit where an action changes. |
| Bluetooth | A wireless way for devices to communicate nearby. |
| microbit | A small computer board used for coding projects. |
