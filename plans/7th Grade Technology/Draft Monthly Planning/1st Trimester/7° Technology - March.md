# 7° Technology - March 2026

## Monthly Focus

Students begin the robotics trimester by identifying mBot components, practicing safe use of materials, exploring mBlock, and creating first movement programs. The month builds the foundation for later navigation and maze work.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- mBot kits
- mBlock software
- USB cables or Bluetooth connection
- charged batteries
- checklist or worksheet
- maze materials
- floor tape or markers
- projector

## Competences

- Identify mBot hardware parts and explain how each part supports robot behavior.
- Use mBlock safely and responsibly to create, test, and upload simple movement programs.
- Connect hardware, software, input, process, and output in a basic robot system.

## Learning Objectives

- Label internal and external mBot components and match key parts with their functions.
- Navigate the mBlock workspace and identify sprites, blocks, scripts, and device connection tools.
- Program basic movement commands, test robot actions, and adjust speed or time values.

## Learning Outcomes

- Complete an mBot vocabulary table using definitions, illustrations, and example sentences.
- Submit an mBot parts diagram with at least eight labeled parts and five function sentences.
- Complete an mBlock interface labeling check and demonstrate a basic movement sequence safely.

## Evaluation

- Daily Grade #1: mBot vocabulary table.
- Daily Grade #2: mBot parts diagram.
- Appreciation Grade #1: robotics safety and responsibility checklist.
- Daily Grade #3: mBlock interface labeling check.

## Vocabulary Plan

### Trimester 1 Summative Vocabulary

Used for Daily Grade #1 as the trimester vocabulary table. Week 1 does not need a separate practice vocabulary because these 10 words are the vocabulary focus.

mBot, hardware, software, chassis, motor, sensor, LED, buzzer, controller, control board

### Practice Vocabulary

#### Week 2: mBlock Workspace

| Word | Simple Definition |
| --- | --- |
| mBlock | A block coding tool used to program the mBot. |
| workspace | The area in a program where you do your work. |
| sprite | A character or object in a Scratch or mBlock project. |
| block | A coding command that snaps into a program. |
| script | A group of connected blocks that run together. |
| upload | To send a program from the computer to the robot. |
| interface | The screen and tools used to work with a program. |

#### Week 3: Movement Commands

| Word | Simple Definition |
| --- | --- |
| movement | A change in position. |
| forward | Moving toward the front. |
| backward | Moving toward the back. |
| turn | To change direction. |
| speed | How fast something moves. |
| time | How long something happens. |
| stop | To end movement or action. |

#### Week 4: Robot Systems

| Word | Simple Definition |
| --- | --- |
| system | Parts that work together. |
| input | Information that goes into a system or program. |
| process | The steps a system or program uses. |
| output | What a system or program produces. |
| sequence | Steps in the correct order. |
| debug | To find and fix a problem in code. |
