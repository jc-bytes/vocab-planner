# 7° Technology - July 2026

## Monthly Focus

Students transition from digital media into Scratch programming. They practice sequence, variables, selection, comparison operators, loops, and debugging, then analyze a teacher-provided Scratch rhythm game. The month ends with a code-walkthrough presentation that prepares students to build their own osu!-style rhythm game for the exam.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- computer
- student's email and password

## Competences

- Build interactive Scratch programs using sequence, selection, loops, variables, and user input.
- Use comparison operators and if/else logic to control program responses.
- Trace, test, and explain how events, broadcasts, variables, user input, timing, and sprite interactions work together in a Scratch rhythm game.

## Learning Objectives

- Create a Scratch response program that uses if/else to give different outputs.
- Use loops and variables together to reduce repeated code and control changing values.
- Analyze the teacher-provided rhythm game and present an assigned code component using correct programming vocabulary.

## Learning Outcomes

- Submit and demonstrate Scratch selection and loop practice programs.
- Complete a quiz-style check on comparison and logic operators after selection practice.
- Present the reference rhythm game, explain how the assigned scripts work, connect the scripts to the visible game behavior, and answer one teacher question.

## Evaluation

- Daily Grade #3: branded slide set.
- Daily Grade #4: Scratch sequence program.
- Daily Grade #5: reference Scratch rhythm-game code-walkthrough presentation.
- Appreciation Grade #1: constructive peer feedback during loop and timing practice.
- Appreciation Grade #2: pair-programming responsibility self-reflection.
- Quiz-style check: Scratch comparison and logic operators after selection practice.

## Vocabulary Plan

### Practice Vocabulary

#### Week 3: Scratch Intro

| Word | Simple Definition |
| --- | --- |
| Scratch | A block coding tool for making programs and games. |
| sprite | A character or object in a Scratch or mBlock project. |
| script | A group of connected blocks that run together. |
| event | Something that starts an action in a program. |
| block | A coding command that snaps into a program. |
| sequence | Steps in the correct order. |

#### Week 4: Variables

| Word | Simple Definition |
| --- | --- |
| variable | A named place that stores a value that can change. |
| value | Information stored in a variable or cell. |
| score | A number that tracks points or progress. |
| condition | A rule that can be true or false. |
| selection | Code that chooses what to do based on a condition. |
| if/else | A code choice between two actions. |

#### Week 5: Operators

| Word | Simple Definition |
| --- | --- |
| operator | A symbol or block that compares or calculates. |
| comparison | Checking how two values are related. |
| logic | Rules used to make decisions. |
| true | Correct or matching a condition. |
| false | Not correct or not matching a condition. |
| response | What happens after an input or event. |

#### Week 6: Loops

| Word | Simple Definition |
| --- | --- |
| loop | Code that repeats. |
| iteration | One repeat of a loop. |
| repeat | To do something again. |
| countdown | Counting backward to a final number. |
| rhythm | A repeated beat or timing pattern. |
| debug | To find and fix a problem in code. |

#### Week 7: Code Tracing and Collaboration

| Word | Simple Definition |
| --- | --- |
| trace | To follow code step by step. |
| event | Something that starts a script. |
| broadcast | A message that starts another script. |
| driver | The partner controlling the computer during pair work. |
| navigator | The partner who guides and checks the work during pair work. |
| feedback | Helpful comments about how to improve. |

#### Week 8: Rhythm Game Analysis

| Word | Simple Definition |
| --- | --- |
| target | The object the player must hit at the correct time. |
| lane | One path used by a target and its matching key. |
| collision | When two sprites touch in the program. |
| tempo | The speed of the beat or timing pattern. |
| score | A number that changes after a hit or miss. |
| code walkthrough | An explanation that connects scripts to program behavior. |
