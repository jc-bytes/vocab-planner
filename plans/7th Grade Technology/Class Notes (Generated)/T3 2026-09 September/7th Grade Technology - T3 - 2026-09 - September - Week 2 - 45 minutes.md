## Class Objective

Practice formulas using a small data set.

## Pre-Activities

- Review Week 2 practice vocabulary. formula: A rule that calculates a value function: A built-in formula tool, such as AVERAGE average: A number found by adding values and dividing by how many values there are minimum: The smallest value maximum: The largest value chart: A visual way to show data interpretation: An explanation of what data means

## While Activities

- Practice formulas using a small data set. Calculate total, average, minimum, and maximum values using cell references. Discuss what responsible data teamwork looks like before the graded reflection.

## Post-Activities

- Check one formula with a calculator or mental math. Fix one formula error if needed.
