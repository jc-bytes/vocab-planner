## Class Objective

Create a vocabulary table for these 10 words: spreadsheet, sheet, row, column, cell, cell reference, formula, function, average, chart.

## Pre-Activities

- Open Google Sheets or Excel. Preview the 10 Trimester 3 vocabulary words: spreadsheet, sheet, row, column, cell, cell reference, formula, function, average, chart. Identify the toolbar, formula bar, active cell, row numbers, and column letters.

## While Activities

- Complete Daily Grade #1: Create a vocabulary table for these 10 words: spreadsheet, sheet, row, column, cell, cell reference, formula, function, average, chart. Then create a class data table.

## Post-Activities

- Save the spreadsheet. Write one formatting choice that made the table easier to read.
