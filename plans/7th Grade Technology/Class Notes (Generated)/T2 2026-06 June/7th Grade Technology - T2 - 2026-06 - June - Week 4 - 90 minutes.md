## Class Objective

Build a Scratch sequence with at least 8 blocks, one event block, one sound or costume change, and one written explanation of why the order matters.

## Pre-Activities

- Review Week 4 practice vocabulary (part 2). condition: A rule that can be true or false selection: Code that chooses what to do based on a condition if/else: A code choice between two actions

## While Activities

- Complete Daily Summative #4: Build a Scratch sequence with at least 8 blocks, one event block, one sound or costume change, and one written explanation of why the order matters. Then create a simple counting or score program in Scratch and test with two different starting values.

## Post-Activities

- Write one way variables could be used in a game. Save the project and submit the Scratch sequence evidence.
