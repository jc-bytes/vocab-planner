## Class Objective

Build and demonstrate a Scratch program that uses at least 1 subroutine or custom block, 1 loop, 1 event, and 1 explanation sentence about how decomposition improves the program.

## Pre-Activities

- Predict how a Scratch script will run when a subroutine is called. Review Week 4 practice vocabulary (part 2). main program: The main set of instructions that controls a project reuse: To use something again instead of rebuilding it loop: Code that repeats

## While Activities

## Post-Activities
