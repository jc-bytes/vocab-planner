## Class Objective

Practice reading distance values with classroom equipment when available, create a small test table, and adjust the threshold rule from the Week 7 design plan.

## Pre-Activities

- Review Week 8 practice vocabulary (part 2). expected: What you think should happen actual: What really happens reliability: How dependably something works Review distance readings and decide which values mean “inside the pot” and “removed from the pot.”

## While Activities

- Practice reading distance values with classroom equipment when available, create a small test table, and adjust the threshold rule from the Week 7 design plan. Use this class for make-up or improvement evidence only if a student missed a previous summative.

## Post-Activities

- Save the test table and write one threshold that seems reasonable and why.
