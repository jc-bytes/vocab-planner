## Class Objective

Demonstrate the mBot Maze Navigator and explain code logic, sensor use, challenge, solution, and reflection.

## Pre-Activities

- Set up the mBot, maze, program, and presentation notes. Test the robot once if time allows.

## While Activities

- Complete Exam Project Presentation: Demonstrate the mBot Maze Navigator, explain how the code controls the robot, describe how sensors support decisions, identify one challenge and solution, and submit the project reflection.

## Post-Activities

- Listen to classmates respectfully. Complete a short reflection about planning, testing, debugging, and teamwork.
