## Class Objective

Program maze sections, test the mBot, document trials, and debug speed, timing, turns, or thresholds.

## Pre-Activities

- Review Week 11 practice vocabulary. debug: To find and fix a problem in code trial: One test attempt improvement: A change that makes something better performance: How well something works documentation: Notes or records that explain the work reflection: Thinking about what happened and what you learned Check the maze spacing and make sure the mBot can pass safely. Review project vocabulary before testing the route.

## While Activities

- Continue Exam Project: Finalize the maze section, program the first navigation algorithm, test the mBot, record trial results, and debug speed, timing, turns, or thresholds.

## Post-Activities

- Record the best trial result. Identify one code change and one maze change for next class.
