## Class Objective

Read ultrasonic sensor values, choose a threshold, and explain a reasonable obstacle condition.

## Pre-Activities

- Observe near and far objects and predict how the sensor value changes. Review Week 8 practice vocabulary. ultrasonic: Using sound waves to measure distance reading: A value measured by a sensor threshold: A limit where an action changes condition: A rule that can be true or false if: A code word used to check a condition else: A code word for what happens when an if condition is false reactive: Able to respond when something changes

## While Activities

- Complete a 6-question quiz-style check on sensor values, thresholds, and if/else choices. Read ultrasonic sensor values for 3 object distances. Choose a threshold that means “too close” and explain why the threshold is reasonable.

## Post-Activities

- Share one threshold with the class. Revise it if testing shows it is too high or too low.
