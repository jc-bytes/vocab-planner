## Class Objective

Program LED colors for robot states and explain what each color means.

## Pre-Activities

- Match colors with robot states: ready, moving, warning, stopped. Explain one color choice with a reason.

## While Activities

- Program green for ready, blue for moving, and red for stop. Test the LED sequence and adjust the order if the color does not match the robot state.

## Post-Activities

- Write a three-line legend explaining what each color means.
