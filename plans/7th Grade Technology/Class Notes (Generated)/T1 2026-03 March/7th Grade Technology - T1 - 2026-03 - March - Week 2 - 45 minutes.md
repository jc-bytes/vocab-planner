## Class Objective

Label main mBot parts and write function sentences for sensors, motors, and the control board.

## Pre-Activities

- Review Week 2 practice vocabulary (part 1). mBlock: A block coding tool used to program the mBot workspace: The area in a program where you do your work sprite: A character or object in a Scratch or mBlock project block: A coding command that snaps into a program

## While Activities

- Practice labeling an mBot parts diagram and draft function sentences for the main parts. Compare your practice labels with a partner and correct missing labels before the graded check.

## Post-Activities

- Circle the two parts most important for movement. Explain one part that helps the robot sense the environment.
