## Class Objective

Label key mBlock workspace areas and test a simple movement script.

## Pre-Activities

- Open mBlock and locate the stage, sprites, blocks, scripts area, and device connection tools. Review Week 2 practice vocabulary (part 2). script: A group of connected blocks that run together upload: To send a program from the computer to the robot interface: The screen and tools used to work with a program

## While Activities

- Complete Daily Grade #2: Label an mBot parts diagram with at least 8 parts and write one function sentence for 5 of the parts. Then drag movement blocks into the scripts area and test a simple sprite movement sequence.

## Post-Activities

- Submit your mBot parts diagram. Write one mBlock tool you expect to use often.
