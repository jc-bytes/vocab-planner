## Class Objective

Debug a Scratch starter program by identifying 3 errors, fixing at least 2 errors, and submitting a short debugging note that names the problem, fix, and result.

## Pre-Activities

- Review Week 7 practice vocabulary (part 2). driver: The partner controlling the computer during pair work navigator: The partner who guides and checks the work during pair work feedback: Helpful comments about how to improve Choose the concept you need to strengthen.

## While Activities

- Complete Daily Grade #5: Debug a Scratch starter program by identifying 3 errors, fixing at least 2 errors, and submitting a short debugging note that names the problem, fix, and result. Then build a small “Moves Like Jim” practice feature with one costume change, one input, and one repeated movement or sound.

## Post-Activities

- Save the practice feature. Submit the debugging note and write one goal for the upcoming dance game project.
