# Grade 7 T3 student task sheets

Print only the section assigned for the class. Digital module practice saves on the current computer and browser. Export before changing computers. Submit working files, share links, typed records, or these printed sheets. Do not use a phone, photo, or screenshot as evidence.

## Spreadsheet cell and formula practice

Name: ____________________ Class: ______ Date: __________

1. In the reference `C4`, circle the column letter and underline the row number.
2. Write the references for the teacher-indicated cells: ______, ______, ______.
3. For values in B2:B5, write formulas for total, average, minimum, and maximum.
4. Predict each result before opening the spreadsheet.
5. Check one result. Record the formula, predicted result, actual result, and correction.

Finished when every formula begins with `=` and uses a cell range.

## Spreadsheet chart and interpretation practice

Name: ____________________ Class: ______ Date: __________

1. State the question the chart should answer.
2. Write the category-and-value range: ____________________.
3. Choose column, bar, line, or pie. Explain why it fits.
4. Write the chart title and both labels.
5. Write two conclusions using exact values from the table.

Finished when another student can match every chart value to the source table.

## Media responsibility reflection

Write one specific example for each prompt.

1. How did you organize a working file so it could be found again?
2. How did you record or correct source credit?
3. What work shows steady effort rather than a last-minute submission?
4. What feedback did you receive, and what did you change?
5. What revision made the final work clearer or more accurate?
