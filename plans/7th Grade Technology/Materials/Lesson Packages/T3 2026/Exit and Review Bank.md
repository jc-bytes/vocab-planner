# Grade 7 T3 exit and review bank

Use one or two prompts for closure. These are formative and do not add another grade.

## Spreadsheets

1. Write one valid cell reference and explain both parts.
2. When would `AVERAGE` answer a better question than `SUM`?
3. What must a chart include so another person can read it without guessing?
4. Explain the difference between sorting and filtering.
5. Write one conclusion frame that requires an exact value.

## Scratch

1. Name one job that belongs in a custom block.
2. Which loop fits an exact count, and why?
3. Which loop fits a stopping condition, and why?
4. What should the main program control?
5. Write a repeatable test in one line.

## Sources and responsible media

1. Which author detail can be checked?
2. When does the date matter most?
3. What evidence makes a claim traceable?
4. How can purpose affect a source?
5. Name the four parts of a complete media credit.

## Sensor systems and Mandrake project

1. Identify the input, process, signal, and output.
2. What happens exactly at a `>` threshold?
3. Why test below, at, and above the boundary?
4. What makes a test controlled?
5. What evidence supports a threshold choice?
