# Mandrake Obstacle-Detection System exam brief

**Exam date:** December 4, 2026

## Goal

Build or simulate a micro:bit system that detects when a Mandrake is removed from its pot and triggers a warning. The ultrasonic sensor supplies a distance. The program compares it with a tested threshold. A Bluetooth message carries the alert and a sound output represents the scream.

## Fixed system requirements

- Use `IF distance > 18 cm, send ALERT by Bluetooth and play the warning sound; ELSE do not alert.` At 18 cm, there is no alert.
- Use only these required roles: micro:bit/controller; ultrasonic distance input; `> 18 cm` process; Bluetooth `ALERT` signal; computer, receiver micro:bit, or labeled simulator; warning-sound output; power/data cable; stable nonliving model/base.
- Code or labeled pseudocode shows: start; read distance; compare; true branch sends/plays warning; false branch does not alert; repeat reading.
- Do not use live plants, liquids, phones, web assets, photos, or screenshots.

## Required evidence

- Project plan with purpose, user need, parts, labeled flow, exact threshold rule, code plan, and test plan.
- Saved MakeCode project file or share link. A clearly labeled simulation is valid when hardware is unavailable.
- Project log with dated individual entries.
- Test record with values below, at, and above the boundary plus repeated reliability trials.
- One controlled improvement and retest.
- Live demonstration or approved make-up explanation.
- Short individual reflection.

Phones, photos, and screenshots are not evidence.

## Safety and scope

- Use only teacher-assigned micro:bit parts, cables, sensor, and output setup.
- Keep liquids away from electronics and disconnect power before changing wires.
- Do not change several variables at once during a controlled test.
- Stop and ask the teacher if a part becomes hot, damaged, or unstable.
