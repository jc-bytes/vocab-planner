# Daily Grade 5: Scratch Custom Block and Repeat Loop

**Date:** October 2, 2026  
**Evidence:** individual `.sb3`/working computer share link plus test sheet; paper block sequence is the equal fallback  
**Allowed:** Scratch Decomposition `#decompose-learn`, `#decompose-practice`, `#loops-learn`, `#loops-practice`, `#debug-practice`; [fixed starter and test sheet](<../Assessment Assets/Daily Grade 5 - Scratch Starter and Test Sheet.md>)  
**Not needed or accepted:** added game features, web assets, phones, photos, or screenshots

## Task

Build the fixed Robot delivery animation. Use the named `move one step` custom block, call it inside `repeat 4`, finish with `Delivered!`, and run the three fixed tests. Save as `Lastname_Firstname_7A-or-7B_Daily5_RobotDelivery.sb3`. Submit the `.sb3` file and test sheet, or return the paper fallback.

## What is scored (40 points)

- Four-part plan: start, reset position, repeated movement, finish message: 9
- Custom block: exact name, one movement job, definition, and active call: 9
- Loop: `repeat 4`, call inside loop, four equal moves, no copied movement sequence: 9
- Three complete tests plus one correction when a test fails: 9
- Filename, usable file/paper fallback, checklist, and responsible work process: 4

## Checklist

- [ ] My plan includes start, reset position, repeated movement, and the finish message.
- [ ] The `move one step` custom block has one movement job and an active call.
- [ ] `repeat 4` contains the custom-block call and produces four equal moves.
- [ ] I recorded all three tests and one correction if a test failed.
- [ ] I will submit the `.sb3` file and test sheet or return the paper fallback.

## Make-up and device failure

If Scratch is unavailable, arrange and label the same blocks on paper, trace the program using the three fixed tests, record results, and return the completed fallback.
