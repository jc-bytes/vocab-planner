# Teacher expected responses and check notes

Teacher-only. Do not project this file during independent practice or assessment.

## Spreadsheet practice

- `C4`: column C, row 4.
- Club table B2:B5 answers: `=SUM(B2:B5)` gives 78; `=AVERAGE(B2:B5)` gives 19.5; `=MIN(B2:B5)` gives 15; `=MAX(B2:B5)` gives 24.
- A column or bar chart fits category comparison. A complete source range includes labels and values.
- Supported example: Robotics has 24 students, 9 more than Music with 15.
- Filtered rows remain stored. Sorting rearranges records. Conditional formatting changes display, not values. `COUNTIF` counts entries matching one condition.

## Scratch practice

- Accept clear verb-and-object names such as `setup scene`, `move player`, and `check obstacle`.
- `repeat 10` fits a fixed count, `forever` fits continuous checking, and `repeat until` fits a stated stopping condition.
- A custom block that is never called does not run. A loop that never stops may have a condition that cannot become true. A score changing twice may have two scripts handling one event.
- A complete test names input/action, expected result, actual result, and one controlled correction.

## Source practice

- A credible decision cites author/organization, date, evidence/references, and purpose. Appearance alone is not evidence.
- For the controlled assessment source set, the museum article is strongest because it has an author, date, references, and educational purpose. The anonymous undated blog lacks checkable evidence. The advertisement has a sales purpose.
- A complete media credit names creator, title, original source, and license when available. Never accept "Google image" as the creator or source.

## Sensor practice

- Chain: ultrasonic sensor input, comparison with threshold, Bluetooth message signal, sound warning output.
- Rule `distance > 18`: 17 is false, 18 is false, 19 is true.
- If 18 produces an alert, likely code uses `>=` instead of `>`.
- Reliability requires repeated controlled trials. Change one likely cause, then repeat the same test.

## Daily-grade check notes

Use the existing rubric linked in each direction file. Confirm the deliverable opens before scoring. A missing or inaccessible working file is not replaced by a photo.

- Daily 1: exactly 10 assigned terms, accurate student-friendly definitions, one correct spreadsheet example per term, readable organization.
- Daily 2: fixed eight-row club CSV; `SUM`, `AVERAGE`, and `MAX` over B2:B9; A1:B9 column chart; exact title/labels; both fixed answers. See `Assessment Expected Responses.md`.
- Daily 3: usable decomposition plan, called custom block, useful loop, at least 3 typed tests, one improvement.
- Daily 4: four checks for each of three assigned sources, evidence-based decision, complete credit, responsible use.
- Daily 5: user need, input-process-output, signal, components, logical flowchart, exact boundary rule, at least 3 measurable tests.
