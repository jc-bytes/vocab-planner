# Grade 7 T3 assessment expected responses

Keep this file teacher-only. Accept equivalent student-friendly wording when the technical meaning and required example are correct.

## Daily Grade 1

Cell references: `spreadsheet` A2, its definition B2, its example C2; `chart` A11, its definition B11, its example C11.

| Term | Accepted meaning | Example |
|---|---|---|
| spreadsheet | File/tool that organizes data in cells and can calculate it | club attendance file |
| sheet | One tab/page inside a spreadsheet | Sheet1 |
| row | Horizontal line of cells, named by a number | row 2 |
| column | Vertical line of cells, named by a letter | column B |
| cell | Box where one value/formula is entered | the box at B2 |
| cell reference | Column letter plus row number locating a cell | B2 |
| formula | Calculation beginning with `=` | `=B2+B3` |
| function | Named built-in calculation | `SUM` |
| average | Sum divided by the number of values | `=AVERAGE(B2:B9)` |
| chart | Visual representation of table data | column chart comparing clubs |

## Daily Grade 5 — Scratch

Expected active order: green flag; reset/start position; `repeat 4` containing the call to `move one step`; `Delivered!` for 2 seconds. The custom block definition contains one movement instruction. Tests verify reset, exactly four moves, and one finish message.

## Daily Grade 4 — STEAM preparation and work process

Score each student's own evidence from the assigned cross-subject project: four preparation checks, four role-work checks, four responsible-work checks, and three log entries. Each log entry must name the individual task, a checkable result, and a next step. Project subject does not change the criteria.

## Daily Grade 3 — STEAM expo participation and closure

Score each student's own expo/closure evidence: four role actions, the five-part explanation, four closure checks, and the three-part individual reflection. The same criteria apply to Mathematics, Arts, Science, and Technology projects and to the shared-kit make-up record.

## Mandrake design milestone — exam process

Correct flow: start → read distance → compare `distance > 18` → true: send Bluetooth `ALERT` and play sound → false: no alert → repeat reading. At 17 and 18 cm there is no message/sound; at 19 cm there is an `ALERT` and sound.

## Appreciation Grade 2

The peer-review boundary must report no alert at 18 cm and Bluetooth/sound alerts at 19 cm. In the make-up sample, `>= 18` is the defect; revise it to `> 18` and trace the same-condition retest.

## Mandrake exam

The fixed system and boundary answers match the Mandrake design milestone. Six trials are 17, 18, 19, 19, 19, 19 cm. A controlled improvement changes one likely cause only, then repeats the same condition. Hardware success is not itself a criterion; the simulation/paper trace can demonstrate every logic and test requirement.
