# Daily Grade 5 fixed Scratch starter and test sheet

## Assigned animation: Robot delivery

Use the Scratch Cat or another built-in sprite. Start on the left side of the stage. The sprite must move to a delivery point in exactly four equal moves, say `Delivered!`, and stop.

Build this announced structure:

1. `when green flag clicked`
2. Go to the chosen starting position.
3. Call one custom block named `move one step`.
4. Put that call inside `repeat 4` so the same movement is not copied four times.
5. After the loop, say `Delivered!` for 2 seconds.

Define `move one step` with one clear movement instruction. Submit the `.sb3` file or working computer share link and this test sheet.
