## Class Objective

Build a Scratch response program that asks a question and uses if/else to give two different responses.

## Pre-Activities

- Sort statements into true and false, such as score > 5, answer = yes, lives < 1, or timer = 0.
- Review Week 5 practice vocabulary (part 1). operator: A symbol or block that compares or calculates comparison: Checking how two values are related logic: Rules used to make decisions

## While Activities

- Build a Scratch response program that asks a question and uses if/else to give two different responses. Test it with correct and incorrect answers.

## Post-Activities

- Explain how selection changes the program path. Submit a screenshot of the condition block.
