## Class Objective

Program an mBot movement pattern, test it twice, and adjust one speed or time value.

## Pre-Activities

- Predict the blocks needed to make the mBot move in a simple pattern. Review Week 3 practice vocabulary. movement: A change in position forward: Moving toward the front backward: Moving toward the back turn: To change direction speed: How fast something moves time: How long something happens stop: To end movement or action

## While Activities

- Complete Daily Grade #3: Label a screenshot of the mBlock interface with at least 6 areas and write one sentence explaining how blocks become robot instructions. Then program the mBot to move in a small square or triangle path, test the path twice, and change one speed or time value.

## Post-Activities

- Demonstrate one movement to another group. Explain how one code value changed the robot behavior.
