## Class Objective

Create a system map showing how mBot inputs, processes, outputs, and program steps work together.

## Pre-Activities

- Sort examples into hardware, software, input, process, and output. Review Week 4 practice vocabulary. system: Parts that work together input: Information that goes into a system or program process: The steps a system or program uses output: What a system or program produces sequence: Steps in the correct order debug: To find and fix a problem in code

## While Activities

- Create a simple system map showing how the mBot control board, sensors, motors, and mBlock program work together. Add arrows that show information or movement.

## Post-Activities

- Share your system map with a partner. Add one correction after feedback.
