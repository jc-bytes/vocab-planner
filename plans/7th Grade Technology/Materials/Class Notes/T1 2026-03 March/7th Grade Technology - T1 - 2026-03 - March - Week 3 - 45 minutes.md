## Class Objective

Connect mBlock movement commands to robot actions and record what each command does.

## Pre-Activities

- Write a human-robot instruction sequence for walking forward, turning, and stopping. Compare the instructions with block commands in mBlock.

## While Activities

- Connect the mBot to the computer. Program the robot to move forward, stop, move backward, and stop. Test each command once and record what the robot does. Practice identifying the main mBlock workspace areas before the graded interface check.

## Post-Activities

- Record one command that worked and one command that needed adjustment.
