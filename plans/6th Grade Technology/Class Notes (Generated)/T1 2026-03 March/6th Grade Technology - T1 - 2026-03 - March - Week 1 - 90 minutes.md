## Class Objective

Connect domain names with IP addresses and complete a vocabulary table for core internet communication terms.

## Pre-Activities

- Review Trimester 1 summative vocabulary with a quick Blooket or matching game: internet, website, browser, address, domain name, DNS, IP address, packet, message, network. No practice vocabulary this week; focus on the summative vocabulary table. Complete a short definition check for the four words.

## While Activities

- Look up two websites and record their domain name and IP address. Compare your results with a partner. Complete Summative Activity #1: Create a vocabulary table with definition, illustration, and example sentence for these words: internet, website, browser, address, domain name, DNS, IP address, packet, message, network. Submit your vocabulary table in class or on Google Classroom.

## Post-Activities

- Share one word from the summative table that you understand better now. Write one question you still have about internet addresses.
