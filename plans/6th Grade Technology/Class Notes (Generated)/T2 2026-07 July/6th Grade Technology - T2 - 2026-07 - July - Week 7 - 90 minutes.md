## Class Objective

## Pre-Activities

- Complete a word soup or matching activity using July Week 3 practice vocabulary (part 2). line: long mark or path input: information or action going in response: what happens after Review the mBot Knowledge Card connected to the available sensor.

## While Activities

- Observe how the sensor reacts to an object or line. Test the sensor in two different situations. Record what changed in each test. Create one simple response using the sensor.

## Post-Activities

- Demonstrate one sensor response. Write what the sensor detected.
