## Class Objective

Create a program that shows text or an icon on the LED display.

## Pre-Activities

- Complete a word soup or crossword puzzle using November Week 2 practice vocabulary (part 2). button: thing you click or press display: screen or lights icon: small picture or symbol Open your first micro:bit project.

## While Activities

- Review feedback from the micro:bit input/output check if needed. Create a program that shows text or an icon on the LED display. Add a button A action. Add a button B action. Test the program in the simulator or device. Complete make-up work for Summative Activity #5 only if needed.

## Post-Activities

- Show your working button program. Write which input your program used.
