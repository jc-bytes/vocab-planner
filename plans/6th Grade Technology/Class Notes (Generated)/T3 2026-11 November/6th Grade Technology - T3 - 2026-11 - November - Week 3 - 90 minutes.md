## Class Objective

Create a variable that starts at 0.

## Pre-Activities

- Review November Week 3 practice vocabulary with Blooket or matching cards (part 2). decrease: make smaller counter: program or value that counts reset: set back to the start Open or create your counter project.

## While Activities

- Create a variable that starts at 0. Program a button to increase the value. Display the current value on the LED screen. Add a second button to decrease or reset the value if time allows.

## Post-Activities

- Demonstrate the counter program. Complete a short reflection about how the variable changed.
