## Class Objective

Create an if/then flowchart practice task with one micro:bit light or temperature condition, one true output, one false output, and one sentence explaining the program.

## Pre-Activities

- Complete a word soup or crossword puzzle using December Week 1 practice vocabulary (part 2). temperature: how hot or cold message: information sent to someone flowchart: diagram of steps or choices Choose the sensor response option you will build.

## While Activities

- Create an if/then flowchart practice task with one micro:bit light or temperature condition, one true output, one false output, and one sentence explaining the program. Submit the completed flowchart in class or on Google Classroom as project evidence. Create one guided sensor program. Use light level or temperature as the input. Show a different icon, message, or output based on the condition. Test the program in two different conditions.

## Post-Activities

- Demonstrate one sensor response. Write what the sensor detected.
