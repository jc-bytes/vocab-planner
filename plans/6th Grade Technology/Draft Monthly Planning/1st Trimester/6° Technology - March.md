# 6° Technology - March 2026

## Monthly Focus

Students explore how the internet works and how people communicate and collaborate online. Students finish the month by observing website features and planning a simple web page.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- vocabulary cards or Blooket/Gimkit set
- packet simulation strips
- IP/domain recording sheet
- website feature planning sheet
- projector
- internet access
- Google Classroom submission space

## Competences

- Explain basic internet communication ideas using clear examples and classroom vocabulary.
- Use online communication and shared digital work responsibly by considering audience, privacy, and permission.
- Identify useful website features and plan a simple web page for a clear audience and purpose.

## Learning Objectives

- Identify domain names, IP addresses, DNS, packets, and message delivery through simple examples.
- Compare online communication and collaboration choices using safe and responsible scenarios.
- Recognize website parts such as title, menu, links, images, and sections and sketch a simple page layout.

## Learning Outcomes

- Complete a vocabulary table for core internet terms with definitions, illustrations, and example sentences.
- Complete packet, collaboration, and responsible communication activities with short written explanations.
- Answer an online communication scenario quiz and submit a simple website feature and page plan.

## Evaluation

- Complete vocabulary practice activities.
- Submit notebook reflections and exit tickets.
- Complete packet and website planning activities.
- Complete Summative Activity #1: Create a vocabulary table with definition, illustration, and example sentence for these words: internet, website, browser, address, domain name, DNS, IP address, packet, message, network.
- Complete Summative Activity #2: Answer 8 online communication scenarios by choosing public or private, naming the audience, and deciding if permission is needed.

## Teacher Reality Notes

- Main purpose: understand internet communication basics before website creation.
- Grade evidence: Summative Activity #1 is the completed Trimester 1 summative vocabulary table; grade definition accuracy, illustration/example match, and completion. Summative Activity #2 is the completed scenario quiz; grade the selected privacy/audience/permission choices and one-sentence explanations.
- Flow guardrail: keep warm-ups to 10 minutes. If the DNS/IP lookup takes longer than expected, reduce it to one teacher-modeled example plus one student example.
- Materials to prepare: vocabulary cards or Blooket/Gimkit set, packet simulation strips, IP/domain recording sheet, website feature planning sheet, projector, internet access, Google Classroom submission space.
- Make-up option: vocabulary table and scenario quiz can both be completed independently from printed copies or Google Classroom.
- Risk: packet simulation can expand past the 90-minute block; assign group roles before starting and stop with 10 minutes left for the written closure.
