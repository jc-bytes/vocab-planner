# 6° Technology - October 2026

## Monthly Focus

Students finish the mBot STEM bridge by creating a chart and conclusion from project data, complete a compact 3D model design task, and finish the last counted trimester summative with a micro:bit parts and input/output check before the November holiday period.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- mBot STEM data table
- mBot chart checklist
- chart checklist
- Tinkercad or 3D tool accounts
- 3D model design-plan template
- screenshot/export instructions
- micro:bit parts worksheet
- input/output sorting check
- micro:bits or MakeCode simulator
- projector
- internet access

## Competences

- Use spreadsheets to present mBot STEM project data with charts.
- Interpret chart information and write a simple conclusion from project data.
- Create and improve a basic 3D model from a labeled design plan.
- Identify micro:bit parts and sort simple examples into input or output.

## Learning Objectives

- Review a mBot STEM data table and choose a chart that answers a project question.
- Create a chart from the mBot STEM data set with title, labels, answers, and a conclusion.
- Use basic 3D modelling actions such as move, resize, rotate, duplicate, group, and improve.
- Label important micro:bit parts and classify simple input/output examples.

## Learning Outcomes

- Submit a mBot STEM chart task with title, labels, answers, and conclusion.
- Complete a 3D model design with sketch, at least three labeled shapes, purpose, planned improvement, and simple model or screenshot evidence.
- Complete a micro:bit parts and input/output check.

## Evaluation

- Submit a mBot STEM chart with a short explanation.
- Submit a 3D modelling practice file.
- Complete Summative Activity #3: Create one chart from the mBot STEM data set, add a title and labels, answer 3 questions about the chart, and write one conclusion sentence.
- Complete Summative Activity #4: Create a 3D model design with a sketch, at least 3 labeled shapes, the model purpose, one planned improvement, and simple model or screenshot evidence.
- Complete Summative Activity #5: Label 5 micro:bit parts and sort 8 examples into input or output.

## Teacher Reality Notes

- Main purpose: close the mBot STEM data bridge, finish the counted 3D design task, and collect the final formal IIIT grade before November holidays.
- Grade evidence: Summative Activity #3 is the mBot STEM chart task; grade correct chart from project data, title/labels, three answers, and conclusion sentence. Summative Activity #4 is the 3D model design; grade sketch/design plan, at least 3 labeled shapes, purpose, one planned improvement, and simple model or screenshot evidence. Summative Activity #5 is the micro:bit parts/input-output check; grade correct labels and sorting.
- Flow guardrail: keep the first 3D modelling build to one simple object. Do not require printing or advanced measurement in October.
- Materials to prepare: mBot STEM data table, chart checklist, Tinkercad or 3D tool accounts, 3D model design template, screenshot/export instructions, micro:bit parts worksheet, input/output sorting check, micro:bits or MakeCode simulator, projector, internet access.
- Make-up option: chart task can be made up with teacher-provided mBot data; 3D design can be made up on paper before a device session; micro:bit input/output check can be made up on paper.
- Risk: account setup for Tinkercad or another 3D tool can take most of the class. Confirm accounts/logins before Week 3.

### Practice Vocabulary

#### October Week 1 - mBot Charts

| Word | Simple definition |
| --- | --- |
| chart | A visual way to show data. |
| title | The name of a page, chart, or project. |
| label | A word or short phrase that names something. |
| category | A group used to sort information. |
| axis | A line on a chart that helps show values or categories. |
| compare | To look at two or more things to see what is similar or different. |
| conclusion | An idea you decide after looking at evidence. |

| resize | To make something bigger or smaller. |
| rotate | To turn something around. |
| duplicate | To make a copy. |
