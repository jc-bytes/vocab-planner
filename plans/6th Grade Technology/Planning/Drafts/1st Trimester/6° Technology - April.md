# 6° Technology - April 2026

## Monthly Focus

Students create and improve a simple website, then begin using variables in Scratch through small game activities.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- copyright image-choice form
- website checklist
- Scratch score starter or example
- Scratch accounts or offline access
- Google Sites access
- projector
- internet access

## Competences

- Choose and credit digital images responsibly for a web page.
- Build and improve a simple web page structure with a clear title, sections, images, and links.
- Use a Scratch variable to create and test a simple score task.

## Learning Objectives

- Decide whether an image is safe to use by checking source, permission, and credit needs.
- Organize a web page with basic structure, navigation, and clear link labels.
- Create a simple Scratch score program using one variable and debug one problem.

## Learning Outcomes

- Submit a copyright image-choice check with source, use decision, fit explanation, and credit line.
- Build and preview web page sections and link/navigation tasks using feedback.
- Submit a Scratch score task with two clickable sprites, a working variable, and a short explanation.

## Evaluation

- Complete website checklist activities.
- Complete vocabulary review activities.
- Submit a Scratch mini-project.
- Complete Summative Activity #3: Select one image for the assigned web page topic, record its source, decide if it is safe to use, explain why it fits the topic, and write the credit line.
- Complete Summative Activity #4: Create a Scratch score task with one variable and two clickable sprites that change the score by different amounts, then explain what each sprite does to the score. Test the score task and fix one problem. Show the working score task and submit the short explanation.

## Teacher Reality Notes

- Main purpose: move from responsible media use to a small working web/Scratch product.
- Grade evidence: Summative Activity #3 is the image-selection form; grade source, safe-use decision, topic fit, and credit line. Summative Activity #4 is the Scratch score task plus explanation; grade one variable, two score-changing sprites, successful test, and explanation of how the score changes.
- Flow guardrail: Google Sites/Scratch login time can consume the class. Have links, accounts, and starter files ready before class; if login fails, students complete the same task on the planning/checklist sheet.
- Materials to prepare: copyright image-choice form, website checklist, Scratch score starter or example, Scratch accounts or offline access, Google Sites access, projector, internet access.
- Make-up option: image-choice form can be made up on paper; Scratch mini-task may need a supervised device session.
- Risk: the Week 2 and Week 3 website classes can take too long if students redesign the whole page. Limit improvements to two visible changes.
