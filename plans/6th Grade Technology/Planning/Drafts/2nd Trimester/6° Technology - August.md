# 6° Technology - August 2026

## Monthly Focus

Students finish the mBot unit by preparing for and completing the teacher-assigned Summative #5 mBot Rescue Robot task. Students practice line following, obstacle decisions, branch checks, stopping logic, testing, and equipment care.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- charged and numbered mBots
- assigned Rescue Robot mBlock starter project
- Summative #5 task sheet and rubric
- mBot readiness checklist
- teacher-prepared rescue route

## Competences

- Combine line-sensor input, ultrasonic distance checks, conditions, and movement responses in a teacher-assigned rescue route.
- Modify, test, debug, and demonstrate an assigned mBlock project.
- Explain the robot's line-following, obstacle, branch, and stop logic in English.
- Follow all numbered-kit, cable, connection, shutdown, and return procedures.

## Learning Objectives

- Review and practice the line-following corrections and ultrasonic branch decisions required by the assigned rescue route.
- Modify and test the assigned Rescue Robot project in controlled stages.
- Explain the sensor checks, conditions, branches, and final stop behavior.
- Demonstrate and submit the assigned project while following equipment procedures.

## Learning Outcomes

- Complete guided line-following and obstacle-decision practice.
- Test the assigned rescue route, record one problem and correction, and prepare an English explanation.
- Complete Summative #5 in Week 11 by presenting and demonstrating the Rescue Robot route, saving and submitting the assigned project, and returning the numbered kit correctly.

## Evaluation

- Complete guided line-following, ultrasonic sensing, and branch-decision practice.
- Rehearse the teacher-assigned rescue route and explanation.
- Complete Summative Activity #5: With a partner, modify the assigned mBlock project so the mBot follows the line, detects blocked paths, turns onto an open branch, and stops when the front, left, and right are blocked; then test, demonstrate, save, submit, explain in English, and complete all equipment procedures.

## Teacher Reality Notes

- Main purpose: finish robotics with the same teacher-assigned Rescue Robot task for all pairs.
- Grade evidence: Summative Activity #5 is the mBot Rescue Robot rubric supplied for Grade 6; grade line-following code, obstacle/rescue-zone code, route performance, mBlock use, English explanation, device/lab care, and punctuality/readiness/respect.
- Assignment guardrail: students do not choose the challenge type, route, or final behavior. The teacher provides the route, starter project, required logic, and success condition.
- Calendar guardrail: Summative #5 must be completed in Week 11. Week 12 contains formative Grade 6 activities only because secondary-level exams are taking place.
- Flow guardrail: teams should work in pairs when possible. If groups of three are necessary, assign driver, tester, and recorder so the grading evidence shows each student's contribution.
- Materials to prepare: charged and numbered mBots, assigned Rescue Robot starter project, Summative #5 task sheet and rubric, teacher-prepared line/branch route, obstacle blocks, connection checklist, projector, computers/software.
- Make-up option: code reading and English explanation can be completed from screenshots; route performance, connection, and equipment criteria require a supervised robot station.
- Risk: route testing can create a bottleneck. Use two identical test lanes when possible and test line following before adding obstacle branches.

## Vocabulary Plan

### Practice Vocabulary

#### August Week 1 - Line Following

| Word | Simple definition |
| --- | --- |
| line sensor | A sensor that detects the dark line and the lighter floor. |
| correction | A small turn used to return the robot to the line. |
| loop | Code that repeats while the robot is running. |
| forward | Moving toward the front. |
| left | The direction opposite right. |
| right | The direction opposite left. |
| lost line | A condition when the sensor no longer detects the route. |

#### August Week 2 - Rescue Decisions

| Word | Simple definition |
| --- | --- |
| obstacle | Something that blocks the route. |
| branch | A path that turns away from the main route. |
| blocked | Not open for the robot to continue. |
| open | Clear for the robot to move through. |
| condition | A rule the program checks. |
| rescue zone | The assigned area where the robot must stop. |

#### August Week 3 - Demonstration and Care

| Word | Simple definition |
| --- | --- |
| demonstrate | To show clearly how something works. |
| test | To try something and see if it works. |
| debug | To find and fix a problem in a program. |
| improve | To make something better. |
| explain | To make an idea clear with words. |
| submit | To turn in completed work. |
| disconnect | To safely remove a cable or connection. |
