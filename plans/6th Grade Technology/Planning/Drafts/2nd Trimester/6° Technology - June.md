# 6° Technology - June 2026

## Monthly Focus

Students begin the mBot robotics unit by learning routines, identifying parts, preparing the robot, and creating basic movement programs.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password. For me: mBots
- USB cables
- batteries
- mBot Knowledge Cards Part 1
- parts diagram
- movement/debugging checklist
- projector
- computers with required software
- student's email and password

## Competences

- Use robotics materials safely and responsibly by following classroom routines.
- Identify and describe the main parts of the mBot and their basic functions.
- Create, test, and improve simple mBot movement programs using basic commands.

## Learning Objectives

- Recognize and name the main components of the mBot and explain their basic functions.
- Follow safety and setup routines when preparing and handling robotics materials.
- Program the mBot to perform simple movements, modify values such as speed and time, and debug simple problems.

## Learning Outcomes

- Complete robotics vocabulary activities and submit a labeled mBot diagram.
- Create and run a simple mBot movement program using basic commands in the correct sequence.
- Complete a vocabulary table and a movement debugging check.

## Evaluation

- Complete robotics vocabulary activities and submit a labeled mBot diagram.
- Create and run a simple mBot movement program using basic commands in the correct sequence.
- Complete Summative Activity #1: Create a vocabulary table with definition, illustration, and example sentence for these words: robot, mBot, program, instruction, safety, motor, wheel, sensor, LED, buzzer.
- Complete Summative Activity #2: Review 3 simple mBot movement sequences, identify the mistake in each one, write the corrected command or value, and explain one correction.

## Teacher Reality Notes

- Main purpose: establish safe mBot routines and reliable basic movement.
- Grade evidence: Summative Activity #1 is the robotics vocabulary table; grade correct meanings, examples, and diagrams. Summative Activity #2 is the movement debugging check; grade identified mistake, corrected command/value, and one explanation. Movement demonstrations are observed with a simple checklist: robot prepared safely, program runs, one movement works, one change is explained.
- Flow guardrail: do not grade robot speed or route perfection in June. Grade setup, vocabulary, sequencing, and one visible improvement.
- Materials to prepare: charged mBots, USB cables, batteries/chargers, mBot Knowledge Cards Part 1, parts diagram, movement/debugging checklist, mbot basic map, projector, computers with required software.
- Make-up option: vocabulary and debugging checks can be made up on paper; movement demonstration needs a supervised robot station.
- Risk: hardware setup can take too long. Number kits, pre-check batteries, and assign pair roles before the first 90-minute robot class.
