# 6° Technology - December 2026

## Monthly Focus

Students use micro:bit sensors and simple conditions to create a small interactive project. The final evaluation is familiar and controlled: students demonstrate one program and explain how it works.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- flowchart template
- final project planning sheet
- demonstration rubric/checklist
- reflection form
- micro:bits or MakeCode simulator
- USB cables
- batteries if needed
- projector
- computers/internet

## Competences

- Use micro:bit sensors and conditions to create simple interactive responses.
- Plan, test, and improve a small program with input, output, variable, or condition logic.
- Demonstrate a final interactive program and explain its purpose in simple language.

## Learning Objectives

- Create an if/then flowchart using one light or temperature condition with true and false outputs.
- Build and test a guided sensor response program in two different conditions.
- Prepare and present a short explanation of the final program, input, output, and improvement.

## Learning Outcomes

- Complete a micro:bit sensor condition flowchart with one explanation sentence.
- Submit a final interactive project plan and test evidence.
- Demonstrate a final micro:bit project and complete a short closing reflection.

## Evaluation

- Complete sensor and condition vocabulary activities.
- Demonstrate a final micro:bit project.
- Submit a simple explanation/reflection.
- Complete Summative Activity #5: Create an if/then flowchart with one micro:bit light or temperature condition, one true output, one false output, and one sentence explaining the program.

## Teacher Reality Notes

- Main purpose: complete a controlled micro:bit project using familiar inputs, outputs, conditions, or variables.
- Grade evidence: Summative Activity #5 is the sensor condition flowchart; grade one sensor condition, true output, false output, and explanation sentence. Final project evidence is the demonstration checklist plus reflection: one input, one output, one condition or variable, test result, one improvement, and explanation of how it works.
- Flow guardrail: keep the final project menu small. Students choose from alarm, mood display, counter, reaction game, night light, or step-counter-style idea; no new advanced features are required.
- Materials to prepare: flowchart template, final project planning sheet, demonstration rubric/checklist, reflection form, micro:bits or MakeCode simulator, USB cables, batteries if needed, projector, computers/internet.
- Make-up option: flowchart can be made up independently; final demonstration needs a short device/simulator appointment.
- Risk: Week 3 demonstrations can be interrupted by end-of-year events. Collect the project file or screenshot before presentation day so grading evidence is not lost.
