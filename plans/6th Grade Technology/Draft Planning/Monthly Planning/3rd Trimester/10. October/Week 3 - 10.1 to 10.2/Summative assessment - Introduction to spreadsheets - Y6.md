## Introduction to spreadsheets

Q1. Which of these statements are true about spreadsheets? (Tick all that apply)

- Calculations can be used on any data type in a spreadsheet

- Data can be calculated using different operations within the spreadsheet

- Charts can be produced using the data held in spreadsheets
