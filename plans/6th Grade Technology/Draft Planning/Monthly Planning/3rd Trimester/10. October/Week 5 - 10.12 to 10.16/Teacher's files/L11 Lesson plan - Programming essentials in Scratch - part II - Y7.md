# Lesson 11: Translate this! (Part 1)

Enjoyed teaching these lessons? Found a mistake? Share feedback at the-cc.io/feedback.

## Introduction

Learners are to be given a scenario to create a translation quiz for a Modern Foreign Languages teacher. The learners should decompose the problem and start to build a Scratch program to meet the requirements. This is a pair programming project that takes place over two lessons; pairs will develop their programs to differing levels. A rubric is used for peer- or self-assessment to monitor learners’ progress. Extension activities allow learners to explore more challenging aspects of the solution. In Lesson 12, learners will be given a multiple choice quiz as a formal final assessment.

## Learning objectives

- To decompose a larger problem into smaller subproblems

- To apply appropriate constructs to solve a problem

## Key vocabulary

Decomposition

## Assessment opportunities

Lessons 11 and 12 involve a pair programming activity. A rubric has been provided in order for learners to peer- or self-assess their work.

A multiple choice quiz has been provided to individually assess the progress of each learner. This will be completed in Lesson 12.

## Outline plan

Please note that the slide deck labels the activities in the top right-hand corner to help you navigate the lesson.

*Timings are rough guides

| Starter activity<br>(Slide 2)<br>5 mins | Provide an example of decomposition<br>Ask learners to provide an example of decomposition using think, write, pair, share. There is also an explorer task which asks learners how decomposition can help when they may find problem solving difficult.<br>Give learners some time to develop an answer, then discuss with the class. The purpose of this activity is to remind learners what decomposition is and let them know that when they are finding a problem difficult to solve, it is most likely because they have not decomposed it enough. |
| --- | --- |
| Activity 1<br>(Slide 4–5)<br>5 mins | Introducing the scenario<br>Ensure that learners all have access to the scenario. Tell the learners that they will be completing a Scratch project based on the scenario given as a pair programming activity. Some decomposition has already been done for the learners by breaking the scenario down into smaller chunks that are labelled as tasks.<br>In their pairs, learners must read the scenario and predict where they think they are most likely to get stuck. There will be a variety of answers to this but the most likely outcome is that learners will find Task 4 the most challenging.<br>Remind learners that when a problem becomes too difficult to solve, it needs to be further decomposed. Learners need to get a small part of the task working for them to then build it up. Learners will practise this in the next activity. |
| Activity 2 (Slide 6–7)<br>5-10 mins | Breaking a task down further: Task 4a<br>Learners will most likely look at Task 4a and wonder how they will ever be able to complete it. Read the task to the learners: “Translate the word into the desired language using the Translate Extension”.<br>This contains new things that they haven’t yet experienced and they might even be struggling with the word ‘translate’. Remind learners that it is OK to feel a little confused by this and that they just need to break the task down.<br>Learners will now complete a short pair programming activity where they will translate a word into the desired language using the Translate Extension. The aim of this activity is to teach learners the new concept of translation but to also build their confidence in decomposing a task that initially looks too difficult to solve. |
| Activity 3<br>(Slide 8)<br>40 mins | Starting the project<br>You may wish to spend some time here going through the self- or peer- assessment rubric with your learners. A link to the rubric is available from the slides.<br>Learners will now work on the project in their pairs. There are several support sheets available that will help to scaffold this project. It is up to you how you distribute these support sheets. This is the first time that learners have tackled a problem on this scale, so it is important that scaffolding is there if they need it.<br>The support sheets are designed to slowly remove the scaffolding through questioning and guidance. This will help build the learners’ confidence in their ability to tackle a challenging project. |
| Plenary<br>(Slide 9–10)<br>5 mins | How are you getting on?<br>Learners have time to reflect on their progress with another pair. Learners should state one thing that they found easy and one thing that they struggled with, before they spend some time offering advice to each other.<br>Review the summary slide. |
