# 6° Technology - October 2026

## Monthly Focus

Students finish the mBot STEM bridge by creating a chart and conclusion from project data, then resume the regular 3D modelling sequence through simple hands-on design tasks.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- mBot STEM data table
- mBot chart checklist
- chart checklist
- Tinkercad or 3D tool accounts
- 3D model design-plan template
- screenshot/export instructions
- projector
- internet access

## Competences

- Use spreadsheets to present mBot STEM project data with charts.
- Interpret chart information and write a simple conclusion from project data.
- Create and improve a basic 3D model from a labeled design plan.

## Learning Objectives

- Review a mBot STEM data table and choose a chart that answers a project question.
- Create a chart from the mBot STEM data set with title, labels, answers, and a conclusion.
- Use basic 3D modelling actions such as move, resize, rotate, duplicate, group, and improve.

## Learning Outcomes

- Submit a mBot STEM chart task with title, labels, answers, and conclusion.
- Submit 3D modelling practice evidence showing basic shape tools.
- Complete a 3D model design plan with sketch, at least three labeled shapes, purpose, and planned improvement.

## Evaluation

- Submit a mBot STEM chart with a short explanation.
- Submit a 3D modelling practice file.
- Complete Summative Activity #2: Create one chart from the mBot STEM data set, add a title and labels, answer 3 questions about the chart, and write one conclusion sentence.
- Complete Summative Activity #3: Create a 3D model design plan with a sketch, at least 3 labeled shapes, the model purpose, and one planned improvement.

## Teacher Reality Notes

- Main purpose: close the mBot STEM data bridge with a chart, then start 3D modelling with a small planned model.
- Grade evidence: Summative Activity #2 is the mBot STEM chart task; grade correct chart from project data, title/labels, three answers, and conclusion sentence. Summative Activity #3 is the 3D design plan; grade sketch, at least 3 labeled shapes, purpose, and one planned improvement. The 3D file/screenshot is practice evidence for tool use.
- Flow guardrail: keep the first 3D modelling build to one simple object. Do not require printing or advanced measurement in October.
- Materials to prepare: mBot STEM data table, chart checklist, Tinkercad or 3D tool accounts, 3D model design-plan template, screenshot/export instructions, projector, internet access.
- Make-up option: chart task can be made up with teacher-provided mBot data; 3D design plan can be made up on paper before a device session.
- Risk: account setup for Tinkercad or another 3D tool can take most of the class. Confirm accounts/logins before Week 3.

## Vocabulary Plan

### Practice Vocabulary

#### October Week 1 - mBot Charts

| Word | Simple definition |
| --- | --- |
| chart | A visual way to show data. |
| title | The name of a page, chart, or project. |
| label | A word or short phrase that names something. |
| category | A group used to sort information. |
| axis | A line on a chart that helps show values or categories. |
| compare | To look at two or more things to see what is similar or different. |
| conclusion | An idea you decide after looking at evidence. |

#### October Week 2 - 3D Basics

| Word | Simple definition |
| --- | --- |
| 3D | Having height, width, and depth. |
| shape | A form such as a cube, sphere, or cylinder. |
| move | To change where something is. |
| resize | To make something bigger or smaller. |
| rotate | To turn something around. |
| duplicate | To make a copy. |

#### October Week 3 - Design Prototype

| Word | Simple definition |
| --- | --- |
| model | A simple version or design of something. |
| design | A plan for how something will look or work. |
| prototype | A first version used for testing. |
| sketch | A quick drawing of an idea. |
| group | To join objects so they work as one. |
| improve | To make something better. |
| purpose | The reason something is made or used. |
| feedback | Helpful comments about work. |
