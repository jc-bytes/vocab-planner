# 6° Technology - September 2026

## Monthly Focus

Students begin the data and spreadsheet unit through simple classroom examples. Students organize information, format it clearly, and use basic formulas.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- spreadsheet vocabulary cards
- prepared data-set template
- formula practice file
- Google Sheets or spreadsheet software access
- projector
- internet/accounts if using Google Sheets

## Competences

- Organize simple data in a spreadsheet using rows, columns, cells, headers, and tables.
- Format spreadsheet information so it is easier to read and compare.
- Use simple formulas to calculate values and explain how inputs affect outputs.

## Learning Objectives

- Identify spreadsheet parts and use them to create a small class data table.
- Format titles, headers, columns, and cells to make data clear.
- Practice basic formulas and cell references using a prepared spreadsheet task.

## Learning Outcomes

- Complete a spreadsheet vocabulary table with definitions, illustrations, and example sentences.
- Submit a clean formatted data table based on a small class data set.
- Complete formula practice tasks and explain one input/output change.

## Evaluation

- Complete spreadsheet vocabulary activities.
- Submit a small formatted data table.
- Complete formula practice tasks.
- Complete Summative Activity #1: Create a vocabulary table with definition, illustration, and example sentence for these words: spreadsheet, data, information, row, column, cell, table, header, formula, chart.

## Teacher Reality Notes

- Main purpose: build spreadsheet foundations before formulas and charts.
- Grade evidence: Summative Activity #1 is the spreadsheet vocabulary table; grade correct definition, example sentence, and illustration for each word. The formatted data table is practice evidence; check title, headers, rows/columns, and readable formatting.
- Flow guardrail: use a prepared spreadsheet file for formula practice. Students should not spend the 90-minute formula class building the file from scratch.
- Materials to prepare: spreadsheet vocabulary cards, prepared data-set template, formula practice file, Google Sheets or spreadsheet software access, projector, internet/accounts if using Google Sheets.
- Make-up option: vocabulary table can be made up on paper; formula practice needs access to the prepared file.
- Risk: formulas become abstract quickly. Model one example before independent work and require students to record one input-output change.

### Practice Vocabulary

#### September Week 2 - Formulas

| Word | Simple definition |
| --- | --- |
| formula | A rule or calculation used by a spreadsheet. |
| cell reference | The name of a cell, such as A1. |
| sum | The result of adding numbers together. |
| average | A usual or middle value found from a group of numbers. |
| input | Information or an action that goes into a device or program. |
| output | What a device does or shows after a program runs. |
| value | A number or piece of data in a program or spreadsheet. |
