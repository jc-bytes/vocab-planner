# 6° Technology - September 2026

## Monthly Focus

Students begin Trimester 3 with an mBot STEM bridge. They inspect the ready robots from Trimester 2, plan and run a second controlled challenge, collect class data, and use spreadsheets to organize and calculate results.

## Weekly Time

- Class 1: 45 minutes
- Class 2: 90 minutes
- Weekly total: 3 class hours

## Main Resources

- Pen
- pencil
- technology notebook
- student's email and password
- mBot readiness checklist from Trimester 2
- mBot STEM data collection sheet
- spreadsheet vocabulary cards
- prepared mBot data-set template
- formula practice file
- Google Sheets or spreadsheet software access
- projector
- internet/accounts if using Google Sheets

## Competences

- Inspect and reuse ready mBots safely for a second controlled STEM challenge.
- Organize mBot challenge data in a spreadsheet using rows, columns, cells, headers, and tables.
- Format spreadsheet information and use simple formulas to calculate values and explain how inputs affect outputs.

## Learning Objectives

- Check robot readiness evidence from Trimester 2 and plan a second challenge.
- Collect mBot challenge data and enter it into a clean spreadsheet table.
- Practice basic formulas and cell references using the mBot data set.

## Learning Outcomes

- Submit a clean mBot STEM data table based on the second challenge.
- Complete formula practice tasks using the mBot data set.
- Explain one input/output or quantity/result change from the project data.

## Evaluation

- Complete spreadsheet vocabulary activities.
- Submit a small formatted mBot STEM data table.
- Complete formula practice tasks.
- Complete Summative Activity #1: Create a clean mBot STEM data table with at least 6 records, headers, units/categories, readable formatting, and one sentence explaining what the data shows.

## Teacher Reality Notes

- Main purpose: use the ready mBots to bridge robotics into spreadsheet foundations.
- Grade evidence: Summative Activity #1 is the mBot STEM data table; grade headers, records, units/categories, readable formatting, and one data sentence. Vocabulary is practice support, not an extra grade.
- Flow guardrail: use a prepared spreadsheet file for formula practice. Students should not spend the 90-minute formula class building the file from scratch.
- Materials to prepare: ready mBots, readiness checklist, mBot STEM data collection sheet, prepared mBot data-set template, formula practice file, Google Sheets or spreadsheet software access, projector, internet/accounts if using Google Sheets.
- Make-up option: students can use teacher-provided mBot data cards if their robot cannot run.
- Risk: robot setup can consume the spreadsheet lesson. Use the readiness checklist first and stop the robot run early enough to enter data.

## Vocabulary Plan

### Practice Vocabulary

#### September Week 1 - mBot Data Tables

| Word | Simple definition |
| --- | --- |
| data | Information collected from a test or activity. |
| record | One complete row of information. |
| header | A label at the top of a column. |
| table | Information arranged in rows and columns. |
| result | What happened after a test. |
| readiness | Being prepared to use materials safely. |

#### September Week 2 - Formulas

| Word | Simple definition |
| --- | --- |
| formula | A rule or calculation used by a spreadsheet. |
| cell reference | The name of a cell, such as A1. |
| sum | The result of adding numbers together. |
| average | A usual or middle value found from a group of numbers. |
| input | Information or an action that goes into a device or program. |
| output | What a device does or shows after a program runs. |
| value | A number or piece of data in a program or spreadsheet. |
