# Lesson 2: Formatting a spreadsheet

Enjoyed teaching these lessons? Found a mistake? Share feedback at the-cc.io/feedback.

## Introduction

Learners will develop their understanding of the structure of a spreadsheet. They will be introduced to cell references, data items, and the concept of formatting cells. Learners will see data items formatted in different ways. They will then choose formats for data items before they apply formats in their own spreadsheets.

## Learning objectives

To build a data set in a spreadsheet

- I can explain what an item of data is

- I can choose an appropriate format for a cell

- I can apply an appropriate format to a cell

## Key vocabulary

Cell, cell reference, data item, format

## Preparation

Subject knowledge:

You will need to be familiar with the way in which cells in spreadsheets can be formatted. Formatting is used to make data easier to work with and more readable. For example, a currency formatted cell will include a unit of currency and can be set to include decimal places. This lesson looks at the following formats:

- Plain text

- Date

- Number

- Duration

- Currency

You will need:

- Slides

- Access to a spreadsheet application

- A1 – Dry wipe boards and pens

- L2 Resource – Spreadsheet

- A2 Handout – Which format?

- A2 Solution – Which format?

- A3 Handout – Applying formats

## Assessment opportunities

Activity 1: Assess learners’ ability to recognise data items and that there are different types of data items.

Activity 2: Assess learners’ ability to recognise different data formats.

Activity 3: Assess learners’ ability to create and apply formatting to a data set.

*Timings are rough guides

| Starter activity<br>(Slide 1–5)<br>5 mins | Introduction<br>Introduce the lesson and the learning objectives.<br>Show slide 3. Tell the learners that each of the boxes that make up a spreadsheet is called a cell.<br>Show slide 4. Explain that each cell has a unique cell reference. This means learners can say where a particular piece of data is stored. Explain to the learners that they can find out a cell reference by using the letters along the top of the columns in the table and the numbers down the left-hand side of the rows.<br>On slide 5, demonstrate that the word ‘Name’ is in cell A1. |
| --- | --- |
| Activity 1<br>(Slide 6)<br>5 mins | What is a data item?<br>Show slide 6. Ask the learners to write on dry wipe boards what is contained in cells A2, B5, C3, and B1. Ask them what they notice about the contents of these cells. Build the slide to show that each cell contains a data item, and these data items can be different formats. In this case, plain text, number, and currency. |
| Activity 2 (Slides 7–8)<br>10 mins | Which format?<br>Explain to learners that there are several formats that can be selected for cells in a spreadsheet. Some of the most commonly used formats are displayed on slide 7 in the form of a screenshot from the ‘format’ menu in Google Sheets.<br>Distribute the handout and ask learners to mark where they think the following formats have been applied:<br>Plain text<br>Date<br>Number<br>Duration<br>Currency<br>Click onto slide 8 to show the answers. |
| Activity 3<br>(Slides 9–11)<br>20 mins | Create your own data set and apply formatting<br>Explain to learners that they are going to create their own version of the travel to school table from the previous activity. Learners’ tables will be based on the travel habits of learners on their table or in their group. Emphasise that it is not crucial that the data is accurate (they can include approximate figures). If necessary, help learners to create a class data set that they can use.<br>Once a data set has been created, direct learners to the spreadsheet resource and ask them to populate it with the data set.<br>Note: The example data set is included in the first tab of the spreadsheet. The column headings are included in the second tab — this is the tab learners should complete.<br>Once learners have entered the data into their spreadsheet, display slide 10, which explains how to apply formatting to a cell. These instructions are also included in the activity handout. Ask learners to apply formatting to the cells on their spreadsheet.<br>Some learners may need support for the ‘duration’ column. Slide 11 provides an explanation of how the duration format will interpret an unformatted number. For simplicity, you may wish to encourage learners to enter the data in the duration format, eg 23 minutes would be 00:23:00. |
| Plenary<br>(Slide 12)<br>5 mins | Why apply formatting?<br>Ask learners to reflect on what they have learned in this lesson and discuss with their partner or group why it is useful to apply formatting to cells in spreadsheets. After learners have given some responses, build the slide to show three possible reasons:<br>It makes them easier to use<br>It makes them easier to read<br>It shows what each cell contains |
