# Solutions: Designing a project with a variable

This page offers a possible solution to the ‘Designing a project with a variable’ activity sheet. To determine whether learners have successfully completed this activity, check whether their design matches their program.

### Task: When the cat sprite is clicked, increase the score by two. When the dog sprite is clicked, increase the score by five. When the bird sprite is clicked, decrease the score by three.

Variable name: Score

| Sprite | Event | Change in value |
| --- | --- | --- |
| Cat | When clicked | Add 2 |
| Dog | When clicked | Add 5 |
| Bird | When clicked | Subtract 3 |
