## Exact task

Create the fixed counter: set `count` to 0 at start; when button A is pressed, change `count` by 1; show the new count. Before testing, predict the display for five button-A presses. Run five tests and record each actual result. Explain the input, process, stored variable, and output. Correct one problem if needed, or state what confirmed the program worked.

Button B reset and decorations are optional only after the required version works. They do not add points.

## Steps and checklist

3. Predict and run five button-A tests.
4. Record actual displays and one correction or confirmation.
5. Complete the input-process-variable-output explanation.
6. Save with the exact filename, demonstrate, and submit.
