## Exact task

Read the fixed narrative. Extract all eight records into the starter with the exact headers `Student ID`, `Club`, and `Minutes`. Preserve each ID, category, capitalization, and numeric value. Keep all eight records visible, make columns wide enough to read, and use one consistent header emphasis. Write one complete sentence naming a Student ID or club and an exact matching value.

Structural example using different data: `Student X attended Chess for 12 minutes.` becomes `X | Chess | 12`.

## Steps and checklist

3. Enter one complete record per row.
4. Compare every row with the narrative before formatting.
5. Write the evidence sentence, save with the exact filename, and submit.
