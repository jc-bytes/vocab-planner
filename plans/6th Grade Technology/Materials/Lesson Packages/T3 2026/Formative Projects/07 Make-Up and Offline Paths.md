# Formative 3D and microbit make-up and offline paths

## 3D model

Use the same fixed desk-organizer goal. If Tinkercad is unavailable, draw front, side, and top views with measurements for the base, holder, and tray. Complete the fit/stability test as a paper prediction. When access returns, build or demonstrate one key transformation to the teacher.

## microbit counter

If MakeCode is unavailable, arrange or draw the blocks for start at 0, button A adds 1, and show count. Trace 0 through five presses in the test table. Demonstrate the saved program later if assigned.

## microbit night light

Use the fixed rule and teacher-provided light readings. Draw the input-condition-output flow, predict below/above results, complete repeat tests, and explain one correction. A paper simulation preserves the objective.

These are formative recovery paths. They do not add a sixth formal grade. Submit printed records or saved files/share links. Do not submit phone photos or screenshots.
