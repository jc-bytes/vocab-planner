# Grade 6 T3 exit and review bank

Use one or two prompts for closure. These are formative.

## Data and spreadsheets

1. What is the difference between a header and a record?
2. Why should a missing value come from a source note?
3. Write a SUM formula using a four-cell range.
4. What question can a column chart answer?
5. Write one conclusion that includes an exact value.

## 3D modeling

1. Name height, width, and depth in a model.
2. What changes when you resize? What changes when you rotate?
3. Why check front, side, and top views?
4. Name one fit or stability test.

## microbit

1. Name one input and one output.
2. Predict a counter after five A presses.
3. What does a threshold do?
4. Explain the true and false paths of the night-light rule.
5. Why repeat the same test after one change?
