## Class Objective

Define a variable and predict how a score variable changes in a Scratch game example.

## Pre-Activities

- Answer the warm-up question: What changes in a game? Review April Week 4 practice vocabulary (part 1). Scratch: block coding tool sprite: character or object in Scratch block: coding piece script: set of coding blocks variable: stores a changing value Identify one variable in a game example.

## While Activities

- Open or view a simple Scratch score example. Predict what happens when the score changes. Record what the variable remembers.

## Post-Activities

- Write one sentence explaining what a variable does. Share one game idea that could use a score.
