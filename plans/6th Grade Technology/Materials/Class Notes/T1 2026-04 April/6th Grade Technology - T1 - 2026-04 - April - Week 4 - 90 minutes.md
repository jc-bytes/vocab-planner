## Class Objective

Create a Scratch score task with one variable and two clickable sprites, test and debug it, and explain how the score changes.

## Pre-Activities

- Complete a vocabulary review activity using April Week 4 practice vocabulary (part 2). value: number or data score: points in a game change: make different test: try and check debug: find and fix a problem Review the goal of the Scratch score challenge.

## While Activities

- Complete Summative Activity #4: Create a Scratch score task with one variable and two clickable sprites that change the score by different amounts, then explain what each sprite does to the score. Test the score task and fix one problem. Show the working score task and submit the short explanation.

## Post-Activities

- Reflect on what changed the variable in your project. Share one debugging step you used.
