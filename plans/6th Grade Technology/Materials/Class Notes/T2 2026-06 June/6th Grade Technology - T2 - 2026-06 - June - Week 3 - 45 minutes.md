## Class Objective

Practice finding mistakes in the sample mBot movement sequences code found in Google Classroom.

## Pre-Activities

- Answer the warm-up question: What can you do when the robot does not move as expected?
- Review June Week 3 practice vocabulary (part 1). test: try and check debug: find and fix a problem improve: make better path: way from start to finish
- Choose the best fix for three simple robot problems: the robot does not move, the robot moves in the wrong direction, or the sensor does not respond.

## While Activities

- Practice finding mistakes in the sample mBot movement sequences code found in Google Classroom.
- Discuss how to write a corrected command.
- Review the debugging check expectations before the next class.

## Post-Activities

- Write one debugging tip for mBot movement. Share your tip with a partner.
