## Class Objective

Debug simple mBot movement sequences and program a path with one improved turn or stop point.

## Pre-Activities

- Review June Week 3 practice vocabulary with Blooket or a matching activity (part 2). route: path to a place problem: something to solve fix: correct a problem
- Draw a simple path with two turns in your notebook.

## While Activities

- Complete Summative Activity #2: Review 3 simple mBot movement sequences, identify the mistake in each one, write the corrected command or value, and explain one correction. Submit the completed debugging check in class or on Google Classroom.
- Program mBot to follow a simple path using the mbot basic map. Test the path one section at a time. Debug one turn or stop point. Improve the program after testing to complete the path faster while staying on track.

## Post-Activities

- Answer in Google Classroom one problem you had during testing and one improvement you made.
