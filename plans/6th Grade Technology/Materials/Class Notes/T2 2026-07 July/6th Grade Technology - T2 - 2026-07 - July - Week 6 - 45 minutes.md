## Class Objective

Predict how a loop can make a program shorter.

## Pre-Activities

- Answer the warm-up question: What actions do you repeat every day? Review July Week 2 practice vocabulary (part 1). repeat: do again loop: code that repeats pattern: repeated design or action Find repeated actions in a sample robot path.

## While Activities

- Act out a repeated command pattern. Rewrite a repeated command list using the word repeat. Predict how a loop can make a program shorter.

## Post-Activities

- Write one sentence explaining what a loop does. Share one repeated robot action.
