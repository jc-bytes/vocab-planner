## Class Objective

Answer responsible communication scenarios, identify website features, and sketch a web page plan for a clear audience and purpose.

## Pre-Activities

- Complete a quick review puzzle using March Week 4 practice vocabulary (part 2). title: name of a page or project menu: list of choices link: clickable connection image: picture section: part of a page Match each website word with its definition.

## While Activities

- Complete Summative Activity #2: Answer 8 online communication scenarios by choosing public or private, naming the audience, and deciding if permission is needed. Submit the completed scenario quiz in class or on Google Classroom. Explore one age-appropriate website. Identify the title, menu, images, links, and main content. Plan a simple web page with an audience, purpose, and three features. Sketch the web page layout.

## Post-Activities

- Share your web page plan with a partner. Improve one part of your plan after feedback. Submit the web page plan.
