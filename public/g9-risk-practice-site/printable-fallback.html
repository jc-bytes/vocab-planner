Read the example

Context. Five students in a Grade 9 group project share one folder. Yesterday, one student accidentally deleted the group's presentation file. The group restored it using version history, and they checked that a backup exists. This is a real situation: shared folders have more people who can make mistakes, but protections like version history and backups reduce the harm.

Probability means how likely something is. Impact means how much harm it could cause. Use facts from the case, not guesses.

A shared folder had one accidental deletion. The file was restored, and a checked backup exists.

The chance of another deletion is medium because five students can edit the folder. The impact is medium because the group could lose work, but version history and the backup help recovery.

Learn to rate a risk

Context. A risk is a bad event that might happen. You will learn how to decide how likely it is, how much harm it could cause, and what protection could help.

Probability asks, How likely is the bad event?

Impact asks, How much harm would the bad event cause?

Protection is an action that lowers the chance of the bad event or reduces the harm.

Worked example: Project folder

A file is deleted about once each month. The folder has no backup.

1. Probability: The deletion has happened repeatedly, so another deletion is possible.

2. Impact: The only copy could be lost, so the harm could be high.

3. Protection: A separate, tested backup lets the group recover the file.
