Probability means how likely something is. Impact means how much harm it could cause. Use facts from the case, not guesses.

A shared folder had one accidental deletion. The file was restored, and a checked backup exists.

The chance of another deletion is medium because five students can edit the folder. The impact is medium because the group could lose work, but version history and the backup help recovery.

Learn to rate a risk

Probability asks, How likely is it? Impact asks, How much harm could it cause?

Example: A project file is deleted every week and has no backup. Probability is high because deletion happens often. Impact is high because the only copy could be lost. A separate backup protects the work because it allows recovery.
