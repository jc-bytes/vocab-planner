This copy packages the author's published HTML5 build for offline use inside
Vocabulary Master. The Tiled tileset extension was changed from `.tsx` to
`.xml` so Vite serves it as XML; the game code, levels, and artwork are
otherwise unchanged. The surrounding arcade integration and iframe sizing
are new.
