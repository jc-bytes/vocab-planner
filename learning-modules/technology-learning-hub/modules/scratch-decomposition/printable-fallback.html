Main-program model

when green flag clicked setup scene repeat until <goal reached> move player check obstacle update score

Decomposition practice, five activities

  1. Write a clear custom-block name for moving a player.
  2. State where setup scene belongs.
  3. Name the event that starts code when space is pressed.
  4. Divide move, wall check, and score update into three named jobs.
  5. Explain what happens when the program calls check obstacle.

Loops and lists practice, five activities

  1. Choose a loop for exactly ten repetitions.
  2. Choose a loop that keeps checking keys while the project runs.
  3. Choose a loop that stops when the sprite touches the goal.
  4. Name the structure that stores five questions.
  5. Write the block idea that reads position 3 from questions.

Debugging practice, five activities

  1. A custom block never runs. Write the first control-flow check.
  2. A repeat until loop never stops. Write the first condition check.
  3. One click adds two points. Write one likely cause.
  4. Write a test with an input, expected result, and actual result.
  5. After one code change, state the fair next step.
