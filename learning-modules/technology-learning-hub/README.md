# Technology Learning Hub

This project is the central student website for reusable Technology modules. Plans reference a module ID, version, section IDs, and track. Formal assessment directions and scoring tools remain outside the public build.

## Grade 6 modules

- `MOD-DATA-SPREADSHEETS-01` v0.1.0, Data Foundations and Spreadsheets
- `MOD-3D-MODELLING-01` v0.1.0, 3D Modelling Foundations
- `MOD-MICROBIT-SENSING-01` v0.1.0, micro:bit Inputs, Variables, and Sensors

## Grade 7 modules

- `MOD-SPREADSHEET-ANALYSIS-01` v0.1.0, Spreadsheet Formulas and Charts
- `MOD-SCRATCH-DECOMPOSITION-01` v0.1.0, Scratch Decomposition, Loops, and Lists
- `MOD-SOURCE-CREDIBILITY-01` v0.1.0, Credible Sources, Licensing, and Credit
- `MOD-SENSOR-SYSTEMS-01` v0.1.0, Sensor Systems, Thresholds, and Testing

## Grade 8 modules

- `MOD-PYTHON-FUNDAMENTALS-01` v0.1.0, Python Input, Arithmetic, and Debugging
- `MOD-DIGITAL-REPRESENTATION-01` v0.1.0, Binary, Images, and Sound

## Grade 9 modules

- `MOD-DIGITAL-REPRESENTATION-01` v0.1.0, Core track with Grade 9 explanations
- `MOD-CYBERSECURITY-RISK-01` v0.1.0, Cybersecurity Threats and Risk Decisions

The Grade 7-9 modules use the shared practice engine. Each topic teaches the idea before opening a five-activity practice set. Attempts stay in local browser storage, can be recreated from History, and can be exported as an HTML practice report. Each module also has a printable fallback and a teacher guide.

All new Grade 7-9 modules remain at `pilot` status until the first monitored classroom run confirms timing, wording, keyboard use, and device behavior. The official plans include the fallback requirement.

The shared STEAM work period does not have a module. Students work on their assigned Mathematics, Arts, Science, or Technology project and receive two Technology appreciation grades from observation, work logs, expo participation, and reflection.

## Development

```bash
npm install
npm run dev
npm test
npm run build
```

Do not publish teacher scoring notes, answer keys, student information, or private assessment variants from this project.
