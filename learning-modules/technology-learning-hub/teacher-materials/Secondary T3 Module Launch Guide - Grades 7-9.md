# Third trimester module launch guide for Grades 7-9

Use the modules from the central Technology Learning Hub. Do not copy module source into grade folders. Keep each module at version `v0.1.0` during the first classroom run and record timing or wording problems in the teacher guide.

Students use their own computers. Phones are not permitted. Students should export their practice report before changing computers or clearing browser data because progress stays on the current browser and device.

## Common classroom routine

1. Open the assigned Learn page and teach from the example.
2. Complete one guided item together.
3. Assign the matching five-activity practice page. The teacher may stop after the number of activities that fits the class period.
4. Have students save the application record when the module includes one.
5. Open History and export the HTML practice report when evidence is needed.
6. Use the separate formal task and rubric for a grade. Module practice is formative.

## Failure paths

- Browser storage problem: export the report before troubleshooting or use the printable fallback.
- No internet: serve the built hub locally. Every listed module works without an account when hosted locally.
- Device interruption: use the printable fallback and enter the final application record later.
- Lost practice history: recreate the task from the saved working file, notebook record, or printed fallback. Do not replace missing evidence with a phone photo.
