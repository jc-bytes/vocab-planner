# App Screens, Events, and Test Cases teacher guide

**Module:** MOD-APP-DESIGN-01 v0.1.0  
**Grades:** Grade 8  
**Status:** Pilot  
**Evidence:** Saved attempts, application record, and exported HTML practice report

## Before class

- Open the assigned module route and verify the required section IDs.
- Prepare App planning template or drawing tool.
- Each practice page contains five written design activities on one screen. Decide whether students finish all five in one class or save and continue later.
- Keep the printable fallback ready.
- Remind students that progress stays on the current browser and device. They should export before changing computers.

## Teaching pattern

1. Use 5 minutes for the objective and one retrieval question.
2. Teach one Learn section for 10-15 minutes while students follow on their computers.
3. Model the worked example without completing the new practice scenario.
4. Assign the matching Practice section for 25-30 minutes. Students must save the exact five responses before leaving the page.
5. Review one common error. Students then complete or update the application record.
6. Use the final 5 minutes to export evidence or record the stopping point.

Do not assign the whole module in one period. Monthly plans name the exact sections for each class.

## What to check

Check the connection across the work: the feature addresses the need, screen jobs support the feature, events move the same user path, stored values have a purpose, and tests can pass or fail.

## Misconceptions

Students describe decoration instead of purpose; omit event results; write opinions instead of pass rules.

## Differentiation

- Ask students who need support to explain one decision aloud before selecting an answer.
- Let students revise saved responses after a conference or class review. Updated work remains available for export.
- Students ready for extension should justify why one rejected option fails or create a new test case using the same rule.

## Make-up and fallback

An absent student completes the same assigned Learn and Practice sections, then exports the report. The printable fallback includes all three five-activity scenarios and the final app-plan table. It works without an account or internet connection.

## Pilot notes

Record actual completion time, unclear wording, repeated wrong answers, device problems, and whether the fallback produced comparable evidence. Keep the module at pilot status until classroom observations have been reviewed.
