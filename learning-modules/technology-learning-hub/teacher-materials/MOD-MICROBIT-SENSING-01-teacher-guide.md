# MOD-MICROBIT-SENSING-01 Teacher Guide

Version 0.1.0 · Pilot · Grade 6 · Formative only

## Intended use

Use the module for the fixed button counter and fixed automatic night-light response. Students first learn the idea, complete several short practice activities, then build in MakeCode and record test evidence. These lessons occur after the five formal third-trimester grades.

## Suggested sequence

1. `BOARD-LEARN-01`, `PARTS-PRACTICE-01`, `IO-LEARN-01`, and `IO-PRACTICE-01`.
2. `VARIABLES-LEARN-01` and `VARIABLES-PRACTICE-01` before the counter build.
3. `COUNTER-RECORD-01` during the MakeCode counter build.
4. `CONDITIONS-LEARN-01`, `CONDITIONS-PRACTICE-01`, and `SENSOR-LAB-01` before the sensor build.
5. `DEBUG-PRACTICE-01` while students test both branches.
6. `NIGHT-LIGHT-RECORD-01` and `HISTORY-01` for evidence and export.

The required counter sets `count` to 0, adds 1 when button A is pressed, and shows the new count. The required sensor response shows a night icon below the chosen light threshold and clears the display otherwise.

## Hardware and fallback

Prepare numbered micro:bits, USB cables, and computers with MakeCode access. If hardware is limited, students use the MakeCode simulator in pairs and rotate through physical-device testing. If the module is unavailable, use `printable-fallback.html` and project the teacher model.

## Evidence

The website stores attempts only on the current browser. Students export the report before changing computers. Hardware or simulator behavior must still be checked directly by the teacher. Phones and phone-camera evidence are not used.
