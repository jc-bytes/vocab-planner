# Data Foundations and Spreadsheets teacher guide

Module: `MOD-DATA-SPREADSHEETS-01 v0.5.0`

Status: Prototype. Use only for a monitored Grade 6 pilot with the printable fallback ready.

## Purpose

This module provides Grade 6 theory, examples, guided practice, immediate feedback, independent responses, review, and practice evidence for the data and chart sequence. It does not replace Summative Activities #1, #2, or #5.

## Before class

1. Open the assigned section on the school computers before students arrive.
2. Keep the printable fallback available for devices that do not load.
3. Decide whether students work individually or in pairs. Every student still completes the teacher's separate formal assessment independently when required.
4. Tell students that progress remains on the current browser and device.
5. Do not ask students to use phones, photographs, or camera evidence.

## Suggested timing

For a 45-minute class, allow 5 minutes for entry and explanation, 20 to 25 minutes for the assigned module section, 10 minutes for correction or discussion, and 5 minutes to save evidence and close.

The 195-minute estimate describes the whole library once. Practice can be repeated with additional datasets. Assign only the learn and practice sections that fit the class block.

## Practice answers

### TABLE-LEARN-01 and TABLE-PRACTICE-01

- Title: Minutes Spent in School Clubs
- Headers: Club and Minutes
- Complete record: A03, Science, 45
- Value in the Minutes column: 50

### CLEAN-LEARN-01 and CLEAN-PRACTICE-01

- Students may edit every cell and delete any row. Undo and Redo recover table changes.
- Change `math` to `Math`.
- Enter `45` because the source note confirms it.
- Change `thirty` to `30`.
- Remove the exact repeated A04 row.

### FORMULA-LEARN-01 and FORMULA-PRACTICE-01

- Students enter formulas directly in cells B6 and B7 and see the calculated results in the simulated spreadsheet.
- Total: `=SUM(B2:B5)`
- Average: `=AVERAGE(B2:B5)`
- The module also accepts mathematically equivalent versions shown in its practice logic.

### CHART-BASICS-01

- Students first learn that a chart turns table data into a visual comparison.
- A labeled example introduces the title, side label, bottom label, and columns before students build.
- A short guide distinguishes column, bar, line, and pie charts by the question each one answers.
- This is a teaching section. It does not add a sixth practice result or grade.

### CHART-TYPES-PRACTICE-01 and CHART-PRACTICE-01

- Students enter two headers and four category-value records.
- Students select A1:B5 by dragging or with the Select all data fallback.
- Column, bar, line, and pie previews are available for comparison.
- Completion requires a column chart with a title, bottom label, and side label.

### INTERPRET-LEARN-01 and INTERPRET-PRACTICE-01

- Largest value: Math
- Difference between Math and Music: 20
- Total: 160
- The conclusion must contain at least 20 characters. Check that it names chart evidence and does not invent a cause.

## Evidence and privacy

The module saves an immutable attempt history in local browser storage. Each submission records the dataset, response, checks, and available editing snapshots. Practice history can reconstruct the student's submitted tables, formulas, charts, and written answers. The downloadable HTML report carries those reconstructions without requiring the original website.

The module does not send progress to a server. The student's name and class are requested only when the browser creates the downloadable HTML report. Those details are not written to local storage.

On shared computers, students should download their report before the next student selects Reset this device. The reset action requires confirmation.

## Failure and make-up path

- Internet or server unavailable: use `printable-fallback.html` or a printed copy.
- Browser progress lost: complete the assigned section again or use the equivalent page in the packet.
- Device shortage: students may practice in pairs, but each student writes the chart conclusion on the printed packet or in the teacher's assigned file.
- Spreadsheet software unavailable: complete the browser simulation or packet. Schedule the actual spreadsheet file for the next available computer session.
- Reduced class time: assign only the named section. Do not combine sections to compensate.
